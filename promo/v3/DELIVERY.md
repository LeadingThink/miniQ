## 复现

当前源码已包含远控修订。从项目根目录运行以下命令可以全片渲染到新文件，并复制原片音乐音轨；原 `build.sh` 使用旧输出名，会覆盖对比原片，本次未运行它。

```sh
export PATH="/usr/local/bin:/opt/homebrew/bin:$PATH"
node promo/v3/capture.mjs
ffmpeg -y -i promo/v3/out/video.mp4 -i promo/out/miniq-promo-v3.mp4 \
  -map 0:v:0 -map 1:a:0 -c copy -t 90 -movflags +faststart \
  promo/out/miniq-promo-v3-remote.mp4
```

依赖沿用 promo 的 puppeteer-core、系统 Chrome 与 FFmpeg。`PREVIEW=1 node promo/v3/capture.mjs` 只生成预览。整个 v3 制作源位于本目录，未改动旧版 v2。
