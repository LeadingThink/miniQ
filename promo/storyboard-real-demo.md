# miniQ 真实能力演示版分镜

目标时长：75–90 秒。每一段都遵循：**对话指令 → 工具调用/审批 → 实际产物**。

| 时间 | 真实演示 | 屏幕证据 | 旁白/字幕 |
|---|---|---|---|
| 0–5s | 先展示已经生成的图片、视频缩略图、音乐播放器和文档产物 | 真实文件/产物卡片 | 一句话，交付多种结果 |
| 5–20s | 输入图片指令并发送 | 对话消息、`generate_image` 工具卡、真实生成图片 | 想法直接变成视觉素材 |
| 20–35s | 基于生成图片发起视频指令 | `generate_video` 高风险审批、任务状态、视频结果 | 同一段对话继续生成视频 |
| 35–48s | 发起音乐生成 | `generate_music` 审批、异步任务状态、音频播放/下载 | 配乐也由对话完成 |
| 48–60s | 上传 PDF/图片，要求总结并生成 docx/xlsx | `doc_read`、`doc_write`、真实文件预览 | 文件读写和结构化交付 |
| 60–72s | 高风险命令审批 + 远程手机批准 | 审批卡、手机端同一会话、继续执行 | 权限始终由你掌控 |
| 72–84s | 保存技能、引用技能、定时任务 | Save as skill、`/weekly-report`、scheduled task | 做过一次，下次自动复用 |
| 84–90s | 多模型/工具路由和品牌收尾 | 模型选择、工具时间线、最终产物墙 | miniQ：你说目标，它来执行 |

## 录制规则

- 所有核心片段来自运行中的 desktop app 或 mobile web app。
- 保留完整对话、工具名、审批状态、异步任务状态和下载/预览结果。
- 生成图片、视频、音乐必须录到真实产物；如果异步任务尚未完成，展示任务 ID、进度和恢复入口，并在完成后补一个结果镜头。
- 录制素材按 `image`, `video`, `music`, `docs`, `approval`, `mobile`, `skill`, `schedule` 命名。
- 动效包装只负责转场和字幕，不能替代产品操作画面。
