# miniQ 产品视频叙事重构方案

## 四幕结构（约 90 秒）

### 第一幕：从结果开始（0–6s）
**镜头**：开场白屏 → 直接展示成品文档/工作成果  
**文案**：  
- Kicker: THE RESULT  
- Title: 报告已经写好了  
- Sub: 你只说了一句话

**画面**：docx 预览、artifacts bar、完成状态

**文案**：

- 工具调用时间线展开（读取、搜索、分析）

#### 2.2 真实资料到交付文件（18–34s）
**镜头**：文件上传 → PDF 预览 → 工具处理 → 文档生成落盘  
**文案**：  
- Kicker: FROM FILES TO DOCS
