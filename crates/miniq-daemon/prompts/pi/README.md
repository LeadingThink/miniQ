# PI system prompt

Source: https://github.com/earendil-works/pi/tree/682c7b93ce3e0a52b579c2b65b4c06bb392e7180

- `system-prompt.ts` is an unchanged copy of `packages/coding-agent/src/core/system-prompt.ts`.
- `text.ts` is an unchanged copy of `packages/ai/src/utils/text.ts`.
- `LICENSE` is the upstream MIT license.
- `system-prompt.txt` is generated by the upstream constructor, then applies the miniQ brand, documentation links, and one tool/skill discovery rule.

miniQ supplies the tool names, tool descriptions, and working directory as runtime values.
Visible PI branding is replaced with miniQ. Documentation links point to the miniQ repository.
Project instructions, skills, and session context remain separate miniQ context sections.
The old miniQ core prompt and execution-policy prompt are not appended.

Generate the template from the repository root:

```powershell
node --input-type=module -e "import { writeFileSync } from 'node:fs'; import { miniqTemplate, piDirectory } from './scripts/pi-prompt.mjs'; writeFileSync(new URL('system-prompt.txt', piDirectory), miniqTemplate());"
```

Verify the template without compiling Rust:

```powershell
node --test scripts/pi-prompt.node-test.mjs
```
