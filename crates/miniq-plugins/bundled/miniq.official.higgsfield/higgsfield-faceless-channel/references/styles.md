# 画风库

所有画风都是**非写实**的。每种画风给出：一句话简介（可直接用作提问选项描述）、画风公式要点、调色约束、动态特征、禁忌。实际使用时，把要点扩写成 80–100 词英文公式（生成模型对英文更稳定），此后每条图片/视频提示词逐字粘贴，不改一个词。

## 1. 杂志拼贴动态图形（Editorial Collage）——解说/历史默认
- 简介：剪报拼贴 + 扁平图形的动态信息图风格，适合讲数据和故事。
- 要点：半色调网点照片剪片、撕纸边、粗描边图形元素、网格纸/牛皮纸底、手写标注箭头、贴纸式标签。
- 调色：米白/黑为基底 + **唯一强调色**（先锁定一个，如信号红、钴蓝、芥末黄），写入公式和“调色锁”。
- 动态：元素滑入、弹出、定格停顿，镜头轻推；像逐层贴上去。
- 禁忌：照片级真实人脸、渐变霓虹、多个强调色、可读的品牌字样。

## 2. 纸艺立体景（Paper Diorama）
- 简介：层叠卡纸搭成的微缩舞台，温暖手作感。
- 要点：多层剪纸、可见纸张纤维和切口厚度、柔和桌面光、浅景深、微缩透视。
- 调色：低饱和纸色 + 唯一强调色。
- 动态：纸片轻微摆动，镜头平移穿过层次，偶有纸片翻折转场。
- 禁忌：塑料光泽、3D 渲染质感、真实照片背景。

## 3. 人偶剧场（Mannequin）
- 简介：无五官木质/哑光人偶演绎历史与戏剧场景。
- 要点：统一的无脸人偶，关节可见，服装靠布料与道具区分身份；戏剧性侧光。
- 身份链：先生成“固定演员表”，之后每个镜头以演员设定图作参考；同一角色的后续形态必须带首个形态作为参考图。
- 禁忌：有五官的写实人脸、血腥特写。

## 4. 电影感绘本（Cinematic Storybook）——童话神话默认
- 简介：像绘本插画活了过来，暖光、神秘、电影构图。
- 要点：水粉/厚涂质感、柔和体积光、宽银幕构图、深色阴影中的暖色光源。
- 动态：一拍二（约 12fps 的阶梯动画感，合成时可用 `fps=12` 后再升回 24/30 实现），缓慢镜头运动。
- 声音：必须有神秘平静的配乐底。
- 禁忌：搞笑夸张表情、现代物件、真实照片感。

## 5. 简笔漫画（Stickman）
- 简介：白底粗线简笔人，信息清晰、成本低。
- 要点：纯色底、均匀粗黑线、极少填色、夸张肢体动作表达情绪。
- 适合：解说、图片故事。

## 6. 平面纸艺 / 手绘墨线（图片故事常用）
- 平面纸艺：扁平剪纸块面、轻投影、有限色板。
- 手绘墨线：钢笔排线、淡彩、留白多。

## 用户自定义画风
- 上传参考图（≤3 张）：只提取线条/表面质感/明暗/调色/背景处理/动态暗示，**剥离人物身份**；不叠加任何频道默认画风。参考图在后续所有重试中保持不变；全部失败报告“画风锚点失败”，不得退化为纯文字生成。
- 自由描述：生成一张“可读的小样”——一个简单可辨认的主体 + 色板条 + 线条/明暗示例，而不是抽象色块。告诉用户“样张看起来可能有点怪，它只是画风参考，不是成片画面”。
