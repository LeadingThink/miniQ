# 儿童内容与儿歌

## 儿童视频通用规则
- 每块 10 秒 = **4 个约 2.5 秒镜头**，每块顺序变化，避免千篇一律。
- **互动模式（必须）**：旁白直接叫角色和观众的名字；镜头里安排可见的反应（挥手、点头、看向镜头）；问题放在句尾，让块边界成为“等答案”的停顿，下一块开头给出答案。
- 语言：短句、具体名词、重复关键词；每块英文 34–38 词 / 中文 42–50 字；不说吓人或危险的内容。
- 地点轮换更频繁；多插入“长了脸的物件”、简单示意图。
- 安全：角色一律非写实卡通形象；提示词避免 child/kid/childlike 等词（用“small cartoon character / little bunny”替代），避免贴脸特写与亲密姿态，这是最常见的审核失败原因。
- 配乐：轻快、低音量；也可无配乐只保留音效。

## 儿童画风组
| 画风 | 简介 | 要点 |
|---|---|---|
| 3D 工作室风（默认） | 圆润明亮的 3D 动画角色 | 大眼、柔软材质、明亮饱和、柔和全局光 |
| 毛毡定格 | 手工毛毡玩偶的定格动画 | 毛绒纤维、针脚、略抖的定格节奏 |
| 蜡笔绘本 | 蜡笔/彩铅手绘 | 纸纹、笔触可见、留白 |
| 积木世界 | 塑料积木搭建的场景 | 方块结构、光滑塑料反光（不用任何品牌名） |
| 剪纸拼贴 | 彩色卡纸剪贴 | 纸边、轻投影 |
选定后同样写成画风公式并锁定。

## 儿歌 MV
1. **歌词**：主歌/副歌结构，副歌重复 2–3 次；每行 4–8 词（中文 6–10 字）；押韵、拟声词、可做动作的指令（拍手、跳一跳）。
2. **生成歌曲**：用音频工具的音乐/歌曲模式（对标为 `generate_audio` 的音乐模型），提供歌词、风格（欢快童声、木琴、尤克里里）、BPM（100–130）、时长。
3. **歌曲是主轴**：先有完整歌曲，再用转写（`higgsfield-subtitles` 的 `transcribe.py`）拿到每行时间，按行规划镜头；视频块长度可以不严格 10 秒，按乐句切分，合成时以音频时长为准。
4. **画面**：每行歌词 1–2 个镜头，动作与歌词对应（唱到“拍拍手”就拍手）；副歌复用同一场景但换角度。
5. **字幕**：儿歌默认开启大字幕，一行一句，卡拉 OK 式逐词高亮可选（ASS `\k` 标签，见 `higgsfield-subtitles`）。
6. **混音**：歌曲本身即全部音频，不再叠旁白；响度 −16 LUFS。
