# 需求采集与分派

## 七项必备参数
| 参数 | 取值 | 缺失时（全自动模式默认） |
|---|---|---|
| 频道类型 | 解说 explainer / 历史 history / 儿童 kids / 图片故事 picture_story / 童话神话 fairytale | 按选题推断，默认解说；神话/传说/童话类推断为 fairytale |
| 画风 | 见 `styles.md`；或用户上传 ≤3 张参考图；或自由描述 | 频道默认画风 |
| 选题 | 自由文本；可“根据附件提炼” | 必问（全自动时从附件提炼） |
| 时长 | 以**秒**记录 `REQUESTED_SECONDS` | 解说/历史 120s，儿童 60–90s，童话 150s |
| 画幅 | 仅 `16:9` 或 `9:16` | 16:9（短视频平台意图时 9:16） |
| 字幕 | 开/关 | 关 |
| 音色 | `voice_id` + `voice_type` 成对 | 调 `list_voices` 选该频道推荐音色 |

- 计费块数 `BILLING_BLOCKS = ceil(REQUESTED_SECONDS/10)`，采集后固定，不从成片实际时长反推。时长不是 10 的倍数时最后一块为短块。
- 历史类时长 ≥600 秒自动进入长片纪录模式（`history-longform.md`）。
- 画风选“逐帧/静帧”类预设时，无论频道类型都改走图片故事机制（`picture-flow.md`），语气保留原频道。

## 提问规则
1. 用户已经说过的参数不再问，也不要“我理解的是……对吗？”式复述确认。
2. 顺序：频道类型 → 画风（先展示可选画风）→ 选题/时长/画幅/字幕 → 音色（先 `list_voices` 再给真实选项）。
3. 一轮最多 3 个问题，选项用简短标签；画风选项描述用 `styles.md` 里的一句话简介，不编造，不写第三方品牌/工作室名。
4. 不问：用哪个模型、每块几个镜头、重试策略、帧率、混音电平、封面标题、角色名——这些由本技能锁定。
5. 不生成音色试听，不在问题里贴媒体链接，音色选定后不再问。
6. 用户说“全自动 / 别问 / 给我惊喜”→ 缺项全部取默认值并在最终汇报里列出所用值。

## 预估与积分确认（所有模式都要做一次）
```
预计：画风样张 1 + 素材 ~{角色+场景+道具} 张 + 视频 {N} 块 × 10s + 旁白 {N} 条 (+ 配乐 1)
```
能查余额就附上余额；用户同意后再生成。全自动模式下仍需在首次消耗积分前得到用户对“全自动生成”的认可（一次即可）。

## 频道默认值速查
| 类型 | 默认画风 | 节奏 | 旁白语气 | 推荐音色倾向 |
|---|---|---|---|---|
| 解说 | 杂志拼贴动态图形（首选）/ 简笔漫画 | 快，密集硬切 | 随意第二人称，冷面幽默，开头钩子+承诺 | 年轻、清晰、有能量 |
| 历史 | 杂志拼贴动态图形；备选纸艺立体景、人偶剧场；长片用水彩编年 | 较慢，按时间线 | 机智、带点讽刺的讲述者（长片：沉稳纪录片） | 低沉男声 / 英式叙述 |
| 儿童 | 儿童画风组（`kids.md`），首选 3D 工作室风 | 快，每块 4 刀 | 温暖老师口吻，直接称呼观众与角色 | 温暖亲切 |
| 图片故事 | 平面纸艺（推荐）/ 简笔 / 手绘墨线 | 由音频时间轴决定 | 随题材 | 随语气 |
| 童话神话 | 电影感绘本（`styles.md`），一拍二动画感 | 慢、有氛围，每块 5 个约 2s 镜头 | 低声、温暖、神秘，不讲笑话 | 叙事感强；必须配神秘平静的配乐 |

## 频道 DNA 复用
如果用户提供上期的 `channel_dna.json`：直接复用画风公式、锚点、音色对和命名素材，只换选题；无需重新选画风和音色。

## 分派到其他技能
- 纯产品广告、单条电影感短片 → `higgsfield-storyboard-video`
- 只要给一段文字配音 → `higgsfield-narrator`
- 只要给现有视频加字幕 → `higgsfield-subtitles`
- 需要通过 API Key 批处理 → `higgsfield-api-generate`
