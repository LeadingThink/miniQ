# 持仓复盘指标口径

## 1. 输入格式

最小 CSV：
```
代码,数量,成本
600519,200,1500.00
300750,500,180.50
00700,300,350.00
AAPL,50,170.00
```
可选列：`市场`（sh/sz/hk/us，缺省按代码规则推断）、`名称`、`买入日期`（YYYY-MM-DD，用于区间起点）、`币种`。
重复代码：合并，数量相加，成本按加权平均 = Σ(成本×数量) / Σ数量，并在报告中注明。

## 2. 单只指标

| 指标 | 公式 | 备注 |
|---|---|---|
| 市值 | 现价 × 数量 | 折算人民币：× 汇率（写明汇率与日期） |
| 成本额 | 成本 × 数量 | 是否含手续费由用户确认 |
| 盈亏额 | 市值 − 成本额 | |
| 盈亏率 | 盈亏额 / 成本额 | |
| 权重 | 市值 / 组合总市值 | 合计应为 100% |
| 盈亏贡献 | 盈亏额 / 组合总盈亏额 | 总盈亏为负时按绝对值解释 |

## 3. 组合指标

| 指标 | 公式 |
|---|---|
| 总市值 | Σ 市值 |
| 总成本 | Σ 成本额 |
| 总盈亏率 | (总市值 − 总成本) / 总成本 |
| 币种占比 | 各币种市值 / 总市值 |
| 前 N 集中度 | 权重最大的 N 只合计 |
| 行业集中度 | 各行业权重；前 3 行业合计 |
| HHI | Σ(权重_i²)，权重用小数。常见参考：< 0.15 分散，0.15–0.25 中等，> 0.25 集中（仅作参考，不评级） |

行业字段来源：A 股 `akshare.stock_individual_info_em(symbol='600519')` 的"行业"；港股/美股 `yfinance.Ticker(x).info.get('sector')`。拿不到写"未分类"。

## 4. 区间收益与基准

- 默认区间：年初至今（1 月 1 日后的第一个交易日 → 最近交易日）；用户给买入日期时可用"自买入起"。
- 组合区间收益（简化，假设区间内持仓不变）：
  ```
  组合市值_t = Σ(数量_i × 收盘价_{i,t} × 汇率_t)
  区间收益 = 组合市值_end / 组合市值_start − 1
  ```
- 基准：沪深 300（`000300`）、标普 500（`^GSPC`）、恒生指数（`^HSI`）；加权基准 = 按组合中各市场权重加权的指数收益，写明权重。
- 超额收益 = 组合区间收益 − 基准区间收益（百分点）。
- 相关性：组合与基准日收益率的 Pearson 相关系数（≥ 60 个交易日才算）。

## 5. 最大回撤（简化）

```python
import pandas as pd
nav = portfolio_value_series  # 按日期索引的组合市值
peak = nav.cummax()
drawdown = 1 - nav / peak
mdd = drawdown.max()
mdd_end = drawdown.idxmax()
mdd_start = nav.loc[:mdd_end].idxmax()
```
- 假设：区间内持仓数量不变；不考虑分红再投资与现金；停牌日用前收盘价填充。
- 基准 MDD 用同样方法算指数。
- 报告中必须写出 `mdd_start → mdd_end` 区间。

## 6. 看板色彩

- 盈利 / 上涨：朱砂 #C8323B + ▲；亏损 / 下跌：松绿 #2E8B57 + ▼（A 股习惯，图例注明）。

## 7. 报告中必须出现的说明

- 现价来源与 `fetched_at`，延迟级别（公开渠道约 15 分钟）。
- 汇率来源与日期。
- 成本是否含手续费。
- 回撤为简化计算。
- 行业分类来源（东方财富 / Yahoo），不同来源口径不同。
