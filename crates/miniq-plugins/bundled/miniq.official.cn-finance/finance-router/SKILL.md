# 金融场景入口

## 适用场景
- "茅台现在多少钱，PE 贵不贵？"
- "帮我看看宁德时代这家公司怎么样。"
- "下周有哪些我关注的公司出财报？"
- "最近 CPI、PMI 什么情况？"
- "我有 5 只持仓，帮我算算盈亏和集中度。"
- "签合同前帮我查查这家公司靠不靠谱。"

用户哪怕没说"股票""金融"，只给了一个 6 位代码（600519）、5 位港股代码（00700）或美股 ticker（AAPL），也应进入本技能。

不适用：个人记账、发票报销、工资社保计算——这些不是投研场景。

## 红线（一票否决，本包所有技能共同遵守）
1. **不编造数据**：拿不到就写"当前公开渠道未覆盖，需进一步核实"，不要编一组数字再标"待核实"。
2. **每个关键数字都能追溯到来源 + 截至时间**：格式 `（来源：东方财富，截至 2026-10-10 15:00）` 或 `（来源：公司 2025 年年报，2026-04-25 披露）`。同一表格共享来源时可在表尾统一标注。
3. **来源分级**：交易所公告、公司年报、统计局、央行为一手来源，可直接采信；财经媒体、第三方平台二次引用为非一手，标注"需核实原文"。
4. **不混淆口径**：净利润 vs 归母净利润、同比 vs 环比、财年 vs 自然年、前复权 vs 不复权；不确定时写"据我理解"并请用户确认。
5. **不提供投资建议**：不给买卖点、目标价、仓位建议。用户直接问"该不该买"，回答以"信息整理 + 条件化框架（若 X 则关注 Y）"代替结论，并说明本包定位。
6. **检索优先于记忆**：任何行情、财务、宏观数字必须通过工具当场获取，禁止引用训练记忆中的数值。

## 步骤

### 1. 识别意图
用 `ask_user` 之前先自行判断，只有标的或范围歧义时才问。把请求拆成一个或多个标签：

| 用户在问什么 | 标签 | 路由到 |
|---|---|---|
| 现价、涨跌、K 线、财务三表、股东、分红、"把数据拉下来" | 取数 | `stock-data-cn` |
| "怎么样""值不值得研究""基本面/技术面/消息面" | 个股分析 | `stock-analysis-cn`（会先调 `stock-data-cn`） |
| 财报日历、业绩预告、超预期/不及预期、管理层指引、关注列表 | 财报 | `earnings-tracker-cn` |
| CPI/PPI/PMI/社融/M2/LPR/美联储/美债 | 宏观 | `macro-monitor-cn` |
| 工商信息、股权、高管、诉讼、"靠不靠谱""背调""尽调" | 尽调 | `company-dd-cn` |
| 持仓、成本、盈亏、权重、回撤、跟指数比 | 持仓 | `portfolio-review` |
| "PE<20 ROE>15% 筛一下" | 选股 | `stock-data-cn` 批量取数 + 本技能做筛选表 |

复合请求必须拆分，例如"结合宏观看看茅台能不能买" → 宏观 + 个股分析；按顺序执行，再汇总。

### 2. 规范化标的
- A 股 6 位数字、港股 5 位数字、美股字母 ticker；公司名用 `web_search "<名称> 股票代码"` 确认，多个候选（同名、A+H 两地上市、ADR）用 `ask_user` 让用户选，不自行猜测。
- 代码映射表（`sh600519` / `1.600519` / `600519.SS` 等）见 `stock-data-cn/references/data-sources.md`。

### 3. 时间口径
- 相对时间按北京时间解释：今天 = 系统日期；昨天 = 日期 −1；本周 = 本周一至今；最近 7 天 = 今天往前 7 个自然日；"上季度"按自然季度。
- 回答"现价/最新"前先判断交易时段：A 股 09:30–11:30、13:00–15:00；港股 09:30–12:00、13:00–16:00；美股夏令时北京 21:30–04:00、冬令时 22:30–05:00（按当前日期推导，不硬记切换日）。非交易时段写明"收盘价（YYYY-MM-DD）"。
- 跨市场对比先对齐窗口：A 股 T 日收盘 vs 美股 T−1 夜盘。

### 4. 执行路由
用 `skill_read` 读取目标技能后按其步骤执行；多技能时用 `task_update` 列清单。数据落盘统一在 `<工作区>/投研/` 目录下，由各技能定义子路径。

### 5. 汇总交付
- 第一段直接回答用户的问题，含关键数字 + 来源 + 时间。
- 多标的对比时每个标的都带标准代码，排序写明依据指标（市值、增速、估值分位），不要用"地位""重要性"等笼统词。
- 置信度分层：高置信度直接陈述；中等用"倾向于"；低用"不排除"。
- 结尾固定附"风险提示"段落。

## 注意事项 / 安全
- 本包只做公开信息整理，不接入任何券商账户，不执行交易，不保存用户账户凭证。
- 用户持仓 CSV 属敏感数据，只在本地处理，不上传到在线服务；输出前问是否需要脱敏（隐藏数量与成本）。
- 公开页面结构可能变化，取数失败时按 `stock-data-cn` 的降级链处理并如实说明。

## 如何确认完成
- 已路由到正确技能并完成其交付物。
- 回复中每个数字都带来源与截至时间。
- 没有任何买卖、目标价、仓位建议。
- 结尾有风险提示。

风险提示：本分析仅为信息整理，不构成投资建议。市场有风险，投资需谨慎。
