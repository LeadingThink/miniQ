# 财报追踪

## 适用场景
- "下周有哪些 A 股公司披露年报？我关注的有没有？"
- "英伟达昨晚财报怎么样，超预期了吗？"
- "把茅台最近 8 个季度的营收和净利润做成同比环比表。"
- "帮我把 600519、00700、AAPL 加到关注列表，以后财报季提醒我。"

不适用：全面个股分析（`stock-analysis-cn`）；只取财务三表不看事件（`stock-data-cn`）。

## 前置条件
- `python3` + `akshare`（A 股日历与业绩）/ `yfinance`（美股财报日期），缺库 `ask_user` 后安装。
- 关注列表文件 `投研/关注.json`，结构：
  ```json
  {"updated_at": "2026-10-10 09:00", "cn": ["600519", "000858"], "hk": ["00700"], "us": ["NVDA", "AAPL"], "note": {"600519": "白酒龙头"}}
  ```
  不存在时首次用 `file_write` 创建；修改前 `file_read` 再合并，不覆盖用户手写备注。
- 财报日历一手来源与预期数据渠道见 `stock-data-cn/references/data-sources.md`；本技能的时间表与术语见 `references/earnings-calendar.md`。

## 步骤

### 1. 识别任务类型
| 用户在问 | 任务 |
|---|---|
| "下周 / 本月谁出财报" | A. 日历扫描 |
| "X 财报怎么样 / 超预期吗" | B. 财报后对比 |
| "X 最近 N 个季度的趋势" | C. 同比环比表 |
| "管理层说了什么 / 指引" | D. 指引摘录 |
| "加到关注 / 看看关注列表" | E. 关注列表维护 |

### 2A. 日历扫描
- A 股：`shell_run` `python3 -c "import akshare as ak; print(ak.stock_yysj_em(symbol='沪深A股', date='20251231'))"`（预约披露时间表，`date` 为报告期；函数名以 `dir(ak)` 为准）；业绩预告 `ak.stock_yjyg_em(date='20251231')`、业绩快报 `ak.stock_yjkb_em(...)`。
- 港股：港交所披露易 `https://www.hkexnews.hk/` 或公司官网"投资者关系"页，`web_fetch`。
- 美股：`yf.Ticker('NVDA').calendar` 或 `.earnings_dates`；一手确认用 SEC 8-K / 公司 IR 页。
- 时间窗口推算：下周 = 下周一至下周日；本月 = 本月 1 日至月末。美股财报标"盘前 / 盘后"并换算北京时间（夏令时 +12h、冬令时 +13h）。
- 与 `投研/关注.json` 交叉，关注的标的置顶。
- 输出 `投研/财报日历-<YYYY-MM-DD>.md`：表格列"日期 | 市场 | 代码 | 名称 | 类型（预告/快报/正式）| 是否关注 | 来源"。

### 2B. 财报后对比
1. 取实际值：A 股用 `ak.stock_yjbb_em(date=报告期)` 或巨潮公告 PDF（`view_pdf` 读"主要会计数据"）；美股用 SEC 10-Q/10-K 或公司新闻稿（`web_fetch` IR 页）；港股用披露易公告。
2. 取预期值：`web_search "<公司> <报告期> 营收 预期"`，来源多为媒体汇总的分析师一致预期，**标"非一手 / 需核实原文"**；拿不到就写"无公开一致预期"。
3. 对比表：营收、归母净利润（美股 EPS）、毛利率、经营现金流；列"实际 | 预期 | 差异% | 同比 | 环比 | 来源"。
4. 判定口径：差异 > +3% 写"高于预期"，< −3% 写"低于预期"，其余"基本符合"。只描述，不评级。
5. 股价反应：从 `stock-data-cn` 取财报次日涨跌幅并注明"单日反应，不代表趋势"。

### 2C. 同比环比表
- 取最近 8 个季度单季数据（A 股季报为累计值，需用本期累计 − 上期累计换算单季，写明换算方法）。
- 同比 = 本季 / 去年同季 − 1；环比 = 本季 / 上季 − 1。春节、财年差异导致的季节性要注明。
- 输出 `投研/<代码>/财报/季度趋势-<日期>.csv` 与 Markdown 表；可用 `visual-charts` 出柱线图。

### 2D. 指引摘录
- 来源：业绩说明会纪要（A 股：上证 e 互动 / 深交所互动易 / 公司公告）、美股财报电话会文字稿（公司 IR 页或 `web_search "<公司> earnings call transcript <季度>"`）。
- 摘录原文（英文附中文翻译），每条带来源链接与日期；只摘管理层对下季/全年的数字指引、资本开支、重大项目进展，不加个人推断。
- 输出到 `投研/<代码>/财报/指引-<报告期>.md`。

### 2E. 关注列表维护
- 增删：`file_read` → 合并 → `file_write`，更新 `updated_at`。
- "扫描关注列表"：对每个代码执行 2A/2B，汇总成一份 `投研/关注列表扫描-<日期>.md`。

## 注意事项 / 安全
- 财报数字必须来自一手文件或 akshare / yfinance 当场返回；预期值一律标非一手。
- 美股财年与自然年不一致（苹果 FY 9 月底），表头写"FY2025Q4（自然年 2025-07 至 09）"。
- 不对"超预期为什么不涨"做结论性归因，只列可能因素并标"推断"。
- 关注列表只在本地，不同步到任何服务。

## 如何确认完成
- 对应输出文件已生成，表格每行带来源与日期。
- 关注列表 JSON 可被 `python3 -c "import json; json.load(open('投研/关注.json'))"` 正常解析。
- 回复开头一句话给出最重要的结论（谁、何时、高于/低于预期多少）。

风险提示：本分析仅为信息整理，不构成投资建议。财报数据以公司正式披露文件为准。
