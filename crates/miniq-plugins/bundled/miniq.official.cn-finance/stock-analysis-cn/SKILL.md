# 个股三维分析

## 适用场景
- "贵州茅台这家公司怎么样，帮我分析一下。"
- "宁德时代最近跌这么多，基本面有没有变化？"
- "看看腾讯 00700 的技术面，均线和 MACD 什么状态。"
- "英伟达最近 30 天有什么大新闻？"

不适用：只要数据不要解读（`stock-data-cn`）；问"该不该买/加仓"（本包不提供建议，用条件化框架回答并说明）。

## 前置条件
- 先按 `finance-router` 规范化代码，确认标的唯一。
- 数据由 `stock-data-cn` 取到 `投研/<代码>/data/`：至少需要 `kline-daily-qfq.csv`（≥ 250 个交易日）、`income.csv`、`balance.csv`、`cashflow.csv`、`indicators.csv`、`quote-*.json`。缺哪个补哪个。
- 出图前读 `miniq.official.visual-language/visual-language-core/SKILL.md` 与其 `references/tokens.md`；图表用 `visual-charts`（交互 HTML）或 `data-visualize`（静态 PNG）。
- 分析框架与阈值见 `references/analysis-framework.md`（**写结论前必读**）。

## 步骤

### 1. 确认范围
用户没指定维度时默认三维全做；指定了只做对应维度，但仍附"其他维度未分析"的说明。用 `task_update` 列：取数 → 基本面 → 技术面 → 消息面 → 出图 → 写报告 → 自检。

### 2. 基本面（5 年趋势）
`shell_run` 跑 `python3`，从财务 CSV 计算近 5 个完整年度 + 最新报告期：
- 营收、归母净利润及其同比；毛利率、净利率；ROE（归母口径）；资产负债率；经营现金流净额 / 归母净利润（现金含量）；应收账款 / 营收。
- 估值：PE(TTM)、PB、股息率，与近 5 年自身分位（用 K 线收盘价 × 股本 / TTM 净利润近似，口径写明）。
- 输出 `投研/<代码>/analysis/fundamental.csv`，每列带单位（亿元 / %）。
- 判读按 `references/analysis-framework.md` 的阈值，只描述事实与趋势（"连续 3 年 ROE > 20%"），不打分、不评级。

### 3. 技术面
`shell_run` 跑 `python3`（只用 pandas，不依赖 TA-Lib）：
- MA5/10/20/60/120/250；MACD(12,26,9)；RSI(14)；20 日均量与量比；距 52 周高/低点的百分比；10 日、20 日、60 日涨跌幅。
- 判读：均线多头/空头/缠绕、MACD 金叉死叉与柱体方向、RSI 是否 > 70 或 < 30、放量 / 缩量。
- 输出 `投研/<代码>/analysis/technical.csv`（最近 60 行）与一段文字事实。
- A 股另算"偏离值"：个股 3 日涨跌幅 − 对应基准指数 3 日涨跌幅（主板 ±20%、创业板/科创板 ±30% 触发异常波动公告），只作提示。

### 4. 消息面（近 30 天）
- `web_search` 三次：`"<公司名> 公告"`、`"<公司名> 新闻"`、`"<公司名> 研报"`，限定近 30 天（推算规则：今天往前 30 个自然日）。
- 一手来源优先：巨潮 / 交易所 / SEC；媒体报道标"非一手"。
- 去重：同一事件多家报道合并为一条，保留最早一手来源链接。
- 每条标注：日期、来源、一句话摘要、情绪（利好 / 中性 / 利空，附判断依据，如"业绩预增 50%"→ 利好）。
- 输出 `投研/<代码>/analysis/news.md`，≤ 15 条，按日期倒序。

### 5. 出图
用 `visual-charts`（或 `data-visualize`）生成至少 3 张：
1. 营收与归母净利润 5 年柱线图（结论句标题，如"营收连续 5 年增长，净利润增速 2025 年放缓"）。
2. 收盘价 + MA20/60/250 + 成交量（涨红跌绿，**图例注明"A 股习惯：红涨绿跌"**；美股标的若用户习惯相反则在图例说明）。
3. ROE / 毛利率 / 资产负债率三线图。
每张图底部写"数据来源：xxx，截至 YYYY-MM-DD"。按 `visual-charts` 流程渲染截图自检（中文不缺字、无重叠、对比度达标）。保存到 `投研/<代码>/analysis/charts/`。

### 6. 写报告
`file_write` 写 `投研/<代码>/分析-<YYYY-MM-DD>.md`，结构固定：
1. **一句话概览**（标的、行业、市值、分析截至时间）
2. **关键事实**（3–5 条，每条带数字 + 来源 + 时间）
3. **基本面**（表 + 趋势描述 + 图）
4. **技术面**（指标表 + 状态描述 + 图）
5. **消息面**（事件表，含情绪列）
6. **需要继续核实的问题**（数据缺口、口径分歧、未解释的异常）
7. **数据来源与时间**（逐项列出）
8. **风险提示**（固定段，见文末）

写作规则：事实与推断分开（推断用"倾向于 / 不排除"）；数字千分位 + 单位；同比与环比、净利润与归母净利润不混用；不出现"买入 / 卖出 / 目标价 / 建仓"。

### 7. 自检
- `file_read` 报告，逐个数字对照 `analysis/*.csv`。
- 图表截图用 `view_image` 复核。
- 搜索报告中是否有"建议买入""目标价"等字样（`file_grep`），有则删。

## 注意事项 / 安全
- 公开接口字段变动时回到 `stock-data-cn/references/data-sources.md` 重新探测，不猜。
- 用户问"该不该买"：回答"本包只做信息整理；若您关注 X，可留意 Y 指标是否达到 Z"，并附风险提示。
- 研报目标价只作为"市场观点"引用并标"非一手"，不转述为本报告结论。

## 如何确认完成
- `投研/<代码>/分析-<日期>.md` 存在，8 个章节齐全。
- `analysis/` 下有 fundamental.csv、technical.csv、news.md 与 ≥ 3 张图。
- 每个数字可追溯，报告无任何买卖建议措辞。

风险提示：本分析仅为信息整理，不构成投资建议。市场有风险，投资需谨慎；过往业绩不预示未来表现。
