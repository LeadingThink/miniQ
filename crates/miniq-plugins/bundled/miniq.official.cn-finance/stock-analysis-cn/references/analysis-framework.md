# 个股分析框架与阈值

本文是"方法论 + 阈值 + 避坑"，不是输出模板。阈值用于描述事实（"ROE 连续 3 年高于 15%"），不用于打分或评级。

## 1. 基本面

### 1.1 成长
| 指标 | 口径 | 观察点 |
|---|---|---|
| 营收同比 | 本期 / 上年同期 − 1 | 连续 3 年 > 15% 为高增长；增速逐年下滑需指出 |
| 归母净利润同比 | 归属母公司股东净利润 | 与营收增速背离（利润增速远高于营收）要查原因：毛利率提升 / 费用下降 / 非经常损益 |
| 扣非净利润同比 | 扣除非经常性损益 | 与归母差异 > 20% 时提示非经常项目占比 |

### 1.2 盈利质量
| 指标 | 口径 | 观察点 |
|---|---|---|
| 毛利率 | (营收 − 营业成本) / 营收 | 行业差异大；看趋势和同业，不看绝对值 |
| 净利率 | 归母净利润 / 营收 | — |
| ROE | 归母净利润 / 期末归母净资产（或平均） | > 15% 较高，> 20% 很高；连续性比单年更重要 |
| 经营现金流 / 归母净利润 | 现金含量 | 连续 3 年 < 0.8 提示利润"纸面化"，查应收与存货 |
| 应收账款 / 营收 | — | 逐年上升提示回款压力 |

### 1.3 财务安全
| 指标 | 观察点 |
|---|---|
| 资产负债率 | 非金融企业 > 70% 需指出；金融、地产、公用事业行业口径不同 |
| 流动比率 / 速动比率 | < 1 提示短期偿债压力 |
| 有息负债 / 净资产 | 与利息覆盖倍数一起看 |
| 商誉 / 净资产 | > 30% 提示减值风险 |

### 1.4 估值
| 指标 | 口径 | 观察点 |
|---|---|---|
| PE(TTM) | 市值 / 最近 4 季归母净利润 | 与自身 5 年分位、同业中位数对比；亏损企业不适用 |
| PB | 市值 / 归母净资产 | 重资产、金融行业更适用 |
| PEG | PE / 未来增速 | 增速取历史 3 年 CAGR，注明假设 |
| 股息率 | 近 12 个月分红 / 市值 | 与分红率（分红 / 净利润）一起看持续性 |

估值分位计算：对过去 5 年每个交易日用"收盘价 × 总股本 / 当时 TTM 净利润"近似，当前值在序列中的百分位。总股本变动大（增发、回购）时注明误差。

### 1.5 避坑
- 财年 ≠ 自然年：港股/美股公司财年各异（苹果 9 月底、微软 6 月底、阿里 3 月底），同比必须用同一财年定义；跨公司比较按自然季度对齐或用 TTM。
- 单位：A 股财报单位"元"，媒体常用"亿元"；港股"港元"与"人民币"并存；美股"百万美元"。表头统一写明。
- 会计准则变更（新收入准则、租赁准则）会造成口径断层，年报附注有说明。

## 2. 技术面

### 2.1 指标计算（pandas 实现）
```python
import pandas as pd
df = pd.read_csv('kline-daily-qfq.csv')  # 列名按 akshare 输出：日期/开盘/收盘/最高/最低/成交量/成交额
c = df['收盘']
for n in (5, 10, 20, 60, 120, 250):
    df[f'MA{n}'] = c.rolling(n).mean()
ema12, ema26 = c.ewm(span=12, adjust=False).mean(), c.ewm(span=26, adjust=False).mean()
df['DIF'] = ema12 - ema26
df['DEA'] = df['DIF'].ewm(span=9, adjust=False).mean()
df['MACD'] = (df['DIF'] - df['DEA']) * 2
delta = c.diff()
gain = delta.clip(lower=0).ewm(alpha=1/14, adjust=False).mean()
loss = (-delta.clip(upper=0)).ewm(alpha=1/14, adjust=False).mean()
df['RSI14'] = 100 - 100 / (1 + gain / loss)
df['VOL_MA20'] = df['成交量'].rolling(20).mean()
df['量比'] = df['成交量'] / df['VOL_MA20']
```

### 2.2 判读
| 状态 | 判定 |
|---|---|
| 均线多头排列 | MA5 > MA10 > MA20 > MA60 且均向上 |
| 均线空头排列 | 反之 |
| 均线缠绕 | MA5/10/20 间距 < 2% |
| MACD 金叉 / 死叉 | DIF 上穿 / 下穿 DEA；柱体由负转正为动能改善 |
| RSI 超买 / 超卖 | > 70 / < 30；只是统计状态，不是反转信号 |
| 放量 | 量比 > 1.5；缩量 < 0.7 |
| 52 周位置 | (现价 − 52 周低) / (52 周高 − 52 周低) |
| 阶段涨跌幅 | 10 日 > 15% 或 20 日 > 25% 提示短期涨幅较大 |

### 2.3 A 股异常波动提示
偏离值 = 个股 N 日涨跌幅 − 基准指数 N 日涨跌幅。沪深主板连续 3 日偏离 ±20%、创业板/科创板 ±30%、北交所 ±40%，ST 股 ±12%，触发交易所"异常波动"公告。基准：60 开头→上证指数 `sh000001`，00→深证综指 `sz399106`，30→创业板综 `sz399102`，688→科创 50 `sh000688`。

### 2.4 避坑
- 复权：技术指标必须用前复权数据；除权日不复权会出现假跳空。
- 美股盘前盘后数据不计入日 K。
- 停牌日不在 K 线中，"连续 N 日"按交易日计。

## 3. 消息面

### 3.1 来源分级
| 级别 | 来源 | 处理 |
|---|---|---|
| 一手 | 巨潮资讯、交易所公告、SEC 文件、公司官网公告、统计局/央行 | 直接引用，标日期 |
| 二手 | 财经媒体（财新、财联社、华尔街见闻、Bloomberg、Reuters） | 标媒体名 + 日期 + "需核实原文" |
| 三手 | 自媒体、论坛、研报摘要转载 | 只作线索，不进报告正文 |

### 3.2 情绪判断依据
| 情绪 | 典型事件 |
|---|---|
| 利好 | 业绩预增、重大合同、回购、高管增持、新品获批、政策扶持 |
| 利空 | 业绩预减、减持计划、监管问询/处罚、诉讼、商誉减值、关键客户流失 |
| 中性 | 人事变动（无负面背景）、常规公告、行业例行数据 |

同一事件不同媒体解读相反时，列出双方观点并标"存在分歧"。

### 3.3 避坑
- 研报目标价是机构观点，不是事实；只作"市场观点"引用。
- "拟""计划""预计"类公告尚未落地，标注"进行中"。
- 并购重组事项：标的营收 / 净利润 / 对价 / 支付方式 / 业绩承诺 / 进展阶段都要列出，商誉 = 对价 − 标的净资产。
