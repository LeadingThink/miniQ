# 尽调报告模板与公开渠道

## 1. 公开渠道清单（境内企业）

| 维度 | 一手 / 官方 | 备选公开页 | 备注 |
|---|---|---|---|
| 工商登记 | 国家企业信用信息公示系统 `https://www.gsxt.gov.cn/` | 企查查 MCP（已启用时）；企查查 / 天眼查公开页 | 公示系统有验证码，由用户操作 |
| 股权 / 实控人 | 公示系统"股东及出资信息"；上市公司看年报"股东情况" | 企查查 MCP 股权穿透工具 | 多层穿透需逐层查 |
| 高管 | 公示系统"主要人员" | 官网团队页、LinkedIn / 脉脉公开页 | 只记录职务与公开履历 |
| 变更记录 | 公示系统"变更信息" | 企查查 MCP | 关注近 2 年法人 / 股东 / 注册资本变更 |
| 行政处罚 | 信用中国 `https://www.creditchina.gov.cn/`；公示系统"行政处罚" | 各部委 / 地方监管局官网 | — |
| 经营异常 / 严重违法 | 公示系统 | 企查查 MCP | — |
| 司法 | 裁判文书网 `https://wenshu.court.gov.cn/`；执行信息公开网 `http://zxgk.court.gov.cn/`；人民法院公告网 `https://rmfygg.court.gov.cn/` | `web_search "<全称> 判决书 / 被执行"` | 裁判文书网需登录检索 |
| 税务 | 国家税务总局"重大税收违法失信案件" | 各省税务局 | — |
| 知识产权 | 国家知识产权局 `https://www.cnipa.gov.cn/`；商标网 | `web_search "<全称> 专利"` | — |
| 资质 | 高新技术企业认定网、各行业许可公示 | 官网 | 以官方名单为准 |
| 招投标 | 中国政府采购网 `http://www.ccgp.gov.cn/`、各省公共资源交易平台 | — | 中标记录反映业务真实性 |
| 招聘 | BOSS 直聘 / 智联 / 猎聘公开页 | 官网招聘页 | 在招岗位数与城市 |
| 舆情 | 官方公告、主流媒体 | 黑猫投诉 `https://tousu.sina.com.cn/`、自媒体 | 自媒体只作线索 |
| 上市公司补充 | 巨潮资讯、交易所、港交所披露易 | — | 交给 `stock-data-cn` |

## 3. 风险信号参考（只作提示，不作结论）

| 信号 | 含义 |
|---|---|
| 近 1 年法定代表人 / 大股东频繁变更 | 控制权不稳定 |
| 注册资本高但实缴极低 | 偿付能力依据不足 |
| 参保人数连续下降 | 经营收缩 |
| 被执行 / 失信 / 限高记录 | 偿付风险、合规风险 |
| 经营异常名录（地址失联、未年报） | 可能已停止经营 |
| 关联企业大量注销 | 需核实业务承接关系 |
| 招聘大量销售岗、无技术岗，但自称技术公司 | 业务与宣传不符 |
| 集中投诉（欠薪、退款） | 现金流或诚信问题 |
