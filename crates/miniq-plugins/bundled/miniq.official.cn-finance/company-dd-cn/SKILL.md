# 企业尽调报告

## 适用场景
- "我们准备跟 XX 科技签 200 万的合同，帮我做一份尽调。"
- "XX 公司给我发了 offer，帮我查查这家公司靠不靠谱。"
- "投资前把 XX 的股权结构、高管背景、诉讼情况整理成报告。"
- "这家供应商有没有被执行或行政处罚记录？"

不适用：境外企业（用 SEC / 公司注册处公开信息，另案处理）；对个人做背景调查（涉及隐私，拒绝）；上市公司股价与估值（`stock-analysis-cn`）。

## 前置条件
- 企业全称或 18 位统一社会信用代码；只有简称时先 `web_search "<简称> 有限公司 统一社会信用代码"` 确认，多候选 `ask_user`。
- 工商渠道：先 `mcp_call {server:"qcc-company", tool:"tools/list"}` 探测企查查 MCP 是否启用（随 `miniq.official.cn-collab` 包提供，需用户在浏览器完成 OAuth）。**工具名与参数以 tools/list 返回为准**；未启用或 401 时走公开渠道降级，并在报告中标注"工商信息来自公开页面，未经企查查核验"。
- 公开渠道与报告章节模板见 `references/dd-template.md`。
- 排版读 `miniq.official.visual-language/cn-typography/SKILL.md`。
- 落盘：`<工作区>/投研/尽调/<企业简称>/`。

## 步骤

### 1. 明确目的与深度
`ask_user`（一次问完）：尽调目的（签约 / 入职 / 投资 / 供应商准入）、关注重点（偿付能力 / 合规 / 实控人 / 经营稳定性）、时限。目的决定"风险"章节的权重：签约重偿付与诉讼，入职重经营与社保，投资重股权与财务。

### 2. 基本信息与股权（工商）
- 有 MCP：按 tools/list 调企业简介、工商登记、股东、实际控制人、受益所有人、主要人员、对外投资、变更记录、行政处罚、经营异常等工具。严格引用返回字段；为空写"暂无记录"。
- 无 MCP：`web_fetch` 国家企业信用信息公示系统 `https://www.gsxt.gov.cn/`（有验证码时改 `browser_automation` 由用户完成验证，不要代填）；企查查 / 天眼查公开页 `web_search "<全称> 企查查"` 可读到的部分；标"公开页面，未核验"。
- 整理：注册资本（实缴 vs 认缴）、成立日期、登记状态、法定代表人、股东与持股比例（画一层股权穿透表）、历史变更（法人 / 股东 / 注册资本 / 名称变更的日期）。

### 3. 业务与经营
- 官网：`web_fetch` 首页与"关于我们"，摘产品线、客户案例、资质证书。
- 招聘：`web_search "<全称> 招聘"`（BOSS 直聘 / 智联公开页），看在招岗位数量、城市、薪资区间——反映扩张或收缩。
- 知识产权：`web_search "<全称> 专利"`，国家知识产权局公开检索页。
- 资质：高新技术企业、ISO、行业许可证，以官方公示名单为准。
- 每条事实带 URL 与访问日期。

### 4. 财务（能拿到多少写多少）
- 上市公司：交给 `stock-data-cn` 取三表，引用其输出。
- 非上市：企查查 MCP 的年报 / 财务工具（如有）；工商年报里的"企业资产状况信息"（部分企业选择不公示）；标"自愿公示，未经审计"。
- 社保参保人数（工商年报）是经营规模的重要旁证，列出近 3 年变化。

### 5. 风险（司法与监管）
- 裁判文书：中国裁判文书网 `https://wenshu.court.gov.cn/`（需登录检索，降级为 `web_search "<全称> 判决书"`）；执行信息公开网 `http://zxgk.court.gov.cn/`（被执行人 / 失信被执行人 / 限制高消费）。
- 行政处罚：信用中国 `https://www.creditchina.gov.cn/`。
- 税务：国家税务总局重大税收违法案件公告。
- 股权冻结、动产抵押、清算信息：工商公示系统。
- 每条风险写：类型 | 日期 | 对方 | 金额 | 状态 | 来源链接。无记录写"公开渠道未检索到"，不写"无风险"。

### 6. 舆情（近 12 个月）
- `web_search "<全称>"` 与 `"<全称> 投诉"`、`"<全称> 裁员"`、`"<全称> 欠薪"`；黑猫投诉等平台公开页。
- 去重、按日期倒序、标情绪（正面 / 中性 / 负面）与来源级别（官方 / 媒体 / 自媒体），自媒体只作线索。

### 7. 写报告与排版
- `file_write` 写 `投研/尽调/<简称>/尽调报告-<YYYY-MM-DD>.md`，章节按 `references/dd-template.md`：摘要（结论先行：核心发现 3–5 条 + 建议关注点）→ 基本信息 → 股权与实控 → 高管 → 业务与经营 → 财务 → 风险 → 舆情 → 数据来源与时间 → 风险提示。
- 用 `cn-typography` 排成 HTML/PDF，主色选黛蓝 #2B4C7E；金额千分位 + 单位；日期 `YYYY-MM-DD`；中西文间空格。
- 截图自检：中文无方块、表格不截断。

## 注意事项 / 安全
- 只处理企业公开信息；涉及自然人身份证号、手机号、住址等一律不收集、不写入报告。
- 不代用户绕过验证码或登录墙；需要登录的页面由用户操作。
- 不下"可以合作 / 不可合作"的结论，只列事实与需关注的点；"风险"章节用"检索到 / 未检索到"措辞。
- 报告若要发给第三方（对外分享属写操作），先 `ask_user` 确认并提醒脱敏。
- 企查查数据有授权与使用条款，报告注明数据来源，不批量爬取。

## 如何确认完成
- 报告 10 个章节齐全，每条事实带来源与访问日期。
- 工商数据注明"企查查核验"或"公开页面未核验"。
- HTML/PDF 排版自检通过，路径已告知用户。

风险提示：本分析仅为信息整理，不构成投资建议或法律意见；企业信息以官方登记与公示为准。
