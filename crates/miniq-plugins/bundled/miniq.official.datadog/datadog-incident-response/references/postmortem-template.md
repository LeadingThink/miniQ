# 复盘模板（无责）

## 概要
- 事件名称 / 严重级别 / 持续时间 / 影响范围（用户数、请求失败率、营收影响如可得）

## 时间线（UTC+8）
| 时间 | 事件 | 来源 |
|---|---|---|
| | 首次异常 | 指标/日志 |
| | 检测（告警触发） | 监控 ID |
| | 响应（开始处理） | incident |
| | 缓解 | 操作记录 |
| | 恢复 | 指标 |

## 根因
- 直接原因 / 触发因素 / 促成因素（监控缺口、流程、设计）

## 做得好的 / 待改进的

## 行动项
| 项 | 类型（预防/检测/缓解） | 负责人 | 截止日期 | 跟踪链接 |

## 关键指标
- MTTD（检测时长）、MTTA（确认时长）、MTTR（恢复时长）
