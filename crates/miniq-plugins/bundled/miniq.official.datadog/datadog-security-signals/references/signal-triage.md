# 安全信号分诊指南

## 判定分类
- **真阳性**：确有恶意或违规行为（如异常地点登录后提权、已知恶意 IP 成功访问）。
- **误报**：规则逻辑命中了正常行为（如运维脚本、扫描器白名单）。
- **良性真阳性**：行为确实发生，但属于授权的正常活动（如渗透测试、变更窗口）。

## 分诊步骤
1. 看规则：检测意图是什么，触发条件是什么。
2. 看实体：用户或服务账号的常见行为、IP 信誉（IOC）、地理位置是否异常。
3. 看上下文：前后 1 小时同一实体的其他信号与日志，是否有后续动作（提权、横向移动、数据外传）。
4. 看变更：是否与已知的发布、运维窗口吻合（审计日志）。
5. 给出判定、置信度和建议动作。

## 处置建议模板
- 真阳性：隔离或禁用账号、轮换凭据、拦截 IP（AAP denylist，需确认）、保全证据、升级为 incident 或 case。
- 误报：添加精确抑制（规则 ID + 实体 + 有效期），并记录原因。
- 规则噪声大：调整阈值或分组字段，先在测试规则上验证。

## 严重级别优先级
critical > high > medium > low > info。同一实体涉及多条中危信号时，应整体升级处理。
