# 模板搜索与填充规则

## 1. 搜索关键词写法
格式：`<用途> + <主题> + <风格>`。模板库以英文标注为主，建议中英文各试一次。

| 用户说法 | 推荐 generalQuery |
|---|---|
| 咖啡店开业海报 | `coffee shop grand opening poster` |
| 生日派对邀请函 | `birthday party invitation` |
| 招聘传单 | `hiring flyer modern` |
| 小红书封面 | `social media post cover 3:4 lifestyle` |
| 朋友圈九宫格活动图 | `instagram post square event` |
| 名片 | `business card minimal` |
| 课程表 / 菜单 | `class schedule` / `restaurant menu` |

放宽顺序：
1. 去掉风格词
2. 去掉主题词
3. 只留用途词（poster / flyer / invitation）

## 2. 分页
- 纯文本展示：`pageSize = 10`；有画廊组件时可以用 24。
- “再来一些”：保持关键词不变，`startIndex` 加上一个 `pageSize`。

## 3. fill_text 的 description 写法
按版面层级逐条写明，不要只给一句话：
```
主标题：周末咖啡市集
副标题：30+ 精品咖啡摊位
时间：6月15日 10:00–18:00
地点：滨江公园草坪
行动号召：免费入场
```

规则：
- 文案长度要和模板占位接近。主标题中文建议 ≤ 12 字，英文 ≤ 5 个词，否则容易溢出。
- 用户没有提供的信息不要编造，用占位符（如“[地址]”）标出，并在交付时提醒用户补充。
- `generalQuery` 只写用途，不写手机号、邮箱、住址等个人信息。

## 4. replace_image 的 description 写法
- 明确要换哪一个元素，例如“把右上角的甜点照片换成拉花拿铁俯拍，暖色木桌背景”。
- 一次调用只换一个元素；有多处要换时依次调用，每次使用最新的 `documentURN`。
- 不支持直接放用户自己的照片。需要用自己的照片时，请用户打开编辑器链接手动替换。

## 5. 背景色
- 优先使用品牌主色；没有时，根据模板主色给出 2–3 个协调色供用户选。
- 深色背景配浅色文字；背景色与正文文字的对比度应不低于 4.5:1。

## 6. 动画
- 适合用于社媒短帖、电子邀请函；打印物料不要加动画。
- 加过动画的文档改为 MP4/GIF 交付，由编辑器导出。

## 7. 交付检查清单
- [ ] 文字无溢出、无缺字（中文字体）
- [ ] 日期、地点、联系方式与用户提供的完全一致
- [ ] 已提供编辑器链接和 PDF 链接
- [ ] 已提醒约 12 小时后清理
