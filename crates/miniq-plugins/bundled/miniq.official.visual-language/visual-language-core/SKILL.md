# 视觉语言基线

## 适用场景
- 任何会产出"给人看"的文件：网页、图表、看板、信息图、海报、幻灯片、PDF 报告、社交封面。
- 其他技能（`visual-charts`、`data-report`、`infographic-cn`、`poster-cn`、`web-deck-cn`、`creative-*`）在动手前先读本技能，再读各自的专项规则。
- 用户说"好看一点""专业一点""有设计感""别那么 AI 味"时，按本技能的约束重做。

## 一、设计令牌（直接复制到产物中）

完整 CSS 见 `references/tokens.md`。要点：

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#FAFAF8` | `#141516` | 页面底色（暖白，不是纯白） |
| `--fg` | `#1F2328` | `#E6E6E3` | 正文 |
| `--muted` | `#6B7280` | `#9CA3AF` | 次要文字、单位、来源 |
| `--card` | `#FFFFFF` | `#1D1F21` | 卡片表面 |
| `--line` | `#E5E7EB` | `#2A2D31` | 分割线、网格线 |
| `--primary` | 见下方主色板 | 同 | 唯一强调色 |
| `--up` / `--down` | `#2E8B57` / `#C8323B` | 同 | 涨跌、正负 |
| `--s1`…`--s6` | 固定 6 色 | 同 | 数据系列 |

### 主色板（中国传统色，任选一个作为 `--primary`）

| 名称 | 色值 | 适合 |
|---|---|---|
| 黛蓝 | `#2B4C7E` | 商务、科技、报告（默认） |
| 松绿 | `#2E8B57` | 环保、健康、增长 |
| 朱砂 | `#C8323B` | 节庆、促销、警示 |
| 杏黄 | `#E8A33D` | 教育、生活、温暖 |
| 青灰 | `#6C7A89` | 极简、文艺 |
| 绛紫 | `#6B3E8C` | 品牌、艺术、高端 |

规则：一页只用一个主色。主色用于标题强调、主按钮、关键数据、当前选中项。其余全部用中性灰阶。

### 数据系列色板（固定顺序，不可改）

`--s1 #2B4C7E` `--s2 #E8A33D` `--s3 #2E8B57` `--s4 #C8323B` `--s5 #6B3E8C` `--s6 #6C7A89`

同一实体（如"华东区"）在所有图中保持同一颜色。超过 6 类时合并为"其他"。

## 二、字体与排版

```css
font-family: "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", "Source Han Sans SC", "Helvetica Neue", Arial, sans-serif;
```

| 层级 | 字号 | 字重 | 行高 |
|---|---|---|---|
| 页面标题 | 32px | 600 | 1.3 |
| 章节标题 | 22px | 600 | 1.4 |
| 小标题 | 17px | 600 | 1.5 |
| 正文 | 16px | 400 | 1.75 |
| 辅助 | 13px | 400 | 1.6 |
| 大数字 | 40–56px | 600 | 1.1，`font-variant-numeric: tabular-nums` |

- 中文不用斜体、不用全大写、不用字间距挤压。
- 中西文之间留一个空格："销售额 1,200 万元"。
- 标点用全角："，。：；！？"；省略号用"……"；破折号用"——"。
- 段落之间用 1em 段距，不用首行缩进。
- 一行正文控制在 40–50 个汉字以内（约 680–800px 宽）。

## 三、布局与留白

- 页面最大宽度 1080px（报告 820px），居中。
- 页边距：桌面 48px，移动端 24px。
- 卡片：内边距 24px，圆角 12px，1px `--line` 描边，无阴影或仅 `0 1px 2px rgba(0,0,0,.04)`。
- 模块间距 40px；标题与正文间距 16px。
- 网格：12 列或 `auto-fit, minmax(260px, 1fr)`。
- 一屏只有一个视觉焦点。

## 四、图表与数据

- 标题写结论："华东贡献 62% 的增长"，不写"各地区销售额"。
- 副标题写口径与时间："按发货日期统计，2026-01 至 2026-09"。
- 底部注明来源与截至日期。
- 条形图、面积图 y 轴从 0 开始。折线图可不从 0，但不夸大波动。
- 类别按数值排序（时间轴除外），超过 8 类取 Top 7 + 其他。
- 饼图/环图 ≤ 5 扇区，否则改堆叠条。
- 禁止：3D、双 y 轴（除非必要且明确标注）、彩虹色、渐变填充、装饰性图标堆砌。
- 涨跌：`--up` 松绿 / `--down` 朱砂，并配 ▲ ▼ 符号；不只靠颜色。注意：国内股市习惯"红涨绿跌"，金融场景按用户所在市场约定，并在图例中说明。

## 五、禁用的"AI 味"模式

- 紫色渐变背景、玻璃拟态卡片堆叠、霓虹发光。
- 每段开头一个 emoji。
- 没有意义的图标网格。
- 标题全是四字词组排比。
- 内容不足却用大量装饰填充。

## 六、渲染自检（必做）

1. 写出 HTML 后，用 `shell_run`（`runInBackground: true`）启动本地服务：`python3 -m http.server 0 --directory <目录>`，或使用 `visual-charts` 的 `viz.py serve`。读取端口。
2. `browser_automation`：`open` 地址 → `wait 800` → `screenshot`；再 `resize` 到 390×844 截一张移动端。
3. `view_image` 逐项核对：
   - 中文无方块、无乱码。
   - 文字不重叠、不截断、不溢出容器。
   - 标题、卡片、图表左对齐在同一条线上。
   - 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1。
   - 深色模式切换正常（可用 `browser_automation` 的 `press` 模拟或在 CSS 里临时强制）。
   - 只有一个主色；数据系列颜色一致。
4. PNG/PDF 产物直接 `view_image` / `view_pdf` 核对相同项目。
5. 不合格就修改再截图，最多三轮；仍不合格在交付时如实说明。

## 如何确认完成
产物使用了本技能的令牌与字体栈；截图自检通过；回复中附文件路径与一句话说明采用的主色和版式。
