# 五种风格方向与底图提示词模板

配合 `SKILL.md` 步骤 2 使用。每个模板分三段：**风格基底**（固定）+ **主题意象**（按用户内容替换 `{…}`）+ **约束尾句**（固定，必须保留）。主色来自 `../../visual-language-core/SKILL.md` 的传统色板。

## 约束尾句（所有风格通用，附在提示词末尾）

> 画面中不出现任何文字、字母、数字、水印、Logo、二维码。{文字预留区} 保持干净留白或低细节背景。构图简洁，主体不超过画面三分之一，{比例} 比例。

文字预留区示例：`上三分之一`、`左半边`、`底部四分之一`、`中央 40% 区域`。
比例按用途：公众号封面 `2.35:1 横向`、小红书 `3:4 竖向`、朋友圈 `9:16 竖向`。

## 1. 国风 · 水墨留白

- 主色：黛蓝 `#2B4C7E` 或 朱砂 `#C8323B`（节庆）
- 文字：深墨色 `#1F2328`，不加遮罩；标题可用宋体感更强的字重 600
- 适合：读书会、茶会、文化讲座、传统节日、博物馆活动

```
中国水墨画风格，宣纸质感的米白色背景，{主题意象：远山与孤舟 / 一枝红梅 / 竹影 / 太湖石}，
笔触克制，大面积留白，淡墨渲染，一点{朱砂红 / 黛蓝}点缀，静谧、雅致，无人物。
```

---

## 2. 极简 · 几何色块

- 主色：杏黄 `#E8A33D`、松绿 `#2E8B57` 或品牌色
- 文字：主色块上白字，浅底上深字；标题可大到 120px
- 适合：小红书知识类封面、课程、工具教程、招聘

```
极简平面设计，{主色名称与色值} 与暖白色 #FAFAF8 的大色块分割，
{主题意象：抽象的书本 / 几何台阶 / 单个圆与直线 / 简化的电脑屏幕轮廓}，
扁平无渐变，边缘锐利，色彩不超过三种，哑光质感。
```

---

## 3. 科技 · 深色光线

- 主色：黛蓝 `#2B4C7E`（线条用 `#7FA7E0` 提亮）
- 文字：白字，不需要额外遮罩；避免霓虹紫、避免玻璃拟态
- 适合：发布会、技术直播、AI/数码产品、线上峰会

```
深蓝黑色 #0F1620 背景，{主题意象：细线构成的网格地平线 / 单一光束 / 粒子组成的球体 / 电路纹理}，
线条纤细，冷色单色调，光线克制，无霓虹紫色、无彩虹渐变，画面下半部较暗。
```

---

## 4. 手绘 · 温暖插画

- 主色：杏黄 `#E8A33D` 或 松绿 `#2E8B57`
- 文字：深棕 `#3B2F2F` 或深灰，底图偏亮不加遮罩
- 适合：亲子活动、社区市集、校园、公益、生活方式

```
温暖的手绘插画风格，蜡笔与水彩质感，奶油色背景，
{主题意象：市集帐篷与气球 / 植物与阳光 / 咖啡杯与书 / 简笔的街道}，
色彩柔和，不超过四种颜色，{杏黄 / 松绿} 为主色，画面上方留出大片天空。
```

---

## 5. 商务 · 影像质感

- 主色：黛蓝 `#2B4C7E` 或 青灰 `#6C7A89`
- 文字：白字 + 顶部/底部深色渐变遮罩（`.scrim`）
- 适合：行业论坛、年会、企业招聘、融资发布、路演

```
商业摄影风格，{主题意象：现代建筑玻璃幕墙的仰视角 / 空旷的会议厅 / 城市天际线清晨薄雾 / 整齐的办公桌面局部}，
低饱和冷色调，浅景深，画面干净，无人物面部特写，整体偏暗以便叠加浅色文字。
```

## 直播预告海报附加要素

无论哪种风格，直播预告必须包含以下文字块（HTML 层）：

| 要素 | 字号（1080 宽） | 位置建议 |
|---|---|---|
| "直播预告" 标签 `.tag` | 28px | 标题上方 |
| 主标题 | 88–96px | 上三分之一 |
| 嘉宾 / 主播 + 头衔 | 32px / 26px | 标题下方；头像用用户提供的图片，圆形裁切 |
| 时间 `10 月 18 日（周六）19:30` | 40px，`tabular-nums` | 中下部，最醒目的次要信息 |
| 平台（视频号 / 抖音 / B 站 / 腾讯会议） | 28px | 时间下一行 |
| 二维码 + "扫码预约" | 220×220，文字 24px | 右下 |

| 科技、AI、发布、互联网、数码 | 3 科技 |
