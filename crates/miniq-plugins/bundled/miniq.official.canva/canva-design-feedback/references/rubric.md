# 设计评审维度与判断要点

## 严重度口径
- **高**：影响信息传达或无法阅读（主信息找不到、文字看不清、错别字出现在标题、内容错误）。
- **中**：明显不专业或不一致（多种强调色、对齐混乱、间距不均、单页信息过载）。
- **低**：细节打磨（标点、个别字距、次要元素微调）。

## 1. 视觉层级
- 眯眼看缩略图：第一眼落在哪里？是否是最重要的信息？
- 标题/副标题/正文是否有至少两级明显差异（字号比 ≥ 1.3，或粗细、颜色区分）。
- 同一页是否有多个“争抢注意力”的元素（多张大图、多处粗体）。

## 2. 布局与间距
- 元素是否对齐到共同的边或中线；有无“差几像素”的错位（只读事务中的 `left/top` 可辅助核对）。
- 页边距是否一致；内容是否贴边或越出安全区（社媒图四周建议留 ≥ 5% 的边距）。
- 留白是否平衡：一侧拥挤、一侧空旷。
- 相关元素靠近、无关元素分开（亲密性）。

## 3. 文案与信息
- 每页是否只有一个核心要点；幻灯片正文建议 ≤ 6 行、每行不宜过长。
- 错别字、标点混用（中英文标点）、全半角、数字格式不统一。
- 术语、缩写是否适合受众；行动号召（CTA）是否清楚。

## 4. 一致性（多页设计）
- 同级标题的字号、颜色、位置在各页是否一致。
- 配色是否控制在主色 + 1–2 个辅助色。
- 图标、图片风格（写实/插画/线性）是否统一。

## 5. 可读性与对比度
- 投影场景正文目测不小于 24pt 等效；手机竖屏图正文不宜过小。
- 图片上压字：是否有蒙层、描边或纯色底。
- 对比度只能目测时写“疑似不足”；WCAG 参考：正文 4.5:1，大字 3:1。

## 6. 无障碍
- 信息是否只靠颜色区分（如红绿表示涨跌），应辅以符号或文字。
- 图表是否有标题与数据标签。
- 动效/闪烁元素是否过多（仅能从用户描述或导出结果判断）。

## 7. 适合场景
- 演示文稿 ≠ 社媒图 ≠ 印刷品：投影需大字少字；社媒需在缩略图尺寸下仍可辨识；印刷需注意出血与分辨率。
- 尺寸与平台是否匹配（例如 Instagram 帖子应为 1:1 或 4:5）。

## 常见“可由 API 改 / 需手动”对照
| 建议 | 归类 |
|---|---|
| 改字、改错别字、精简文案 | API：`replace_text` / `find_and_replace_text` |
| 字号、加粗、斜体、颜色、对齐、行距 | API：`format_text`（响应式页面不支持） |
| 换图、删元素、移动、缩放 | API：`update_fill` / `delete_element` / `position_element` / `resize_element` |
| 换字体族、加新文本框、改背景色/渐变 | 需手动 |
| 调整页面顺序、增删页 | 需手动 |
| 改形状颜色/边框、透明度、动画、编组 | 需手动 |
