# Canva 设计评审（只读）

## 触发场景
- “帮我看看这张海报哪里不好”“评审一下这份 PPT”“这页幻灯片有什么问题”。
- “怎么让这个设计更专业/更好读”“给点修改意见”。
- 用户只要意见，不要求改动。若用户要“直接帮我改”，评审后转 `canva-edit-design` 或 `canva-implement-feedback`。

## 前置条件
- `canva` MCP 已启用并登录（见 `canva-design-studio` 的前置条件）。
- 能查看该设计（至少有查看权限）。
- 评审维度与打分口径见 `references/rubric.md`。

## 可用信息源（先认清局限）
| 来源 | 能拿到 | 拿不到 |
|---|---|---|
| `get-design` | 标题、页数、链接 | 内容 |
| `get-design-thumbnail` / `get-design-pages` | 每页渲染图（判断层级、配色、对比度、留白的**主要依据**） | 精确数值 |
| `get-design-content` | 各页文字 | 颜色、字体、字号、位置 |
| 只读事务：`start-editing-transaction` → 读 `richtexts`/`fills` → **必定** `cancel-editing-transaction` | 元素位置、尺寸、文字；偶尔有样式 | 颜色/字体经常缺失 |

原则：颜色、字体、对比度结论以缩略图为准；payload 里没有的具体色值、字体名不得写成事实，只能写“目测偏浅灰”之类。

## 分步流程
1. **定位设计**：按 `canva-design-studio/references/design-resolution.md`（短链 → `resolve-shortlink`；完整 URL 取 `/design/` 后的 ID；`D` 开头的 ID 直接用，不要拿去搜索；只有名称 → `search-designs`，多个结果时让用户选）。
2. **了解用途**：若用户没说投放场景（投影、手机竖屏、打印）和受众，一句话问清；不问也可以，但要在报告里写明按什么场景评估。
3. **读取设计**：
   - `get-design`（`design_id`）→ 标题、页数。
   - `get-design-thumbnail` 或 `get-design-pages` → 每页图；用 `view_image` 或直接查看返回图像。
   - `get-design-content` → 全文，用于检查错别字、冗长、术语、每页主旨。
   - 需要对齐/间距细节时开只读事务，读完立即 `cancel-editing-transaction`。
4. **逐维度评估**（见 `references/rubric.md`）：视觉层级、布局间距、文案信息、一致性、可读性与对比度、无障碍、是否适合投放场景。与设计类型无关的维度跳过。
5. **排序**：每条问题标注严重度 高/中/低，并写清页码 + 元素 + 具体改法。先挑出 3–5 条影响最大的，再按页列细节。
6. **标注可执行性**：对每条建议注明“可由 API 改”（文字内容、字号、粗细、斜体、颜色、对齐、行距、换图、移动、缩放、删除）或“需手动”（换字体族、加文本框、改背景、增删重排页、动画、形状颜色）。边界以 `canva-edit-design/references/limits.md` 为准。
7. **收尾**：询问是否由你执行可 API 修改的项（转 `canva-edit-design`）。

## 质量检查
- 每条意见都能对应到缩略图或文字中实际看到的内容，禁止“让它更吸睛”这类空话。
- 每个问题都配一个具体改法（改成多少、换成什么、移到哪里）。
- 开过的事务必须已取消；本技能全程不调用 `commit-editing-transaction`。
- 对比度只能目测时，写“疑似不足，建议用对比度工具核实（正文目标 ≥ 4.5:1）”。

## 失败回退
- 缩略图拿不到：用 `export-design`（`png`）导出后 `curl -L -o` 下载再 `view_image`；仍不行则只做文案评审，并说明视觉部分无法评估。
- 无权限/找不到设计：请用户确认链接或把设计分享给当前账号。
- 页数很多（>20）：先评审前 10 页和结构，问用户是否继续。

## 输出交付格式
```
## 设计评审 —「<设计标题>」（共 N 页，按 <场景> 评估）

### 优先处理
1. [高] 第 2 页 — 标题与正文字号、粗细相同，视线无落点。
   改法：标题放大到约 1.5 倍并加粗。（可由 API 改）
2. [高] 第 4 页 — 浅色照片上的白色说明文字难以辨认。
   改法：给图片加深色蒙层，或把说明移到纯色色块上。（需手动）

### 逐页意见
**第 1 页** — [中] 出现三种强调色，建议统一为一种。[低] “登陆” → “登录”。
**第 2 页** — …

### 做得好的地方
- 页边距统一；封面主图有冲击力。

需要我把标注“可由 API 改”的项直接改掉吗？
```
