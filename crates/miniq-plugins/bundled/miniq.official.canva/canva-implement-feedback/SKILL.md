# Canva 按评论落实修改

## 触发场景
- “把这份 PPT 上的评论都处理一下”“按审阅意见改设计”“落实大家的反馈”。
- 设计已发给同事审阅，评论散落在各页，需要汇总并执行。

## 前置条件
- `canva` MCP 已启用并登录；账号对设计有编辑权限、能读评论。
- 熟悉 `canva-edit-design` 的事务协议与 `canva-edit-design/references/limits.md` 的能力边界（分诊前必须对照）。
- 分诊口径与评论回复模板见 `references/triage.md`。

## 分步流程
1. **定位设计**：按 `canva-design-studio/references/design-resolution.md`。
2. **读取全部反馈**：
   - `list-comments`（`design_id`）→ 所有评论线程；分页参数（如 `continuation`）存在时要翻完。
   - 有回复的线程逐个 `list-replies`（`design_id`、`thread_id`），拿到完整讨论和最终结论。
   - `get-design-content` → 各页当前文字；`get-design-thumbnail` → 页面外观，用于定位评论所指元素。
3. **分诊**（每个线程归一类，规则见 `references/triage.md`）：
   - **可执行**：API 能做且意图可合理推断。积极理解，例如“标题再有力一点”就直接改写，不要标成“含糊”。
   - **需手动**：API 做不到（换字体族、加文本框、改背景、增删重排页、动画、形状颜色、透明度、编组）。
   - **需决策**：审阅人意见互相矛盾，或引用了设计中找不到的内容。两方观点都列出来让用户选。
   - **已解决/无需处理**：已标记完成、已被后续回复否定、或仅是“LGTM”“不错”等肯定。
4. **一次性确认**：把分诊结果做成计划表（每条：页码、评论人、原意见摘要、拟执行改动 原值 → 新值），连同“需决策”问题一起用 `ask_user` 提交。用户调整后再确认一次即可。**这是全流程唯一的确认点。**
5. **执行并提交（不再询问）**：
   - `start-editing-transaction` → 从 `richtexts`/`fills` 找到元素 ID。
   - `perform-editing-operations`：把所有已批准改动合并到尽量少的调用里（操作 JSON 见 `canva-edit-design/references/operations.md`）。响应式页面只用允许的操作。
   - 检查返回缩略图有无文字溢出/越界；有问题在同一事务内修正。
   - `commit-editing-transaction`，不要再问“要保存吗”。
   - 展示提交后的缩略图。
6. **输出手动清单**：列出所有“需手动”项，每项含页码、改什么、谁提的、为什么 API 做不到、在 Canva 编辑器中的操作步骤。
7. **回复评论闭环**：对已处理线程用 `reply-to-comment`（`design_id`、`thread_id`、`message_plain`）说明改了什么；对需手动线程说明已做的近似处理和仍待手动的部分。回复文案用评论原语言。若用户在确认时表示不要回复评论，则跳过。

## 质量检查
- 每个线程都出现在最终报告的某一类中，无遗漏（报告末尾给出“线程总数 = 各类之和”）。
- 改动只覆盖已批准内容；未批准的不做。
- 提交后再 `get-design-content` 抽查关键文字已生效。

## 失败回退
- `list-comments` 无权限或工具不存在 → 请用户把评论文字粘贴过来，其余流程照常。
- 部分操作失败 → 移除失败项重试其余，失败项并入手动清单。
- 提交失败 → 草稿丢失；用同一计划重开事务再执行一次，仍失败则全部转为手动清单。
- `reply-to-comment` 失败 → 不影响设计修改；在报告里附上建议回复文案供用户手动粘贴。

## 输出交付格式
```
## 已按评论更新：<设计标题>
共 12 个评论线程：已修改 7 ｜需手动 3 ｜需决策 0 ｜无需处理 2

### 已修改
| 页 | 评论人 | 意见 | 改动 |
|---|---|---|---|
| 3 | @张三 | 数字过时 | “2024 年营收” → “2025 年营收” |

### 需在 Canva 中手动处理
1. **第 3 页 — 标题字体改为思源黑体**
   评论人：@李四 ｜原因：API 不能更换字体族
   → 打开第 3 页，选中标题，在顶部字体下拉框选择“思源黑体”

### 无需处理
- 第 1 页 @王五：“封面很好” — 肯定意见

编辑链接：<edit_url>
评论线程已回复：7/10
```
