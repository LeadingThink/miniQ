# Canva 编辑 API 能力边界

## 可以做
- 文字：整段替换、子串查找替换。
- 文字格式：字号、字重（常规/粗体）、斜体、颜色、对齐、行高、下划线、删除线、超链接、列表层级与符号。
- 媒体：替换图片/视频填充、插入新图片/视频、删除元素。
- 布局：移动、改尺寸。
- 元数据：改设计标题；为固定页面设计设置自动填充字段。

## 不能做（遇到就归入“需手动处理”）
| 需求 | 在 Canva 编辑器中的手动路径 |
|---|---|
| 改字体族（如换成思源黑体） | 选中文字 → 顶部工具栏字体下拉 |
| 新增文本框 | 左侧“文本” → 添加标题/正文 |
| 改背景色 / 渐变 | 点击空白背景 → 顶部颜色块 |
| 增加、删除、重新排序页面 | 底部页面缩略图栏拖动/右键 |
| 动画、转场 | 选中元素 → “动画” |
| 已有元素的透明度 | 选中 → 透明度图标 |
| 编组 / 取消编组 | 多选 → “编组” |
| 形状的颜色、描边 | 选中形状 → 颜色块（形状内文字 API 可改） |

处理原则：不要尝试用插图覆盖、删除重建等变通方式模拟这些能力；直接列入手动清单，给出明确步骤。

## 响应式页面（`is_responsive: true`）
只允许：`update_title`、`replace_text`、`find_and_replace_text`、`update_fill`、`delete_element`。
不允许：`format_text`、`position_element`、`resize_element`、`insert_fill`、`update_autofill_field`。
发调用前逐条检查操作所在页；不允许的操作不要发出，说明原因并给替代方案（例如改文字内容而不是改格式，或手动调整）。

## 文字长度变化的风险
替换后的文字比原来长 30% 以上（翻译、改写时常见）时，预览里重点检查溢出和换行；必要时用 `format_text` 适当缩小字号（非响应式页面），或者把问题列给用户。
