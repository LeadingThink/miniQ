# Canva 品牌合规检查（只读）

## 触发场景
- “这张海报符合我们的品牌规范吗”“对照品牌工具包检查一下这份 PPT”。
- 设计发布前的品牌审核；外包/同事交付的设计验收。

## 前置条件
- `canva` MCP 已启用并登录；读取品牌工具包需要授权范围包含 `brandkit:read`。
- 品牌规范来源（二选一或合并）：Canva 品牌工具包，或用户提供的色值/字体/Logo/语气说明（可为文档，用 `doc_read` 读取）。
- 判定细则见 `references/brand-checklist.md`。

## 分步流程
1. **定位设计**：按 `canva-design-studio/references/design-resolution.md`。
2. **获取品牌规范**：
   - `list-brand-kits` → 只有一个就直接用；多个则让用户选；没有则请用户提供规范。
   - 注意：该工具可能只返回 ID、名称和缩略图，不含色值和字体。此时查看品牌工具包缩略图做视觉比对，并用 `ask_user` 请用户补充主色 HEX 与字体名称。**绝不编造品牌色值或字体。**
   - 报错含 `Missing scopes` / `brandkit:read` → 告诉用户在 miniQ 中断开并重新授权 Canva 连接（重新登录时勾选品牌工具包权限），同时可先用用户口述的规范继续。
3. **读取设计**：
   - `get-design`（标题、页数）、`get-design-thumbnail` / `get-design-pages`（每页渲染图，**颜色与字体的主要证据**）。
   - `get-design-content`（文案，用于检查语气、术语、品牌名写法）。
   - 可选：只读事务 `start-editing-transaction` 读取位置尺寸与可能存在的样式，读完**必须** `cancel-editing-transaction`。
4. **逐项判定**（每项给出 符合 / 不符合 / 无法核实 之一）：
   - **配色**：主色、辅助色是否来自品牌色板；是否出现品牌外的显眼颜色。
   - **字体**：只有 payload 真的返回字体名时才能断言；否则按字形目测，写“疑似非品牌字体”并归入“无法核实”。
   - **Logo**：是否出现、版本是否正确、比例是否被拉伸、周围留白、是否放在杂乱背景上。
   - **文案语气**：品牌名大小写/中英文写法、禁用词、语气（正式/亲切）是否符合规范。
   - **一致性**：多页间同级元素样式是否统一。
5. **生成报告**：按“不符合 → 无法核实 → 符合”排序，每条附页码与证据（看到了什么）。
6. **提供修复**：列出可经 `canva-edit-design` 修复的项（文字颜色、字号、粗细、斜体、文案替换、换 Logo 图片、移动/缩放 Logo），其余标为需手动（换字体族、背景色、形状颜色）。用户同意后转 `canva-edit-design`，由其执行预览与确认；本技能自身不提交任何修改。

## 质量检查
- 每个“不符合”都有可验证证据（页码 + 元素 + 观察到的现象），证据不足的降级为“无法核实”。
- 报告中出现的品牌色值、字体名均来自工具返回或用户提供，并注明来源。
- 全程没有调用 `commit-editing-transaction`；打开过的事务均已取消。

## 失败回退
- 无品牌工具包且用户也无法提供规范 → 改做“内部一致性检查”（设计自身配色/字体是否统一），并在报告标题注明“无品牌基准”。
- 缩略图不可用 → `export-design` 导出 PNG，`curl -L -o` 下载后 `view_image`。
- 工具缺失（旧版 MCP 没有 `list-brand-kits`）→ 用 `tools/list` 结果告诉用户，并使用用户提供的规范。

## 输出交付格式
```
## 品牌检查 —「<设计标题>」对照「<品牌工具包名称/用户规范>」
结论：3 项不符合，1 项无法核实，4 项符合

### 不符合
- [配色] 第 2 页 CTA 按钮为亮橙色，品牌色板中没有该色（品牌主色 #1A4DFF，来源：用户提供）。
  修复：需手动（形状颜色 API 不可改）。
- [文案] 第 1、3 页品牌名写作 “Miniq”，规范为 “miniQ”。
  修复：可自动（find_and_replace_text）。

### 无法核实
- [字体] 正文字形与品牌字体相近，但接口未返回字体名，无法确认。

### 符合
- [Logo] 各页 Logo 比例正确、留白充足。

要我把“可自动”的项交给编辑流程修复吗？（会先给你看预览）
```
