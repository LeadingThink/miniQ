# 设计翻译规范

## 保留原文的内容
- 品牌名、产品名、人名（除非有官方译名）、网址、邮箱、电话、优惠码、话题标签、代码、型号。
- 法律声明、商标符号保持位置不变。

## 格式转换
| 项目 | 做法 |
|---|---|
| 日期 | 按目标语言习惯：中文“2026年3月8日”，英文 “March 8, 2026”，日文“2026年3月8日” |
| 数字 | 千分位按目标习惯；中文“万/亿”译英文时转为 thousand/million（例如 3.5 万 → 35K） |
| 货币 | 保留原币种符号，不做汇率换算（除非用户要求） |
| 标点 | 中文全角标点 ↔ 英文半角标点；英文不使用“、” |
| 引号 | 中文「」或“”，英文 "" |

## 文本长度
- 大致膨胀率：中 → 英 +30%~80%，英 → 德/法/西 +15%~35%，英 → 中/日 -20%~-40%。
- 标题、按钮、标签类短文本优先意译为同等长度；正文可稍长。
- 若估算译文长度 > 原文 1.5 倍，先给出更短的备选译法。

## 字体与字形
- 源设计为中文字体、译成英文：一般可正常显示。
- 源设计为拉丁字体、译成中/日/韩文：可能缺字形或自动回退为系统字体，导致风格不一致或显示方框。API 不能换字体族 → 列入手动清单，建议在 Canva 中改为支持该语言的字体（如思源黑体/Noto Sans CJK）。
- 从左到右语言译为阿拉伯语/希伯来语（从右到左）：对齐方向需要手动调整，提前告知用户。

## 语气与本地化
- 营销文案按目标市场习惯改写，而非逐字翻译；行动号召使用目标语言常见表达。
- 用户提供术语表时严格遵循，并在对照表中标注。
- 文化敏感内容（节日、颜色寓意、手势图片）如可能不适合目标市场，在报告里提示。

## 对照表要求
- 每行：页码、元素 ID（内部使用，可不展示给用户）、原文、译文、备注（保留原文/缩短/字号调整）。
- 对照表同时作为失败重试和手动粘贴的依据。
