# Canva 设计翻译（生成译文副本）

## 触发场景
- “把这张海报翻译成英文”“做一个日文版的 PPT”“把设计本地化成繁体中文”。
- 一次要多种语言时，按语言逐个执行本流程（每种语言一个副本）。

## 前置条件
- `canva` MCP 已启用并登录；对源设计有查看权限，账号可创建设计副本。
- 编辑协议与限制见 `canva-edit-design`（尤其响应式页面限制、文本元素无法新增）。
- 翻译规范、文本膨胀与字体注意事项见 `references/translation-guide.md`。

## 分步流程
1. **定位设计**：`D` 开头 ID 直接用（不要拿去 `search-designs`）；URL 取 `/design/` 后的 ID；短链 `resolve-shortlink`；名称 → `search-designs`，多个结果让用户选。
2. **确认目标语言与规则**：目标语言、是否保留品牌名/产品名原文、术语表（用户有就用）。已说明的不重复问。
3. **创建副本**：`get-design` 取原尺寸，再 `resize-design`（相同宽高的 `custom` 类型，或同一预设类型）得到新设计 ID。**所有修改只在副本上进行，绝不修改原稿。**
   - `resize-design` 不可用或失败 → 告知用户，请其在 Canva 中“复制设计”后提供副本链接，再从第 4 步继续；不要改为直接编辑原稿。
4. **开事务读取文字**：对副本 `start-editing-transaction` → 记下 `transaction_id`、`pages`，以及 `richtexts` 中每个文字元素的 `element_id`、所在页、原文。
5. **翻译**：逐元素翻译（按 `references/translation-guide.md`）：
   - 保留换行结构、项目符号、数字/日期/金额格式按目标语言习惯转换（货币单位不自动换算，除非用户要求）。
   - 品牌名、产品名、网址、邮箱、代码、话题标签保持原样。
   - 目标文本明显比原文长（如中译英常增加 30%–80%）时，优先选更精炼的译法。
   - 把“元素 ID → 原文 → 译文”整理成对照表。
6. **批量替换**：一次 `perform-editing-operations`，对所有元素使用 `replace_text`（所有页放在同一事务中），并加一个 `update_title`，标题为“<原标题>（<语言>）”或其译文。
7. **预览检查**：展示返回的每页缩略图和对照表；检查文字溢出、截断、换行、字体缺字（显示为方框/豆腐块，常见于把拉丁字体用于中日韩文字）。
   - 溢出可在同一事务中用 `format_text` 缩小字号（非响应式页面），或换更短译法。
   - 缺字问题 API 无法换字体 → 列入手动清单。
8. **审批并提交**：用户确认后 `commit-editing-transaction`；用户拒绝则 `cancel-editing-transaction`，副本仍是未翻译状态，告知用户可删除。
9. **交付**：给出副本编辑链接、对照表、手动事项。

## 质量检查
- `richtexts` 中每个元素都有译文或明确标注“保留原文”，数量对得上。
- 提交后 `get-design-content` 抽查，确认无遗漏原文（除刻意保留的专有名词）。
- 原设计内容未改变（可 `get-design-content` 对比首页文字）。

## 失败回退
- 图片中的文字（嵌在位图里）无法通过 API 翻译 → 列入手动清单，建议替换图片。
- 某些元素替换失败 → 移除后重试其余，失败项列入手动清单并附译文，方便用户粘贴。
- 提交失败 → 用对照表重新开事务再执行一次。

## 输出交付格式
```
## 已生成译文副本：<原标题>（English）
编辑链接：<edit_url> ｜原设计未改动
| 页 | 原文 | 译文 |
|---|---|---|
| 1 | 夏季大促 | Summer Sale |
| 1 | 全场五折起 | Up to 50% Off |
需手动处理：
1. 第 2 页主视觉图片内含中文字样，API 无法翻译 → 建议替换为英文版图片
2. 第 3 页译文较长，已缩小字号至 28，建议人工检查排版
```
