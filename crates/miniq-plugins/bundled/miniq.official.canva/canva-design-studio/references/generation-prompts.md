# generate-design 的 query 写法

`generate-design` 的效果几乎完全取决于 `query` 的信息密度。按下面的结构写，一段话 + 条目均可。

## 通用结构
1. **用途与渠道**：这是什么（海报/小红书封面/邀请函/演示文稿），用在哪（线下张贴、手机竖屏、投屏）。
2. **受众**：给谁看，他们关心什么。
3. **必须出现的文案**：主标题、副标题、日期地点、价格、CTA（行动号召），逐字给出并加引号。
4. **视觉方向**：风格关键词（极简/复古/科技感/手绘）、主色与辅色（有品牌色就写 hex）、图片主体、留白程度。
5. **版式偏好**：信息层级（先看什么后看什么）、文字与图片比例、是否需要 Logo 位置。
6. **禁忌**：不要出现的元素或颜色。

## 示例（海报）
```
用途：咖啡店秋季新品线下张贴海报（A3 竖版）。受众：附近写字楼白领。
必须出现的文案：主标题“桂花拿铁 限时上市”；副标题“10 月 1 日 - 10 月 31 日”；CTA“到店出示本海报立减 5 元”。
视觉：温暖、治愈，主色 #C8702A，辅色奶白 #F6EFE6；主体为一杯带桂花的拿铁特写，背景有少量飘落桂花。
版式：标题占上 1/3，产品图居中，CTA 放底部色块内；右下角留 Logo 位。
不要：卡通人物、霓虹色。
```

## 中文内容注意
- 明确写“所有文字使用简体中文”，否则可能生成英文占位文案。
- 较长的中文标题建议控制在 12 字以内，避免自动换行破坏版式。
