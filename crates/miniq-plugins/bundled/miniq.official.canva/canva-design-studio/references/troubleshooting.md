# Canva 连接器故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `mcp_call` 报服务器未启用/无此服务器 | 插件的 `canva` MCP 未启用 | 请用户在 miniQ 插件页启用 Canva 插件的 MCP 连接器 |
| 进程启动失败、`npx: command not found` | 未装 Node.js | 请用户安装 Node.js 18+ 后重试 |
| 浏览器没有弹授权页 / 一直等待 | mcp-remote 授权回调被拦截 | 让用户检查默认浏览器、关闭拦截插件后重启连接器；必要时清理 `~/.mcp-auth` 中 canva 相关缓存后重试（先征得同意） |
| 401 Unauthorized / token expired | 授权过期 | 重新启用连接器并在浏览器重新登录 |
| `Missing scopes: [...]` | 旧授权缺少新权限 | 停用再启用连接器，重新授权以刷新 scope |
| 403 / feature not available / plan | 套餐不支持（品牌模板、autofill、品牌工具包常见） | 说明需要团队/企业版；给出降级方案 |
| 404 design not found | ID 错误、设计被删、无权限 | 重新定位；请用户确认链接与账号 |
| 429 rate limit | 调用过快 | 等待 10–30 秒后重试，批量任务改为串行并在每次调用间留间隔 |
| 导出任务一直 in_progress | 大文件/视频导出慢 | 每 3–5 秒轮询，超过 2 分钟告诉用户仍在处理，可稍后再取 |
| 下载 403/过期 | 导出链接有时效 | 重新导出 |
| 编辑提交失败 | 事务过期或冲突（别人同时在编辑） | 草稿已丢失；重新开事务再做一遍，并提醒用户避免同时在编辑器中修改 |

## 汇报失败的格式
```
❌ <步骤> 失败：<错误摘要>
已完成：<列表>
未完成：<列表>
建议：<下一步>
```
