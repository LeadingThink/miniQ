# 社媒平台尺寸预设（单位：像素）

平台规格会调整，以下为常用推荐值；用户指定尺寸时以用户为准。

## 默认五种（“全部社媒”时使用）
| 格式 | 宽×高 | 比例 | `design_type` |
|---|---|---|---|
| Facebook 帖子 | 1200×630 | 约 1.91:1 | `{"type":"custom","width":1200,"height":630}` |
| Facebook 快拍 | 1080×1920 | 9:16 | `{"type":"custom","width":1080,"height":1920}` |

## 安全区建议
- 9:16 竖屏：上下各留约 250px（平台 UI 会遮挡头像、按钮、字幕区）。
- 1.91:1 横图：主要文字保持在中间 80% 宽度内。
- 公众号头图：分享卡片会裁切成 1:1 预览，关键信息放在正中 383×383 区域。

## 构图变化风险
| 源 → 目标 | 常见问题 | 处理 |
|---|---|---|
| 横 → 竖 | 两侧内容被挤压、上下空白 | 缩放主视觉、上移标题 |
| 竖 → 横 | 上下被裁、文字过小 | 文字块移到一侧 |
| 方 → 超宽（900×383） | 主体过小 | 建议手动重排或重新生成 |
