# 视觉方向构思

用生图快速给出几个**真正不同**的方向，让用户用眼睛做决定，而不是读长篇描述。每个方向是一张完整的界面效果图（不是情绪板、不是拼贴）。

## 触发场景

- “给我几个方向”“出三版首页”“想看看不同风格”
- 重设计链路：“把设置页做得像 Linear 那样”“比现在更好看”
- 用户只有文字需求，要做高保真原型但没有视觉参考

## 前置条件

- 已通过 `product-design-brief` 关卡（目标与用户结果清楚）。
- 已运行预检，读取 `user-context.md`（品牌色、平台、参考产品）。
- 重设计：已用 `browser_automation` 截取现状页面与参考产品页面（或用户提供截图），并用 `view_image` 看过。
- 提示词写法与差异化维度见 `references/direction-prompts.md`。

## 分步流程

1. **确定画布**：按平台定尺寸与比例（手机竖屏 ≈ 9:19.5，桌面横屏 ≈ 16:10 或 3:2，落地页首屏 16:9）；同一批方向必须同尺寸，便于比较。
2. **拟定方向轴**：从“信息密度 / 布局结构 / 视觉风格 / 情绪基调 / 导航模式”中挑 2–3 个轴，让每个方向在轴上的取值明显不同（例：A 高密度表格型、B 卡片化图文型、C 对话/助手型）。只改颜色或圆角不算不同方向。
3. **写提示词**：每个方向一段完整提示词，包含：产品与屏幕名称、平台与比例、布局结构（从上到下的区块）、真实文案（主标题、按钮、数据示例，用用户语言）、视觉风格、配色（有品牌色就用）、字体气质、要避免的内容（设备外壳、乱码文字、水印）。
4. **生成**：对每个方向调用一次 `generate_image`（`size` 按画布设置，方向多时可用 `agent_run` 并行，每个子任务只生成一个方向并返回路径）。重设计时在提示词中描述现状问题与参考产品的关键特征，但不要照搬参考产品的 Logo 和品牌名。
5. **核验**：对每张图用 `view_image` 检查：是否符合平台与比例；方向之间是否真的不同；文字是否可读、无大面积乱码；是否出现设备外壳、水印、无关元素。不合格用 `edit_image` 局部修正或重新生成（每个方向最多重试 2 次）。
6. **保存**：图片放在 `design/directions/`，命名 `direction-1-<关键词>.png`；用 `file_write` 写 `design/directions/README.md`，每个方向 3 行：核心思路、适合场景、主要取舍。
7. **展示并提问**：在消息里展示所有方向图片，每个方向一句话特点，然后只问一个问题：“选哪一个？也可以说想怎么组合或调整。”
8. **用户选择后**：
   - 要调整：用 `edit_image` 基于选中图迭代（改局部布局、配色、文案），再次 `view_image` 核验。
   - 定稿：把选中图作为参考，发构建预告后进入 `product-design-image-to-code`（高保真还原）；若需要多屏，先用 `generate_image` 以选中图为风格锚点补生成其他关键屏，保持同一视觉语言。

## 工具与参数要点

- `generate_image`：`prompt` 写完整界面描述；`size` 与画布一致（如 `1024x1536` 竖屏、`1536x1024` 横屏）；`quality` 高保真方向用 `high`。
- `edit_image`：`image_path` 指向选中方向图，`prompt` 只描述要改的部分和要保持不变的部分。
- `view_image`：每张生成图都要看；检查小字时用 `detail: original`。
- `agent_run`：并行生成时每个子任务独立输出文件名，避免覆盖。

## 质量检查

- 至少 2 个、至多 4 个方向；两两之间在至少 2 个方向轴上不同。
- 每张图都经过 `view_image` 核验并记录结论；图中文案与产品语境一致。
- 没有用文字描述代替图片；没有用 CSS/SVG/ASCII 伪造效果图。
- 保存目录与 README 完整。

## 失败回退

- `generate_image` 不可用或连续失败：告诉用户受阻，改为提供 2–3 个参考产品截图（`browser_automation` 截取公开页面）加一句话差异说明，由用户选择；不要用手绘 SVG 或 HTML 模拟效果图冒充。
- 生成图文字乱码严重：在提示词中减少文字量、指定“清晰的中文/英文 UI 文本”，或接受乱码并在说明中注明“文字仅示意，实现时会用真实文案”。
- 用户对所有方向都不满意：问一个问题定位原因（太花/太素/结构不对），据此换方向轴重新生成。

## 交付格式

- 文件：`design/directions/*.png` 与 `README.md`。
- 消息：展示图片 + 每个方向一句话 + 恰好一个选择问题。
