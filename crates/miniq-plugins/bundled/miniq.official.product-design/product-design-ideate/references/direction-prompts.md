# 方向提示词与差异化

## 1. 方向轴（每批挑 2–3 个轴拉开差异）

| 轴 | 取值示例 |
| --- | --- |
| 信息密度 | 极简留白 / 均衡 / 高密度专业 |
| 布局结构 | 单列流 / 卡片网格 / 左侧导航 + 表格 / 分屏 / 看板 |
| 视觉风格 | 扁平克制 / 柔和拟物 / 编辑排版感 / 大胆撞色 / 暗色专业 |
| 情绪基调 | 可信稳重 / 轻松友好 / 高效冷静 / 活力年轻 |
| 导航模式 | 底部 Tab / 顶部分段 / 侧边栏 / 命令面板 / 对话式 |
| 主视觉 | 数据可视化主导 / 摄影图主导 / 插画主导 / 纯排版 |

反例：三个方向只是蓝、绿、紫三种主色——这不算不同方向。

## 2. 提示词结构

```
一张<平台>产品界面设计效果图，<宽高比>，正面平视、无设备外壳、无水印。
产品：<产品名>，<一句话定位>。屏幕：<屏幕名称>。
布局（从上到下）：
1. <区块1：内容与元素>
2. <区块2>
3. <区块3>
文案：主标题“<真实标题>”，主按钮“<按钮文字>”，示例数据：<人名/金额/日期>。
视觉风格：<风格关键词>；配色：<品牌主色 HEX 与辅助色>；字体气质：<如 几何无衬线、紧凑>。
细节：清晰可读的<语言>界面文字，统一的图标风格（<线性/面性>），真实的照片/插画内容。
避免：手机外壳、浏览器外壳、乱码文字、占位灰框、多余装饰。
```

## 3. 重设计提示词要点

- 先用一两句描述现状的问题（来自截图观察），再描述方向如何解决。
- 借鉴参考产品的**手法**（如“命令面板式导航、低饱和中性色、紧凑列表”），不复制其 Logo、品牌名、专有插画。
- 保留用户产品的品牌识别（Logo 位置、主色），除非用户要求换品牌。

## 4. 多屏一致性

定稿后补生成其他屏时，在提示词开头写“延续以下视觉语言：<从定稿图提炼的 5–8 个特征：配色 HEX、圆角、阴影、字体气质、图标风格、间距节奏>”，并用 `view_image` 并排检查一致性。

## 5. 核验清单（每张图）

- [ ] 比例与平台正确
- [ ] 与其他方向在 ≥2 个轴上不同
- [ ] 主要文字可读，无大面积乱码
- [ ] 无设备外壳 / 水印 / 无关元素
- [ ] 与产品语境与用户一致
