# 还原检查清单

## 1. 量取顺序（由粗到细）

1. 画布：宽高、推断视口与设备像素比（截图宽 1170 → 390 CSS 像素 @3x；2880 → 1440 @2x）。
2. 栅格：页面左右边距、内容最大宽度、列数与栏间距。
3. 区块：从上到下列出每个区块的高度与内部结构。
4. 排版：每个层级的字号、字重、行高、颜色；中英文字体气质（衬线/无衬线、几何/人文）。
5. 颜色：背景、表面、文字、边框、主色、状态色；取色时找面积大且平整的区域。
6. 形状：圆角、边框粗细、阴影（偏移、模糊、透明度）。
7. 资产：每个图片/图标槽位的位置、尺寸、内容。
8. 交互：所有看起来可点的元素及其预期行为。

## 3. 字体替代

- 苹方/系统中文：`-apple-system, "PingFang SC", "Noto Sans SC", sans-serif`
- 常见英文几何无衬线（如 Inter、SF Pro）：`Inter, -apple-system, "Segoe UI", sans-serif`（Inter 可按开源许可从本地或 CDN 引入）
- 无法获得的商业字体：选最接近的开源字体，并在交付中说明。

## 4. 不改进原则

允许：修复原图中明显不可实现的部分（如图片裁切到一半的文字）、补齐原图没画出的状态（hover、focus、加载）。
不允许：改配色、改间距节奏、换图标风格、重写文案、“顺手”加功能。
有建议时：在交付消息中单独列出，不写进实现。

## 5. 自查（进入 QA 前）

- [ ] 截图与参考图同尺寸，叠在一起看主要区块边缘对齐
- [ ] 所有文案逐字一致（含标点、数字格式）
- [ ] 颜色抽查 5 处，与原图目测无差
- [ ] 图片槽位比例正确、无拉伸
- [ ] 所有可点元素有效
