# 首次引导（Onboarding）

目的：用一次简短对话，把以后每次设计任务都会用到的稳定信息存进 `user-context.md`，让后续的构思、原型、审计直接“贴着产品”做。

## 何时进行

- 用户说“初始化/设置产品设计插件”“记住我们的产品”“你知道我们产品什么情况吗”。
- 预检显示没有 user-context.md，且用户显然在做一个会反复迭代的真实产品（而不是一次性小练习）。此时**提议**一次，用户拒绝或不回应就继续当前任务，不阻塞。

## 引导期间不做的事

不扫描工作区、不装依赖、不生成图片、不做审计、不开始实现。引导只收集和保存信息。

## 提问方式

用 `ask_user` 一次发出，分两组，全部可选，允许用户粘贴链接、路径或一句话：

**必填（缺了会影响每次设计判断）**
1. 产品叫什么？一句话说它帮谁解决什么问题？
2. 主要用户是谁？主要在什么平台上用（Web / iOS / Android / 小程序 / 桌面）？

**选填（有就给，没有跳过）**
3. 线上/测试地址，或本地怎么跑起来？
4. 代码库路径、组件库、设计 token 或主题文件？
5. 品牌主色、Logo、字体、喜欢的参考产品？
6. 以后做好的原型默认怎么分享（本地看 / Vercel / Netlify / GitHub Pages / 其他）？

更新已有上下文时，只问用户想改的部分，并先用 `preflight.py show` 读出现有值，避免重复询问。

## 保存

1. `python3 <插件目录>/product-design-user-context/scripts/preflight.py init --workspace <工作区>`（项目级）；用户希望跨项目通用时加 `--scope global`。
2. 逐项写入：`preflight.py set --field 产品名称 --value "…"`，或用 `file_edit` 直接编辑对应行。
3. 用户给的截图或参考图，复制到 user-context.md 同级的 `assets/` 目录，并在“参考截图目录”字段记录。
4. 保存后用 `preflight.py show` 回读确认。

## 保存规则

- 只存长期稳定、用户明确提供或确认的信息；推测的内容不写。
- 不存密码、API 密钥、访问令牌、Cookie、个人隐私数据。
- 与已有值冲突时以用户最新说法为准，替换旧值而不是追加矛盾的两条。
- 用户说“忘掉/删掉某项”时，把该字段改回“（待填写）”。
- 跨项目的个人偏好（如“我总是先要移动端”）可在用户同意后额外用 `memory_write` 保存一句话摘要。

## 引导结束的回复

两三行：说明记住了哪些关键信息、还缺哪一项必填（若有），然后给一个下一步（如“要不要先基于这些信息出三个首页方向？”）。
