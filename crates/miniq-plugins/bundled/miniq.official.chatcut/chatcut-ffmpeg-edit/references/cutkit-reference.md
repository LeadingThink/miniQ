# cutkit.sh 子命令参考

所有子命令：`bash scripts/cutkit.sh <子命令> ...`。输出目录不存在会自动创建；输出文件存在会被覆盖，所以调用前要确认输出名不与已有文件冲突（或先 `ask_user`）。默认视频编码 H.264 CRF 20、yuv420p、AAC 160k、faststart。

| 子命令 | 参数 | 说明 |
|---|---|---|
| probe | 输入 | JSON 输出时长、大小、码率、各流编码/分辨率/帧率/采样率 |
| trim | 输入 开始 结束 输出 | 重编码截取，切点精确；时间可写 `75` 或 `00:01:15.5` |
| desilence | 输入 输出 [dB=-35] [最短静音秒=0.6] [边距秒=0.15] | silencedetect 找静音，保留有声段并拼接；打印保留段数与前后时长 |
| concat | 输出 输入1 输入2 ... | 统一到第一个输入的尺寸、30fps、48k 立体声；无音轨的素材自动补静音 |
| speed | 输入 倍率 输出 | 0.25–4 倍，音频用 atempo 链保持音调 |
| vertical | 输入 输出 [blur/crop] | 转 1080x1920；blur=模糊背景补边（保留全画面），crop=居中裁切 |
| subtitle | 输入 字幕.srt 输出 [字体=PingFang SC] | 烧录硬字幕；需要 libass |
| compress | 输入 目标MB 输出 | 按时长反算码率，两遍编码；码率下限 150k |
| audio | 输入 输出.m4a | 抽 AAC 音轨 |
| wav16k | 输入 输出.wav | 单声道 16kHz PCM，最适合 `transcribe_audio` 或 whisper |
| silences | 输入 [dB=-35] [最短静音=0.4] | 每行打印 `开始 结束`（秒），供 `srt_tool.py align` 使用 |
| loudnorm | 输入 输出 [LUFS=-14] | 单遍 loudnorm，视频流直接复制 |
| bgm | 视频 音乐 输出 [音乐dB=-18] | 音乐循环补足、结尾 2 秒淡出，与原声混合；原片无音轨时只用音乐 |
| frames | 输入 目录 [张数=6] | 均匀抽帧（宽 640），文件名含时间点 |
| scenes | 输入 [阈值=0.35] | 打印镜头切换时间点，阈值越小越敏感 |
| check | 文件 | 基本信息 + 黑场（≥0.5s）+ 长静音（≥2s，-45dB） |

## 参数选择建议
- 去静音：口播/访谈 `-35 0.6 0.15`；节奏更紧的短视频 `-32 0.35 0.08`；环境嘈杂的录音先试 `-30`。
- 边距太小会吞掉字头字尾，听感“被掐断”，这时把边距加到 0.2。
- 竖屏：人物居中的口播用 `crop`；横屏 PPT、游戏录屏、多人画面用 `blur`。
- 压缩：目标大小留 5% 余量（要 50MB 就填 47）。
