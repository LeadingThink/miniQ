# 幻灯片版式设计规则

> 属于 `figma-use-slides` 技能。新建 deck 或"重设计/优化"已有 deck 时阅读。目标：做出有设计意图、页页有变化、观众一眼能读懂的演示文稿。

## 0. 适用优先级

1. **编辑已有 deck**：本文原则是用来"匹配"的，不是用来"引入"的。先检查（盘点脚本 + 截图）现有配色、字体、空间习惯、母题——那就是这份 deck 的设计语言，保持一致。只有现有 deck 没回答的问题才用本文补缺。
2. **用户给了设计方向**（品牌规范、色板、字体、参考文件）：用户的输入优先。"用 Helvetica + 藏青/金色"意味着字体与配色已定，本文只指导用户没定的部分（版式变化、构图、节奏、密度）。"让一种颜色主导"即让**用户的主品牌色**主导；"字体匹配 deck 气质"即在品牌字体体系内选择，不引入新字体。
3. **从零开始**：以下规则全部适用，由你做出明确决定并贯彻全篇。

## 1. 配色

- **一种颜色主导**：确立主角色（占据大部分视觉面积）、辅助色、少量强调色。所有颜色平分秋色会显得犹豫不决。一个实用比例：主色/背景约 60%，辅助约 30%，强调约 10%。
- **配色要属于这个主题**：讲基础设施可靠性的 deck 与讲品牌活动的 deck 不该像同一套模板。从内容出发选色。
- **设计明暗走向**：深色页与浅色页给人的感受不同，可主动利用。常见结构是封面与结尾用更深、更有氛围的页，中间用浅色保证可读；全深或全浅也可以，只要是有意选择。
- **背景是设计面**：渐变、色块、贴边的柔和几何形、分节间的色调变化，都能营造氛围、引导视线而不抢正文。
- **可读性不可妥协**：深色背景上的正文要接近纯白、高对比，不要用灰调或染色的低对比文字；品牌色/强调色留给标题、标签和形状。眯眼看不清正文就是对比度不够（正文与背景对比度建议 ≥ 4.5:1，大标题 ≥ 3:1）。
- 在规划阶段把色板定义为**按角色命名**的常量（如 `bgDark`、`surface`、`textPrimary`、`textMuted`、`accent`），所有构建脚本复用同一对象。

## 2. 字体与字号层级

- **字体匹配 deck 的气质**：用 `figma.listAvailableFontsAsync()` 查看可用字体，选择范围远比默认几款大。"展示字体做标题 + 耐用字体做正文"的组合能赋予个性；不同 deck 之间换着用，不要每次都收敛到同一组合。中文 deck 必须选含中文字形的字体。
- **层级要一眼可辨**：从房间另一头眯眼看，标题仍应是最"响"的元素——级差要大，不是礼貌性的一小步。
- **基于 1920×1080 画布的参考字号**（按内容与字体调整，关键是级差）：

| 角色 | 参考字号 | 说明 |
|---|---|---|
| 超大数字 / 关键指标 | 200–320 | 单独成为画面主体 |
| 封面 / 章节标题 | 110–160 | 一到两行 |
| 页标题 | 64–96 | 一页一个观点 |
| 小标题 / 引言 | 40–56 | |
| 正文 / 要点 | 30–40 | 投影下不低于 28 |
| 标签 / 注释 / 来源 | 20–26 | 最小不低于 18 |

相邻层级至少约 1.5 倍差距；**不要**让全页文字挤在一个窄区间里（例如全部 18–28）。
- **正文左对齐**：居中的段落和列表难以扫读；居中只用于标题、引言和单行陈述。
- **字重也是设计工具**：细体大标题配较重正文，与粗厚标题配轻正文，气质截然不同。行高：标题 100–115%，正文 130–150%。

## 3. 内容密度

- **幻灯片不是文档**：一页的目的是用视觉冲击落地一个观点，而不是完整覆盖一个话题。
- **测试**：观众能否在几秒内吸收这一页？需要仔细读的页就是内容过多——节奏由讲者控制，不由读者控制。
- **你的工作是编辑**：删掉什么比留下什么更重要。一页一个有力的洞见加充足留白，胜过六个好观点挤在一起。
- **拆成更多页，而不是更密的页**：放不下时拆成两张构图良好的页，而不是缩字号、压间距。页数不花钱，注意力很贵。

## 4. 版式与构图

- **版式从内容推导，而不是从菜单挑选**：先问"这页在做什么"——引入观点、证明论点、制造停顿、抛出结论。单个关键指标需要巨大字号和四周留白；对比需要强化反差的视觉分隔；转折需要克制与空白。
- **不对称制造张力**：50/50 稳定但呆板；70/30 之类的不均分割让视线从大区流向小区。画布怎么分、文字与空白怎么配重、元素之间大小比例，都适用。
- **元素关系承载含义**：重叠显得相连、有层次；大间距分开显得独立而重要；推到边缘并被裁切显得有动势，像是更大画面的一部分。
- **全篇结构要变化**：每页都"标题左上、正文在下、辅助内容排成网格"会有机械节奏。每页应像一次新构图：变换内容锚点（左、右、中、贴边）、画布分割方式、占用与留空的比例。
- **用满整块画布**：内容缩在中间、四边等距浪费了最有冲击力的边缘。出血的形状、锚定在角落的标题、延伸到画框边界的色块，让页面像一扇看向更大世界的窗。
- **允许偏离中心**：把内容块放到左三分之一，或把形状群推向右上角，产生运动感。
- **层叠制造纵深**：文字块后的色块、部分压过内容边界的强调形状、出血的装饰元素。
- **在密与疏之间表态**：要么单一洞见加大量留白，要么紧凑的对比网格；"不疏不密"的页看起来像没做完。
- **节奏与单页同样重要**：密集之后接开阔，深色之后接浅色，信息量大的页之后接只有一个观点的页。安静的页不是填充，是让密集页产生冲击的停顿。
- **先规划版式序列再动手**：用文字描述每页的空间策略，读起来重复（"网格、网格、双栏、网格"）就一定看起来重复——在写代码前调整，比返工便宜得多。

可轮换的版式原型（按内容选择，不要机械套用）：

- 巨型数字 + 一句解释，数字贴左下、说明在右上；
- 左侧窄色带放标题，右侧大面积放单一图片或图表；
- 满版深色背景 + 居中单句陈述（过渡/转折页）；
- 非对称双区：70% 主视觉 + 30% 要点栏；
- 时间线横穿画面并从两侧出血；
- 大号引语 + 小号出处，不加卡片；
- 三个并列概念用大小不一的形状表达主次，而非等宽卡片。

## 5. 边距、对齐与间距节奏

- **安全边距**：正文与关键信息距画布边缘建议 ≥ 96–140px（1920 宽画布），避免投影裁切；**装饰元素可以出血**，但文字不要贴边或越界。
- **锚点要变化**：同一套边距与起始坐标不必每页一致——一页内容从左上开始，下一页单元素居中，再下一页标题推到右三分之一。变化要有意为之，而不是随机，但必须**存在**。
- **对齐**：同一页内的元素共享清晰的对齐线（左边线、基线或中心线）；数值用整数像素；同一角色的元素（页脚、页码、来源）在全篇位置一致。
- **间距有节奏**：相关元素紧密成组（如标题与副标题 16–32px），重要观点周围留大空间（≥ 80px）；到处等距 = 没有分组、没有节奏。
- 采用 8px 的倍数作为间距基准，方便保持一致。

## 6. 形状语言与签名母题

- **每页至少一个非文字元素**：形状、线条、色块、强调圆、装饰边框——给视线一个落脚点并增加结构。纯文字页很快被遗忘。
- **选一个可重复的视觉母题贯穿全篇**：好的母题可辨识（脱离上下文也认得出）、可复用（在不同类型的页上都不别扭）、应用有变化（这页裁切、那页完整，这里大、那里小）。可以是一种形状、一种线条处理、一种层叠惯例或一种空间规则。
- **形状用于结构，而不只是装饰**：矩形可以是容器、分隔、背景面板、强调框；线条可以分区、连接、造节奏；圆可以承载图标或聚焦关键数字。
- **对母题下决心**：4–6% 透明度的重复形状等于不存在。选了圆形母题，就让它足够大到被边缘裁切、足够实到被察觉。删掉它也没人注意的形状，就没有尽到职责。

## 7. 反模式清单（交付前逐条自查）

以下迹象说明 deck 是"没有设计意图地生成"的，主动避开：

1. 每页结构相同——顶部居中标题 + 下方列表，一页接一页。
2. 保守无立场的配色——全是灰蓝，没有明确主色或强调色。
3. 纯文字页——没有形状、没有视觉结构。
4. 一切居中、四边等距——没有元素接近边缘。
5. 每个标题下都画一条线——用留白、色彩变化或版式变化来分区。
6. 扁平层级——所有文字字号接近，没有视觉优先级。
7. 每个 deck 都用同一款"安全"字体。
8. 全篇纯色平铺背景——背景层什么都没有。
9. 到处等间距——没有分组与节奏。
10. 所有内容都装进同一种浅色圆角卡片——引言可以就是大号斜体字，数据可以就是一个数字，对比可以靠空间分隔。只有分组真正有帮助时才用容器。
11. 对比两个对象时用同一版式只换颜色——给每个对象不同构图，让视觉差异强化概念差异。
12. 为氛围牺牲可读性——深色背景上的低对比、染色、半透明正文。
13. 内容过多但字体很漂亮——好字体救不了糟糕的编辑取舍，先删内容再设计。
14. 每页内容起始位置完全相同。
15. 可有可无的装饰——太小、太淡、太普通而无法被感知为有意设计的形状。
