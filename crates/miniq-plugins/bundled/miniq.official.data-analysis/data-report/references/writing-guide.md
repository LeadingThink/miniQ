# 报告写作规范

## 叙事
- 金字塔：结论先行 → 分论点 → 证据
- 每节开头一句“本节结论”，然后证据
- 用读者的业务语言，而非表名/字段名
- 结尾给出明确的下一步，而不是“需要进一步研究”

## 数字
- 带单位与时间：“2024 年 5 月 GMV 1.23 亿元，环比 +4.5%”
- 比率变化用百分点（pp）；相对变化用 %
- 精度与不确定性匹配：样本小就少写小数
- 大数用万/亿；表格内统一单位并写在表头
- 同一数字全文只出现一个值（避免四舍五入不一致）

## 事实、推断与建议
- 事实：“新客占比从 32% 升至 41%”
- 推断：“这可能拉低了整体复购率，因为新客复购率仅为老客的一半”
- 建议：“针对新客增加首购后 7 天触达”
- 对推断标注置信度或验证方法

## 证据与来源
- 每张图下方注明：数据来源、截至日期、口径
- 报告末尾列出：脚本、查询、数据文件路径

## 措辞
- 避免：显著（非统计意义时）、证明、导致（无因果设计时）、暴涨暴跌
- 推荐：与……相关、同期、贡献了、可能反映
- 不确定就说不确定，并说明需要什么来确定

## Markdown 约定（便于渲染与导出）
- 一级标题只有一个（报告标题）
- 表格用标准管道表格；图片用相对路径 `![说明](../../analysis/figures/x.png)`
- 提示框可用引用块 `> **注意**：...`
