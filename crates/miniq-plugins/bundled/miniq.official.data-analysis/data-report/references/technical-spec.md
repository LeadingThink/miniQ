# 技术版报告规范

## 目标
让另一位分析师能理解、复核、复现分析，并判断结论的稳健性。

## 必需结构
1. **摘要**：问题、方法、主要结论、置信度
2. **问题与范围**：研究问题、决策背景、总体、时间窗、排除项
3. **数据**：来源表/文件、粒度、行数、截至时间、质量检查结果与处理
4. **指标定义**：公式、分子分母、过滤、去重、时区
5. **方法**：分析步骤、统计方法、模型与参数、为何选择该方法
6. **结果**：按研究问题分节；图表 + 表格 + 解读；包含区间或显著性
7. **稳健性检查**：替代口径、不同时间窗、排除异常值、分群一致性
8. **局限与威胁**：偏差、未观测混杂、数据缺口
9. **结论与建议**
10. **复现信息**：脚本/Notebook/SQL 路径、依赖版本、运行命令、随机种子

## QA 附录（交付前自查）
- [ ] 复现命令实际运行过，输出与报告一致
- [ ] 所有表格的合计与分项一致
- [ ] 统计检验的前提条件已检查
- [ ] 多重比较已处理或说明
- [ ] 数据质量问题对结论的影响已评估
