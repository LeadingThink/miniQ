# 高管版报告规范

## 目标
2 分钟内让决策者知道：发生了什么、为什么重要、建议做什么、有多大把握。

## 必需结构
1. **标题**：结论式，如“Q2 增长放缓主要来自华东新客获取下降”
2. **一句话摘要**：核心结论 + 关键数字 + 时间范围
3. **关键发现（3–5 条）**：每条 = 结论句 + 1 个数字 + 对比基准；可配 1 张图
4. **建议与决策请求**：行动、负责人、时间、预期影响
5. **风险与不确定性**：最多 3 条，说明对结论的影响方向
6. **口径与数据说明**：来源、截至日期、主要口径（一小段）
7. **附录**（可选）：详细图表、方法、技术附录链接

## 篇幅
- 正文 1–2 页（打印），图表 ≤ 4 张
- 每段 ≤ 3 句；避免术语，必要术语首次出现时解释

## QA 附录（不对外，交付前自查）
- [ ] 标题与摘要中的数字与正文、图表一致
- [ ] 每条发现都有对比基准
- [ ] 建议能从发现推出
- [ ] 风险写明而非隐藏
- [ ] 无未经验证的因果表述
