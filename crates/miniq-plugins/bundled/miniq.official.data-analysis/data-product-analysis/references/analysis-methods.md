# 产品分析方法手册

## 漏斗
- 定义有序步骤与转化窗口（如 7 天内完成下一步）
- 两种口径：严格有序（必须按顺序）与宽松（只要都发生）；写明所用口径
- 指标：各步到达人数、步间转化率、累计转化率、步间中位耗时
- 分拆：渠道、平台、新老用户、地区；找“步间转化差异最大”的分群
- pandas 思路：每个用户各步骤首次时间 `groupby(['user','step']).time.min().unstack()`，再按顺序与窗口判断
- 纯 SQL 思路：每步一个 CTE 取首次时间，LEFT JOIN 并加时间条件

## 留存与同期群
- 同期群：按首次行为（注册/首购）的周或月分组
- N 日留存：第 N 天（或第 N 周）有活跃的比例；区分“当日留存”与“N 日内留存（滚动）”
- 输出留存矩阵（行 = 同期群，列 = 周期序号），用热力图展示
- 右删失：观察期不足的格子留空，不当作 0
- 比较同期群时用相同周期序号，不要比较不同日历时间

## 分群
- RFM：最近一次（R）、频次（F）、金额（M）各按五分位打分，组合成 重要价值/重要挽留/新客/沉睡 等
- 行为分群：按核心功能使用组合；聚类（k-means）只在有 sklearn 时使用，并解释每群特征
- 每群给出：人数占比、收入占比、关键特征、建议动作

## 功能采纳与影响
- 采纳率 = 使用过功能的活跃用户 / 可用该功能的活跃用户
- 使用深度：人均使用次数、使用天数
- 影响评估优先用实验；没有实验时用 前后对比 + 对照组（双重差分），并说明假设（平行趋势）
- 警惕选择偏差：主动使用新功能的用户本来就更活跃

## 单位经济
- CAC = 获客总成本 / 新增付费客户数（口径：是否含人力、品牌投放）
- ARPU/ARPA = 收入 / 活跃用户（账户）
- LTV ≈ ARPU × 毛利率 / 月流失率（稳态近似）；或按同期群累计毛利
- 回收期 = CAC / (月 ARPU × 毛利率)
- LTV/CAC > 3 常被视为健康，但需结合回收期与现金流

## 渠道与营销
- 渠道 ROI = (归因收入 × 毛利率 − 成本) / 成本
- 归因模型：末次点击、首次点击、线性、位置加权；说明所选模型的偏差
- 增量性：有条件时用地域/时间分组实验或对照测算增量，而非仅看归因

## 流失
- 定义流失（如 30 天无活跃 / 订阅取消），与用户确认
- 流失率按同期群与分群比较
- 流失前行为：流失用户在最后 N 天的行为变化；只做描述，因果需谨慎
