# A/B 实验评估

## 评估前检查
1. **SRM（样本比例不匹配）**：实际分组人数与设计比例做卡方检验；p < 0.001 视为异常，结果不可信，先查分流/日志问题
2. **实验时长**：至少覆盖完整一周（周末效应）；检查是否提前停止
3. **预设主指标**：以实验设计文档中的主指标为准，避免事后挑指标
4. **分析单位 = 随机化单位**：按用户随机就按用户统计；按会话统计会低估方差

## 效应计算
- 比率型（转化率）：两比例 z 检验；差值 Δ = p_B − p_A，标准误 √(p_A(1−p_A)/n_A + p_B(1−p_B)/n_B)，95% CI = Δ ± 1.96·SE
- 均值型（人均收入）：Welch t 检验；长尾明显时用对数变换、截尾或自助法（bootstrap）
- 相对提升 = Δ / p_A；报告绝对值与相对值
- 纯标准库可实现：`math.erf` 计算正态分布 p 值；`random` 实现 bootstrap；有 scipy 时可用 `scipy.stats`

## 多重比较与分群
- 多个指标或多个分群时，使用 Bonferroni 或 Benjamini–Hochberg 校正，或把分群结果标为“探索性”
- 分群结论需要足够样本，且最好在实验前预设

## 检验力与样本量
- 每组样本量 n ≈ 2·(z₁₋α/2 + z₁₋β)²·p(1−p) / MDE²（比例型）
- 显著性不足时，报告“在当前样本下无法检测到小于 X 的效应”，而非“没有效果”

## 结论模板
| 指标 | 对照 | 实验 | 绝对差 | 相对差 | 95% CI | p 值 | 结论 |
- 决策建议：全量 / 不全量 / 延长实验 / 迭代后重测，附理由与护栏指标表现
- 新奇效应：对比实验前后半段效应
