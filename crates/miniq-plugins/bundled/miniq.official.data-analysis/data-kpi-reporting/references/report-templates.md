# KPI 汇报模板

## 1. 高管一页纸（周/月）
```markdown
# <业务> <周期> 经营简报（截至 YYYY-MM-DD）
**一句话**：<本期最重要的结论，含数字>

| 指标 | 本期 | 对比期 | 变化 | 目标达成 | 状态 |
|---|---|---|---|---|---|

## 重点变化（最多 3 条）
1. <结论句>：<数字>；主要由 <维度/因素> 贡献 <X%>
## 风险与需要的决策
- <风险> → 建议 <行动>（负责人）
## 口径说明
- 数据来源、截至时间、口径变化、已知问题
```

## 2. 运营周报（更细）
- 记分卡（含驱动指标与护栏指标）
- 各维度（渠道/地区/品类）小表或小多图
- 本周事件时间线与影响
- 上周行动项的跟进状态
- 下周计划

## 3. 季度复盘
- 季度目标达成总览（保底/目标/挑战）
- 月度趋势图与关键拐点说明
- 各举措效果评估（有实验/对照的写明方法）
- 下季度目标与调整

## 写作规范
- 数字：千分位；金额写单位（万元/百万美元）；比率变化用 pp（百分点）
- 状态：绿 ≥ 目标；黄 90%–100%；红 < 90%（或按指标自定义，但全文统一）
- 趋势描述使用对比基准：“较上周 +3.2%”“同比 −1.1pp”
- 原因分“已确认”与“待验证”
- 不堆砌指标：一页纸最多 8 个指标，其余放附录

## 进度（Pacing）计算
- 线性：应达 = 目标 × 已过天数 / 周期总天数
- 季节加权：应达 = 目标 × Σ历史同期已过天数权重
- 外推：期末预估 = 当前累计 / 应达比例；注明假设
