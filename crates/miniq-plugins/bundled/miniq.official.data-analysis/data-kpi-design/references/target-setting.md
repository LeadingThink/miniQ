# 目标设定方法

## 1. 基线外推
- 用最近 8–13 个周期的值估计趋势（线性或按增长率），以同比消除季节性
- 目标 = 基线趋势值 × (1 + 期望增量)；增量来自计划中的举措

## 2. 自下而上拆解
- 将主指标拆成驱动因子乘积或求和，例如 收入 = 活跃客户 × 购买频次 × 客单价
- 对每个因子估计可达变化，再合成；用 `data-market-sizing/scripts/sizing_model.py` 的敏感性分析看哪个因子最关键

## 3. 基准对标
- 同行业/同阶段公开基准、内部表现最好的分群或地区
- 注意定义与样本差异，仅作合理性检查

## 4. 分层目标
| 层级 | 含义 | 常见设定 |
|---|---|---|
| 保底 | 大概率可达（约 90%） | 基线趋势值 |
| 目标 | 努力可达（约 50%） | 基线 + 已规划举措的预期效果 |
| 挑战 | 小概率可达（约 10–20%） | 所有举措超预期 |

## 5. 合理性检查
- 目标隐含的增长率与历史最高增长率比较
- 各团队目标加总是否与公司目标一致（避免重复计算）
- 驱动指标目标与主指标目标在算术上是否自洽
- 护栏指标目标是否被主指标目标挤压

## 6. 进度追踪约定
- 周期内按日历进度或季节性权重计算“应达进度”
- 状态阈值：达成 ≥100% 绿；90–100% 黄；<90% 红（可按指标调整）
