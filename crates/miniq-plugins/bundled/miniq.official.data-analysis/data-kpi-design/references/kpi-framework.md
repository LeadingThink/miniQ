# KPI 框架与定义

## 指标层级
- **北极星/主指标**：最能代表为用户创造价值且与长期商业成果相关的单一指标
- **驱动指标**：可被团队直接影响、领先于主指标的输入指标
- **护栏指标**：必须守住的底线（质量、成本、体验、合规、风险）
- **诊断指标**：不设目标，用于解释变化（分渠道、分平台等）

## 常见业务的指标树示例
- 电商：GMV = 访客 × 转化率 × 客单价；护栏：退货率、履约时效、毛利率
- 订阅 SaaS：ARR/净收入留存；驱动：激活率、周活跃席位、扩容率；护栏：流失率、客服工单、毛利
- 内容/社区：有效活跃用户（完成核心动作）；驱动：新用户次日留存、人均核心动作；护栏：举报率、内容质量分
- 市场营销：获客成本、线索转化率、渠道 ROI；护栏：线索质量、品牌搜索量
- 运营/客服：首次响应时长、一次解决率；护栏：满意度、单工单成本

## 候选评分（每项 1–5 分）
| 维度 | 问题 |
|---|---|
| 相关性 | 指标变好是否意味着目标更接近？ |
| 可影响性 | 负责团队能否通过行动改变它？ |
| 可度量性 | 数据是否可靠、口径是否清晰？ |
| 时效性 | 能否在决策周期内看到变化？ |
| 抗操纵 | 能否被不创造价值的方式刷高？ |
| 易理解 | 非专业读者能否一句话理解？ |

## 指标定义卡
```markdown
### 指标：<名称>
- 目的：回答什么问题 / 支持什么决策
- 公式：<分子> / <分母>
- 粒度与维度：按 <日/周/月>，可按 <渠道/地区/平台> 切分
- 过滤：剔除 <测试/内部/退款> ；去重键：<...>
- 时间归属与时区：<...>
- 数据源：<表/文件>，刷新：<频率>，延迟：<...>
- 好的方向：↑ / ↓；正常波动区间：<...>
- 负责人：<...>
- 已知局限与可能的操纵方式：<...>
```

## 常见错误
- 虚荣指标（累计注册数、页面浏览量）作为主指标
- 只有比率没有规模（转化率上升但流量腰斩）
- 指标之间无因果/逻辑联系
- 目标只有一个点值，没有区间和依据
- 频繁改口径导致历史不可比
