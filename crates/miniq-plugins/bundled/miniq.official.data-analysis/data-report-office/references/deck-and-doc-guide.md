# Word 与 PPT 版式指南

## Word 报告
- 封面信息：标题（结论式）、副标题、作者、日期、数据截至时间
- 第一页放摘要与关键发现，细节放后文
- 标题只用 1–3 级；正文段落 ≤ 5 行
- 表格：表头加粗、数字右对齐、单位写在表头、表格上方写表题
- 图片：宽度不超过正文宽度，图下方写“图 N：结论句（来源、截至日期）”
- 附录：方法、口径、复现信息

## PPT 汇报故事线
1. 标题页：结论式标题 + 日期
2. 一页摘要：3 条关键结论 + 1 条建议
3. 背景/问题（可选，1 页）
4. 发现 1…N：每页一个观点，标题即结论，正文一张图或 3–5 条要点
5. 建议与下一步：行动、负责人、时间
6. 附录：口径、方法、补充图表

## 幻灯片规则
- 一页一个信息；标题 ≤ 2 行
- 要点 ≤ 5 条，每条 ≤ 2 行
- 字号：标题 28–36pt，正文 ≥ 16pt，图表标签 ≥ 12pt
- 图表占页面主要区域；关键数字可用大字号单独呈现
- 颜色与看板/报告保持一致

## 导入在线平台
- Google Docs / Slides：在 Google Drive 上传后“用 Google 文档/幻灯片打开”
- 飞书/钉钉/腾讯文档：均支持“导入 Word/PPT”
- 导入后检查字体与表格宽度
