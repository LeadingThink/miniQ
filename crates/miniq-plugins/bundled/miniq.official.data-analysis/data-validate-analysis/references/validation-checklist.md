# 分析校验清单

## A. 问题与框架
- [ ] 分析回答的是用户/决策者真正要问的问题，而不是一个相近但更容易的问题
- [ ] 总体定义清楚（谁被纳入、谁被排除、为什么）
- [ ] 对比基准合理：环比、同比、目标、对照组、同类实体；季节性已考虑
- [ ] 时间窗与时区明确；首尾不完整周期已处理
- [ ] 结论的范围与证据的范围一致（不把一个渠道的结论推广到全体）

## B. 指标口径
- [ ] 分子、分母、去重键、过滤条件、时间归属（下单时间 vs 支付时间）写清
- [ ] 与团队已有定义一致（查 `data-context-layer` 语义层或业务文档）
- [ ] 比率在汇总时用 Σ分子/Σ分母，而非各组比率的平均
- [ ] 货币单位、汇率、含税/不含税、退款处理一致

## C. 数据处理
- [ ] 连接类型正确；一对多连接未造成金额重复
- [ ] 过滤条件没有意外丢掉 NULL（`WHERE col <> 'x'` 会排除 NULL）
- [ ] 缺失值处理方式说明并评估影响
- [ ] 测试/内部/机器人流量已剔除
- [ ] 去重逻辑正确（按什么键、保留哪一条）

## D. 计算
- [ ] 至少 3 个关键数字从原始数据复算
- [ ] 分项之和 = 总计；占比之和 ≈ 100%
- [ ] 增长率基数正确（(本期-基期)/基期），百分点与百分比区分
- [ ] 同比对齐同样的天数与星期结构
- [ ] 累计值、滚动平均的窗口正确

## E. 合理性
- [ ] 数量级与常识/历史一致（转化率 80%？人均消费 10 万？）
- [ ] 变化幅度在历史波动区间内，或有解释
- [ ] 意外结论经过第二条路径验证

## F. 统计推断
- [ ] 样本量足够；给出置信区间或至少样本数
- [ ] 显著性检验方法与数据类型匹配；多重比较已校正或已说明
- [ ] 实验：随机化检查（SRM 样本比例不匹配）、新奇效应、干扰、提前停止
- [ ] 因果表述有设计支撑（实验、双重差分、断点等），否则用相关性措辞

## G. 可视化与呈现
- [ ] 柱状/面积图从 0 起；差异/瀑布图若不从 0 起需清楚标注
- [ ] 轴标签、单位、时间范围、数据来源与截至日期齐全
- [ ] 对比图使用一致刻度；双轴、截断轴、3D 需要理由
- [ ] 类别排序服务于比较；颜色语义前后一致（同一实体同一颜色）
- [ ] 标题陈述的结论与数据一致，不夸大
- [ ] 数字格式与精度合适（不写 12.3456%）
- [ ] 限制与说明放在对应结论旁边

## H. 可追溯与完整
- [ ] 数据来源、查询/脚本路径、Notebook 路径、截至时间可查
- [ ] 用户要求的章节全部存在；缺失的说明原因
- [ ] 未验证的结论已显式标注
