# 常见统计与分析陷阱

| 陷阱 | 表现 | 检查方法 | 处理 |
|---|---|---|---|
| 辛普森悖论 | 整体趋势与各分组趋势相反 | 按主要维度拆分后比较方向 | 同时报告整体与分组，并做结构/率效应分解（`decompose_change.py`） |
| 均值的均值 | 直接平均各组比率 | 检查是否有分组样本量差异 | 用 Σ分子/Σ分母 或加权平均 |
| 分母漂移 | 比率变化其实来自分母口径变化 | 分子分母分别画趋势 | 固定口径或拆开解释 |
| 幸存者偏差 | 只分析留下来的用户/存活的商品 | 检查被排除的样本 | 纳入流失者或说明 |
| 选择偏差 | 分组依据是结果本身（如“活跃用户留存更高”） | 分组变量是否在处理/结果之前确定 | 用处理前特征分组 |
| 回归均值 | 极端值下一期自然回落被当成干预效果 | 与未干预的同类对比 | 设对照组 |
| 小样本 | 小组的比率剧烈波动 | 列出每组 n | 合并小组、给置信区间、标注 |
| 多重比较 | 测了 20 个分群总有 1 个“显著” | 数一数检验次数 | Bonferroni/BH 校正，或作为探索性结论 |
| 挑选时间窗 | 起止点刚好让结论成立 | 换几个窗口看是否稳健 | 报告多个窗口或说明选择理由 |
| 前视偏差 | 使用了当时还不知道的信息 | 特征时间 ≤ 预测时间 | 严格时间切分 |
| 时区错配 | 不同来源日切点不同 | 核对时区 | 统一时区并注明 |
| 极端值主导 | 均值被少数大客户拉动 | 看中位数与分布 | 报告中位数/截尾均值/分层 |
| 相关≠因果 | 同期变化被说成原因 | 是否有实验或准实验设计 | 改用“相关/同期”措辞，建议验证方法 |
| 季节性 | 把节假日效应当成趋势 | 同比、同星期对齐 | 同比或季节调整 |
| 不完整周期 | 本月只过了 10 天却与上月整月比较 | 检查周期天数 | 同期对比或按天均值/外推并说明 |
