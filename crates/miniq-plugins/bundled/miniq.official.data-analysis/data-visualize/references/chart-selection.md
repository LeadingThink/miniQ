# 图型选择

| 想表达 | 推荐 | 可选 | 避免 |
|---|---|---|---|
| 随时间变化 | 折线图 | 面积图（总量）、柱状图（少量时间点） | 饼图 |
| 类别对比 | 横向条形图（排序） | 柱状图、点图 | 雷达图、3D 柱 |
| 构成/占比 | 100% 堆叠条、堆叠柱 | 饼图（≤5 类）、树图 | 多个饼图对比 |
| 构成随时间变化 | 堆叠面积、100% 堆叠柱 | 小多图折线 | 多个饼图 |
| 分布 | 直方图、箱线图 | 小提琴图、分位数表 | 只给均值 |
| 两变量关系 | 散点图（+趋势线） | 气泡图（第三变量） | 双轴折线暗示相关 |
| 变化分解/桥接 | 瀑布图 | 分组条形 | 堆叠柱 |
| 流程转化 | 漏斗条形图 | 桑基图（多路径） | 饼图 |
| 两维矩阵（同期群、热区） | 热力图 | 表格加色阶 | 3D 曲面 |
| 目标达成 | 子弹图、进度条 | KPI 卡片 | 仪表盘指针 |
| 排名变化 | 斜率图 | 凹凸图 | 多条交叉折线 |
| 地理 | 分级地图（需地图数据） | 按地区排序条形图 | 气泡叠加难比较 |

## 决策小抄
1. 读者要比较的是什么？——大小、变化、占比、分布、关系
2. 有几个变量、多少类别、多少时间点？
3. 读者是谁？高管：少而清晰；分析师：可更密
4. 这张图的一句话结论是什么？图型应让这句话一眼可见

## 多系列
- ≤ 4 条折线直接标注在线尾，省去图例
- 系列多时用小多图（small multiples），共享坐标轴
- 强调一个系列：其余灰色
