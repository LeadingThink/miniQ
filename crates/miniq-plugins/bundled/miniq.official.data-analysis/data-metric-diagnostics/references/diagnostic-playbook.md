# 诊断方法手册

## 1. 加法指标的维度贡献
对总量 Y = Σ yᵢ（i 为某维度的分群）：
- 分群贡献 Δᵢ = yᵢ(当期) − yᵢ(基期)，Σ Δᵢ = ΔY
- 贡献占比 = Δᵢ / ΔY（ΔY 接近 0 时改看绝对值并说明）
- 新出现/消失的分群单独列出
- 对每个维度计算“集中度”：|最大 Δᵢ| / Σ|Δᵢ|，越高说明该维度越能解释变化

## 2. 比率指标的结构/率分解
R = Σ wᵢ · rᵢ，其中 wᵢ = 分母ᵢ / Σ分母（结构），rᵢ = 分子ᵢ / 分母ᵢ（分群率）
- 率效应（rate）= Σ w̄ᵢ · Δrᵢ
- 结构效应（mix）= Σ r̄ᵢ · Δwᵢ
- 取两期平均权重/率（对称分解），两者之和严格等于 ΔR
- 辛普森悖论信号：多数分群 Δrᵢ 与 ΔR 符号相反，而 mix 效应占主导

## 3. 乘法指标
Y = A × B × C（如 访客 × 转化率 × 客单价）：
- 对数分解：Δln Y = Δln A + Δln B + Δln C，各因子贡献按比例分配到 ΔY
- 适合解释“收入下降主要来自流量还是转化”

## 4. 时间形态判断
| 形态 | 典型原因 | 下一步 |
|---|---|---|
| 阶跃（某日起整体平移） | 发版、埋点/口径变更、定价、渠道开关 | 找当天事件与受影响分群 |
| 渐变 | 季节性、竞争、产品体验逐步变化、用户结构变化 | 同比、分群趋势 |
| 单日尖峰 | 活动、故障、重复加载、机器人流量 | 查明细与去重 |
| 周期性 | 周末效应、月初发薪、结算周期 | 同星期对比 |
异常点检测：滚动中位数 ± k·MAD（k≈3），比均值±3σ 对尖峰更稳健。

## 5. 事故/回退分析
1. 精确定位开始/恢复时间（小时粒度更好）
2. 找出受影响与未受影响的分群（平台、版本、地区、渠道）——差异即线索
3. 量化损失：用未受影响分群或历史同期构造反事实基线，损失 = 基线 − 实际
4. 与变更记录对齐（git log、发布记录、配置变更）

## 6. 集中度与头部依赖
- Top N 贡献占比、帕累托曲线（前 20% 实体贡献多少）
- 增长是否来自少数客户/商品；若头部波动大，结论需分层表述

## 7. 对账差异
按顺序对齐并记录每一步的差额：
1. 实体范围（哪些账户/门店/产品） 2. 时间范围与时区 3. 过滤（测试、退款、取消） 4. 去重键 5. 连接与维表版本 6. 货币/汇率/税 7. 数据延迟与快照时间
最后剩余的无法解释差额单独列出。

## 8. 结论表述
- “5 月转化率下降 1.8pp，其中 1.3pp 来自低转化的新渠道 X 流量占比上升（结构效应），各渠道自身转化率基本持平（率效应 −0.2pp）。”
- 避免：“转化率下降是因为用户体验变差了”（无证据）
