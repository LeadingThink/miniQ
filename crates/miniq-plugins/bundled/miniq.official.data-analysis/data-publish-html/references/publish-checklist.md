## 敏感信息
- [ ] 无个人身份信息（姓名+联系方式、手机号、邮箱、身份证、地址）
- [ ] 无客户/合同级明细，除非授权
- [ ] 无密钥、令牌、内部系统地址、数据库连接串
- [ ] 嵌入的 JSON 数据只含展示所需聚合结果（用 `file_grep` 搜索 `application/json` 块检查）
- [ ] HTML 注释与隐藏元素中无内部信息
- [ ] 小样本分组已合并或抑制（避免反推个体）

常用搜索模式（`file_grep`）：
- 手机号：`1[3-9]\d{9}`
- 邮箱：`[\w.+-]+@[\w-]+\.[\w.]+`
- 身份证：`\d{17}[\dXx]`
- 密钥：`(?i)(api[_-]?key|secret|token|password)\s*[:=]`
