# Notebook 安全注意

- 执行 notebook 会运行其中全部代码。来源不明的 notebook 先用 `file_read` 审阅：删除/覆盖文件、网络请求与上传、`!` shell 命令、`%run`/`exec`/`eval`、安装包、读取凭据文件等，列出后向用户确认再执行。
- 不在 notebook 中写入密钥或密码，改用环境变量（`os.environ`）读取；已有明文密钥时提醒用户轮换。
- 输出单元格可能包含个人数据或内部数字，分享前清空输出或检查。
- 覆盖原 notebook 前先备份为 `<名称>.bak.ipynb`。
- 安装依赖前先征得用户同意，优先装在项目虚拟环境中。
- 不依赖交互式 Jupyter 界面，所有操作通过命令行完成；不要启动对外监听的 Jupyter 服务器。
