# 常用平台尺寸与安全区

尺寸会随平台更新变化；以下为常见做法，重要投放前请以平台最新规范为准（可用 `web_search` 核实）。

| 用途 | 尺寸（px） | 比例 | 安全区建议 |
| --- | --- | --- | --- |
| 小红书笔记封面 | 1242x1660 或 1080x1440 | 3:4 | 底部约 15% 可能被标题栏遮挡 |
| 微信朋友圈 / 公众号配图 | 1080x1080 | 1:1 | 四周各留 6% |
| 公众号头图 | 900x383 | 2.35:1 | 主体居中，分享卡片会裁为 1:1 |
| 抖音 / 视频号 / 故事竖版 | 1080x1920 | 9:16 | 上 14%、下 20% 避开界面元素 |
| 信息流竖图 | 1080x1350 | 4:5 | 四周 5% |
| 横版链接广告 | 1200x628 | 1.91:1 | 文字面积尽量少 |
| 电商主图 | 800x800 或 1000x1000 | 1:1 | 主体占 70–85%，纯净背景 |
| 网站首屏 Banner | 1920x1080 / 1920x600 | 16:9 / 3.2:1 | 文字置于中间 1200px 内 |
| 演示文稿封面 | 1920x1080 | 16:9 | 四周 5% |
| 头像 / Logo 预览 | 512x512 | 1:1 | 圆形裁切时内切圆内 |

## 多尺寸工作法
1. 以最竖或最横的那个尺寸先排版，确定信息层级。
2. 其他尺寸复制 HTML，只调 `data-layout`、字号与留白，不改文字内容。
3. 纯图片派生（无文字）用 `fit.sh cover`；主体靠边容易被裁时用 `contain` 补边。
4. 全部导出后运行 `export_check.py` 一次性核验。
