# 契约：源主体保真（source-preservation）

适用：用户提供了产品图、包装、人物、logo、界面截图等，要求放进新场景、换角度或做变体。

## 规则
1. **用 `edit_image`**，`image_path` 指向用户原图（不要先重新生成一个“相似”的主体）。
2. 提示词结构：先写“保持 <主体> 的形状、比例、颜色、材质、logo 与文字完全不变”，再写要改变的部分（背景、光线、机位、道具）。一次只改一类。
3. 生成前先 `view_image` 看源图，记录**保真清单**写入 `creative/source-notes.md`：
   - 轮廓与比例（如“高宽约 3:1，顶部圆角”）
   - 主色与辅色（尽量写具体，如“哑光墨绿 + 金色瓶盖”）
   - logo / 文字的位置、颜色、内容
   - 关键结构：按键、接口、缝线、图案的数量和位置
   - 材质：光面 / 磨砂 / 透明
4. 源图分辨率很低或主体被遮挡时，先告诉用户，询问是否有更好的图。

## 核对（每张结果）
用 `view_image` 同时查看源图与结果（必要时用 `render.sh` 渲染并排对比 HTML），逐条对照保真清单：
- [ ] 形状与比例一致，无拉伸、变胖、变形
- [ ] 颜色一致（环境光造成的自然变化可以接受，色相不能变）
- [ ] logo 与包装文字未被改写、未镜像、未消失
- [ ] 结构件数量与位置一致
- [ ] 没有凭空添加源图不存在的部件

## 不合格时
- 第 1 次：在提示词中加强被破坏的那一条（例如“logo 位于正面中央上方，白色，不可改变”），重试。
- 第 2 次：缩小改动范围（只换背景、保留原机位）。
- 仍失败：采用合成方案——生成无主体的空场景，把源图（去背景后）在 HTML 中叠放，或如实告知限制。
