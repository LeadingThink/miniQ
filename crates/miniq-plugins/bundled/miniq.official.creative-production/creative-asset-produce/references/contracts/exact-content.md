# 契约：精确内容（exact-content）

适用：任何成品上需要出现**可读文字或精确数据**时——标题、卖点、CTA、价格、日期、品牌名、图表数字、法律声明、页码。

## 规则
1. **生图阶段不写字**。提示词中写“画面中没有任何可读文字、字母、数字、标签或水印”，并描述文字将要放置的留白区域。
2. **文字在后期叠加**：用 `creative-layout-deliver` 的 `layout.html` 模板（或自写 HTML/SVG）以真实字体排版，再用 `render.sh` 渲染。
3. **唯一来源**：所有文字从用户原话、`creative/brief.md` 或用户提供的文件中逐字复制，写入 `creative/copy.md`；不润色数字、不改单位、不补全用户没给的信息。
4. **品牌名 / logo 字标**：若生图结果里出现了品牌名，逐字核对；有误则去掉文字部分，改为确定性排版。
5. **图表**：数据先抄录为结构化文件（JSON/CSV），由代码绘制；生图只提供无字的装饰层。

## 例外
- 用户明确要“手写感 / 招牌效果”且接受不精确时，可让模型生成文字，但交付时标注“文字为生成效果，需人工核对”。
- 用户提供的真实包装上已有的文字，经 `edit_image` 保留时要与源图逐字一致。

## 核对清单（交付前）
- [ ] `view_image`（`detail: original`）逐字对照 `copy.md`：错字、漏字、标点、数字、单位。
- [ ] 没有出现 `copy.md` 以外的文字（包括模型生成的伪文字）。
- [ ] 文字与背景对比度足够，未压在主体关键部位上。
- [ ] 价格、日期、法务信息已由用户确认。
