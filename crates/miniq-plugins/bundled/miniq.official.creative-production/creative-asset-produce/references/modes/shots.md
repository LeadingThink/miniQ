# 模式：多机位（shots）

目标：主体保持完全一致，只改变**机位、景别与构图**，得到一套可以组合使用的镜头。**必须**加载 `contracts/source-preservation.md`。

## 默认 8 个机位
| key | 机位 | 说明 |
| --- | --- | --- |
| overhead | 正俯拍 | 90° 顶视，适合平铺与图案感 |
| three-quarter | 四分之三侧 | 约 45° 前侧，最能表现体积 |
| side | 正侧面 | 轮廓清晰，适合展示厚度 / 线条 |
| wide | 远景 | 主体较小，环境交代完整 |
| close-up | 近景特写 | 主体填满画面主要部分 |
| macro | 微距 | 材质、接缝、按键等细节 |
| low-hero | 低角度英雄 | 从下往上拍，显得强大、有存在感 |
| surprise | 意外角度 | 一个非常规视角（透过玻璃、倒影、极近前景虚化等），每次只选一个 |

## 一致性规则
- 用同一张源图作为 `edit_image` 的 `image_path`；背景与光线风格在所有机位中保持一致（写入风格锁定块），只变机位。
- 提示词中明确：“保持产品的形状、比例、颜色、材质、logo 位置与源图完全一致”。
- 源图没有展示的面（如背面）不要凭空编造细节；此类机位可以改为局部遮挡或阴影处理，并在交付中说明。

## 质检
- 每张与源图并排比较（可先用 `creative-layout-deliver/scripts/render.sh` 渲染两图并排的 HTML，再 `view_image`）：轮廓比例、颜色、logo、按键 / 接口数量与位置。
- 8 个机位确实不同，没有两张几乎一样的构图。
