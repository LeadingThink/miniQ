# 模式：场景植入（scenes）

目标：把主体放进**真实可信的商业场景**。用户提供了产品图 / 截图 / logo 等源主体时，**必须**加载 `contracts/source-preservation.md`，并使用 `edit_image`。

## 场景库（选 4–6 个不同类型）
| 类型 | 例子 |
| --- | --- |
| 居家 | 厨房台面、书桌、浴室架、客厅茶几 |
| 办公 | 会议桌、工位、共享空间 |
| 户外 | 露营桌、街头长椅、海边、山道 |
| 零售 | 精品店层架、超市端架、快闪柜台 |
| 餐饮 | 咖啡馆吧台、餐桌布置 |
| 工作室 | 无缝背景纸 + 道具的棚拍 |
| 季节 / 节日 | 雪景窗边、春日野餐、节日礼盒桌 |
| 设备样机 | 手机、笔记本、平板、户外大屏、公交站灯箱 |

## 真实感要点
- 比例：主体相对于手、桌面、门框的尺寸要合理，在提示词中写明参照物。
- 光线：主体的光向、色温与环境一致，要有接触阴影与反射。
- 道具：少而相关，不喧宾夺主；不出现他人品牌。

## 设备样机特别说明
- 屏幕内容必须是用户提供的真实截图或设计稿。
- 推荐：先生成“屏幕为纯色 / 关闭状态”的设备场景，再在 `creative-layout-deliver` 中把截图贴到屏幕区域；或 `edit_image` 以截图为源让模型只生成外围设备与环境。
- 合成后逐字核对屏幕内文字未被改写或模糊。

## 质检
- 源主体的形状、颜色、logo、比例未变（逐项对照源图）。
- 无悬浮感：阴影、接触点、透视正确。
- 各场景类型彼此不同。
