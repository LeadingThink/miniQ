# 模式：视觉风格（styles）

目标：为同一主体探索不同的**视觉系统**，选定后生成“风格锁定块”，用于轮播、系列海报、模板多变体。

## 五个风格维度
| 维度 | 可选值举例 |
| --- | --- |
| 色板 | 单色、互补高对比、低饱和莫兰迪、品牌色 + 中性色、夜间霓虹 |
| 字体气质（仅用于留白与后期排版参考） | 几何无衬线、人文衬线、手写、粗黑体 |
| 质感 | 光面、磨砂、纸张颗粒、胶片噪点、3D 渲染、水彩 |
| 光线 | 柔和漫射、硬光强影、逆光轮廓、窗光、霓虹彩光 |
| 构图 | 居中对称、三分法、大面积留白、满版、网格 |

每个方向在至少 3 个维度上与其他方向不同；给每个方向起一个短名称（如“晨雾纸感”“霓虹夜行”）。

## 风格锁定块
用户选定方向后，把该方向写成一段可复用文本并存入 `creative/style-lock.md`，格式：
```
色板：…（写出 3–5 个具体颜色描述或 HEX）
质感：…
光线：…
构图：…
镜头：…（焦段感、景深）
禁止：可读文字、水印、他人商标
```
后续所有同系列图片把这段原样放入提示词末尾（`variants.py --style` 参数）。

## 模板多变体
- 有模板源图时：用 `edit_image`，每个变体只改一个变量（配色 / 主体 / 背景 / 季节），版式骨架不变。
- 文字部分不交给生图，交付阶段统一排版。

## 质检
- 并排看缩略图，风格差异明显。
- 选定后的系列图，锁定维度确实一致（色板、光线无跳变）。
