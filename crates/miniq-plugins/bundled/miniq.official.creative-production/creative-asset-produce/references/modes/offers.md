# 模式：产品 / 服务呈现（offers）

目标：同一个“卖的东西”在不同**使用场合与展示界面**下的呈现方式。有源图时加载 `contracts/source-preservation.md`。

## 呈现方式库（默认取 6 个）
| 方式 | 画面 | 用途 |
| --- | --- | --- |
| 英雄展示 | 产品 / 服务的代表性单一画面，光线讲究 | 首页首屏、主视觉 |
| 使用中 | 真实人物正在使用或受益的瞬间 | 社媒、详情页 |
| 电商主图 | 纯净背景、完整可见、无遮挡 | 商品列表 |
| 落地页首屏 | 宽幅构图，一侧大面积留白放标题 | 网站 |
| 零售陈列 | 货架、柜台、门店环境中的样子 | 线下 / 渠道提案 |
| 活动现场 | 发布会、快闪、展台中的呈现 | 活动推广 |
| 功能证明 | 用画面演示一个关键功能（不写数字） | 说明型素材 |
| 编辑部风 | 杂志内页般的构图与留白 | 品牌内容 |

服务类（课程、咨询、App）没有实物时：用“人物 + 环境 + 结果状态”表达，屏幕内容留空或用用户提供的截图后期合成。

## 禁止项
- **不编造价格、折扣、套餐名、库存、限时信息**；不出现价签上的数字。
- 功能证明只表现“能做什么”的画面，不添加测试数据、百分比、认证。
- 电商主图遵循平台常见规范：主体完整、无多余装饰、无文字水印。

## 质检
- 产品外观与源图一致（形状、颜色、logo、比例）。
- 每个方式的用途一眼可辨；落地页首屏的留白确实足够放标题。
