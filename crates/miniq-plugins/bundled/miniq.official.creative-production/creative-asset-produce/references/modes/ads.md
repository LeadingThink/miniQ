# 模式：广告（ads）

目标：同一个产品 / 服务，给出几条**商业逻辑不同**的广告路线，而不是同一张图换滤镜。

## 路线库（按需挑 4–6 条，彼此不重复）
| 路线 | 画面核心 | 适合 |
| --- | --- | --- |
| 英雄主图 | 产品居中、干净背景、强光比 | 品牌认知、电商首图 |
| 使用瞬间 | 真实人物正在使用，产品清晰可辨 | 生活方式类 |
| 痛点对照 | 用画面暗示“没有它”的麻烦（不做前后对比拼图，单图表达） | 功能型产品 |
| 感官特写 | 材质、液体、蒸汽、纹理的微距 | 食品饮料、美妆 |
| 场景氛围 | 产品只占画面 1/4，环境讲情绪 | 高端、生活方式 |
| 创意隐喻 | 用夸张或超现实的视觉比喻表达一个利益点 | 社媒吸睛 |
| 平铺陈列 | 俯拍 knolling，产品与配件整齐排列 | 套装、配件多 |
| 社群 / UGC 感 | 手机随手拍质感、自然光 | 信息流原生感 |

## 构图要求
- 每条路线一张单图；主体清晰、可识别。
- 预留文字区：在提示词里写明“画面上方 / 下方约 30% 为干净留白，用于后期排版”，但**不在图中生成任何可读文字**。
- 竖版信息流默认 4:5，故事 / 短视频封面 9:16。

## 禁止项
- 不编造功效、数据、价格、折扣、限时信息。
- 不生成用户评价、星级、“专家推荐”、奖项、认证徽章、检测标志。
- 不出现竞品商标、名人肖像、可读的法律条款或小字免责声明。
- 所有标题 / 卖点 / CTA 均在交付阶段按 `contracts/exact-content.md` 叠加。

## 质检重点
- 各路线的第一眼印象是否不同（遮住文字区看缩略图也能分辨）。
- 图中无伪文字、乱码标签；产品包装上的文字若为用户真实包装，应与源图一致，否则保持无字或模糊。

## 推荐时怎么讲
每条路线一句话：“适合 X 渠道 / X 受众，靠 Y 打动人”。推荐 1–2 条并说明理由。
