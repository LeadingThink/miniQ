# 模式：Logo（logos）

目标：探索**不同的标识家族**，而不是同一个图形的六种配色。

## 家族库（每个方向选不同家族）
| 家族 | 描述 |
| --- | --- |
| 字标 | 以品牌名字形为主体，重在字距与字形个性 |
| 字母组合 | 首字母或缩写组合成紧凑符号 |
| 抽象符号 | 几何或有机形体，不直接描述行业 |
| 具象图形 | 与品牌含义相关的简化图形 |
| 徽章 / 印章 | 图形与文字封装在外框内 |
| 吉祥物 / 角色 | 友好角色形象，适合大众消费 |
| 负形 / 巧思 | 利用正负空间藏一个二重含义 |
| 动态 / 可变 | 一套可变形的系统，给出其中一个代表形态 |

## 生成规范
- 每张单独一个 logo，纯色背景，居中，四周留足空白；不画在名片、T 恤、墙面上（样机另作 scenes 任务）。
- 平面矢量感：明确写“扁平、清晰轮廓、少于 3 种颜色、可缩小到 16px 仍可辨认”。
- 品牌名文字生图容易拼错：可以让模型尝试，但交付前必须 `view_image` 逐字核对；拼错则改为“图形 + 确定性排版字标”（字标在 `creative-layout-deliver` 中用真实字体排）。
- **不要手写 SVG 占位图冒充设计结果**。若用户需要矢量文件，说明当前是位图概念稿，矢量化需要专门的描摹 / 设计环节。

## 禁止项
- 不模仿知名品牌 logo，不使用他人商标元素。
- 不编造“品牌手册”“设计规范”页面、色值体系或字体授权说明；只有用户确认方向后，才基于实际图片提取颜色写一页简要说明，并标注为建议。

## 质检
- 缩小到约 64px 查看（`sips -Z 64` 后 `view_image`）是否仍可辨认。
- 黑白单色下是否成立。
- 各方向是否属于不同家族。
