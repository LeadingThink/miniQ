# 出图策略（image-building-strategy）

## 提示词结构（按顺序）
1. **主体**：是什么，关键可识别特征（颜色、材质、形状）。有源图时写“保持源图主体不变”。
2. **方向意图**：这张图要表达什么（一句话）。
3. **场景 / 环境**：地点、时间、道具（少而具体）。
4. **构图与机位**：景别、角度、主体位置、留白位置与比例。
5. **光线**：光源方向、软硬、色温。
6. **风格锁定块**：系列统一时原样粘贴（见 `modes/styles.md`）。
7. **约束**：无可读文字、无水印、无他人商标、单张图非拼贴、比例正确。

写具体名词而不是形容词堆砌：“清晨窗边斜射的暖光、木质桌面上的细长影子”优于“温馨、高级、氛围感”。

## 一次只改一个变量
- 探索阶段：不同方向之间可以多维度不同。
- 迭代阶段（用户已选定某方向）：每轮变体只改一个变量（例如只换背景色，或只换机位），其余逐字不变，这样用户能判断是哪个改动带来的效果。在看板中用 `--parent` 记录衍生关系，`--prompt` 记录完整提示词。

## 画幅
- 生成时就用接近最终用途的画幅（`size` / `aspect_ratio` 参数），避免后期大幅裁切丢失主体。
- 多平台时：以最“挑剔”的画幅构图（主体居中、四周留余量），其他尺寸在导出阶段裁切。

## 重试策略
| 问题 | 调整方法 |
| --- | --- |
| 出现伪文字 | 约束句提前，并写“标签和屏幕为空白” |
| 主体变形 / 走样 | 改用 `edit_image` 以源图为基础；缩小改动范围 |
| 方向之间太像 | 换掉场景和机位两个维度，而不是只换颜色 |
| 画面太杂 | 删减道具，写明“背景简洁、只有 X 和 Y” |
| 手 / 脸畸变 | 减少人物数量，改为局部（手持特写）或背影 |
| 风格跳变 | 检查风格锁定块是否被改动；逐字复用 |

同一方向最多重试 2 次；每次只改 1–2 处并在看板 `retry --prompt` 中留下新提示词。仍不行就换思路或如实说明。

## 并行
- 每个方向独立、无先后依赖，适合 `agent_run` 并行（≤4 路）。
- 迭代变体依赖父图时，必须等父图 `done` 并通过质检后再开始。
