# 简报模板与安全默认值

## brief.md 模板

```markdown
# 创意简报：<项目名>

## 用户给出的事实（逐字）
- 主体 / 产品：
- 品牌名（准确写法）：
- 必须出现的文案：
- 价格 / 日期 / 数据 / 法务信息：
- 源图 / 参考资料路径：

## 目标
- 用途与渠道：
- 目标受众：
- 希望对方看完做什么：

## 假设（由助手推断，可随时推翻）
- ...

## 禁止事项
- 不编造价格、功效、认证、奖项、背书、用户评价
- 不使用竞品标志或他人商标
- 

## 生产计划
- 模式：
- 方向数：
- 画幅：
- 看板目录：creative/board
```

## 缺信息时的安全默认值

| 缺什么 | 默认值 | 说明 |
| --- | --- | --- |
| 渠道 | 社交信息流 | 画幅 4:5，兼顾手机屏占比 |
| 画幅 | 按模式：ads/offers/scenes/styles 4:5，logos/shots 1:1，charts 16:9 | 交付阶段再扩展尺寸 |
| 方向数 | 4–6 | shots 默认 8 个机位 |
| 受众 | 由产品品类推断的一般消费者 | 写入“假设” |
| 风格 | 不预设，由不同方向本身覆盖 | 避免 6 个方向同一风格 |
| 色彩 | 用户资料中的品牌色；没有就不锁定 | |
| 文案 | 不写 | 生图阶段一律无可读文字 |
| 语言 | 与用户对话语言一致 | 后期排版时使用 |

## 何时必须问而不能默认
- 品牌名的准确写法（Logo 任务）。
- 需要出现在成品上的价格、日期、法律声明。
- 需要源图的模式却完全没有主体信息（连品类都不知道）。
