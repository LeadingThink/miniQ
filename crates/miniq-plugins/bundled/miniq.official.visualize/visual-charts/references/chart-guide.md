# 图表选型与绘制要点

## 选型
| 目的 | 首选 | 备注 |
|---|---|---|
| 随时间的趋势 | 折线（点少时加标记） | 多系列 ≤5 条，更多时拆成分面小图 |
| 类别比较 | 条形图 | 类别 >8 或名称较长时用横向条形，并按数值排序 |
| 占比 | 环图（≤6 类） | 类别多，或需要跨期比较时，用 100% 堆叠条形 |
| 分布 | 直方图 / 箱线图 | 标注样本量 n |
| 相关性 | 散点图 | 点很多时降低透明度或做分箱热力图 |
| 并行任务、时序 | 同一时间轴上的泳道图 | 状态用颜色区分，时长用长度表示 |
| 多指标对比 | 共享刻度的分面小图 | 避免双 Y 轴；一定要用时，明确标注左右轴 |
| 地理 | 分级设色地图 | 地图数据要内联，并注明来源 |

## 绘制要点
- **标题**：简洁、可见，写出“是什么、哪段时间、什么单位”。
- **坐标轴**：数值轴标注单位，使用千分位格式（`toLocaleString("zh-CN")`）。条形图的数值轴从 0 开始；折线图可以不从 0 开始，但要说明。
- **定义域**：用全部观测值算出范围，再适当留白（D3 用 `d3.extent` 加 `.nice()`）。
- **防重叠**：每次绘制后检查刻度和数据标签是否重叠。重叠时减少刻度数、旋转标签或省略部分标签。
- **自适应**：
  - SVG 的 `viewBox` 按容器实际宽度设置，并用 `ResizeObserver` 在尺寸变化时重绘。
  - ECharts 设置 `grid.containLabel: true`，并调用 `chart.resize()`。
- **交互**：
  - 用一个共享的 tooltip 显示数据。
  - 有序序列用 `d3.bisector(d => d.x).center` 查找最近的点。
  - 孤立的数据点加透明的命中区域，宽度 ≥32px。
  - 重要信息不能只靠悬停才能看到。
- **重点标注**：最大值、最新值、拐点可以直接加标签。图例放在靠近数据的位置，只放一个。
- **说明**：页面上只放必要的标签、图例和来源脚注。解释性的文字写在回复里，不写在图里。

## 各库的最小写法
- **ECharts**：
  - `echarts.init(el)` → `setOption({...})`。
  - 颜色取自令牌：`color: [1..6].map(i => css('--viz-series-'+i))`。
  - 深色模式切换时重新调用 `setOption`。
- **Chart.js**：`new Chart(canvas, {type, data:{labels, datasets:[{label, data, backgroundColor}]}, options:{responsive:true, maintainAspectRatio:false}})`。
- **D3**：
  - 按 `svg.attr('viewBox', `0 0 ${w} ${h}`)` → 比例尺 → 坐标轴（`g.axis`）→ 网格（`g.grid`）→ 图形 → tooltip 的顺序绘制。
  - 过渡动画用 `transition().duration(400)`。

## 渲染自检清单
- [ ] 图形确实绘出，不是空白；数值与数据源一致（抽查 2 个点）。
- [ ] 1280 和 390 两种宽度下，都没有文字重叠、截断，也没有横向滚动条。
- [ ] 浅色和深色模式都可读（对比度足够，网格线不刺眼）。
- [ ] 主要交互（筛选、滑块、悬停）确实会更新图形。
- [ ] `viz.py check` 没有错误。
