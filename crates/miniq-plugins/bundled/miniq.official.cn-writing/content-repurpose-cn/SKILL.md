# 一稿多发

## 适用场景

用户说：
- "把这篇公众号文章拆成小红书、微博和朋友圈版本"
- "我有一份演讲稿，帮我改成知乎回答和一分钟口播稿"
- "这篇报告做一套分发素材，所有平台都要"
- "只要微博和 X 的版本，各给两版"

不适用：从零写长文（先用 `wechat-article` / `long-doc-cn`）；发布动作（公众号用 `wechat-publish`，其他平台由用户手动发布）。

## 前置条件

- 源文来自工作区文件（`file_read`）或用户粘贴；网页链接用 `web_fetch` 抓取正文。
- 平台规格表见 `references/platforms.md`，第 3 步读取。
- 输出目录：`<工作区>/分发/<标题>/`，每个平台一个文件。

## 步骤

1. 读源文：`file_read` 全文；用 `shell_run` `wc -m` 记录字数。提取：核心观点（1 句）、3–5 个支撑点、最有传播力的 2–3 句原话、关键数字、作者语气特征（口语 / 冷静 / 犀利）。
2. 确认范围：用 `ask_user` 一次问清 —— 要哪些平台（默认全部 6 种）、每个平台几版（默认 1）、是否带话题标签、是否需要配图建议、有无不能提及的内容（如内部数据）。用户已说明则跳过。
3. 读规格：`file_read` 本技能 `references/platforms.md`，按选中的平台取字数上限、结构、禁忌。
4. 逐平台改写（每个平台一次 `file_write`）：

   | 平台 | 文件名 | 要点 |
   |---|---|---|
   | 公众号摘要 | `公众号摘要.md` | 120 字内摘要 + 3 个备选标题，用于公众号"摘要"栏与转发卡片 |
   | 小红书 | `小红书.md` | 标题 ≤ 20 字、正文 ≤ 1000 字、3–8 个话题、配图建议；复杂时转交 `xiaohongshu-note` |
   | 微博 / X | `微博-X.md` | 微博 ≤ 140 字优先（可长微博）、X ≤ 280 字符；各给钩子句 + 一个数据 + 一个话题 |
   | 知乎回答 | `知乎回答.md` | 先拟一个"问题"，回答 800–2000 字，结论先行、分点论证、引用来源 |
   | 朋友圈 | `朋友圈.md` | ≤ 150 字（折叠前约 6 行），个人口吻，1 句观点 + 1 句引导，不带外链 |
   | 视频口播稿 | `口播稿.md` | 60 秒约 180–220 字 / 3 分钟约 600–700 字；每句 ≤ 20 字，标注停顿与画面提示 |

   共同要求：核心观点一字不改地保留在每个版本里；数字与来源一致；作者人称与语气一致；不编造源文没有的事实；中西文空格、全角标点。
5. 同步生成 `README.md`（`file_write`）：源文路径、各版本文件与字数、建议发布顺序（通常：公众号 → 知乎 → 小红书 → 微博 / X → 朋友圈 → 视频）与间隔。
6. 自检：每个文件用 `shell_run` `wc -m` 对照 `references/platforms.md` 上限；`file_grep` 搜索各平台禁忌词（小红书：`微信|公众号|VX`；朋友圈：`http`）；核对 6 个版本的核心观点一致。
7. 需要配图时：小红书与朋友圈封面交给 `poster-cn`，数据类内容交给 `infographic-cn`；口播稿配图提示写在稿内即可。
8. 用户要求口播音频试听时，可用 `synthesize_speech` 把口播稿读出来供检查节奏；不自动发布。
9. 回复：目录路径、各版本一行摘要与字数、建议发布顺序；提醒除公众号（可用 `wechat-publish`）外其他平台需用户手动发布。

## 输出目录示例

```
分发/AI-Agent 对小团队的影响/
├── README.md
├── 公众号摘要.md
├── 小红书.md
├── 微博-X.md
├── 知乎回答.md
├── 朋友圈.md
└── 口播稿.md
```

## 注意事项 / 安全

- 本技能只产出文件，不执行任何平台的发布 / 发送；用户要求发布时转到对应技能并 `ask_user` 确认。
- 不为了凑字数添加源文没有的观点与数据；需要补充时明确标注"（新增）"让用户审阅。
- 源文含他人引语、图片时提醒版权；朋友圈与微博版本去掉内部链接与未公开数据。
- 各平台规则会变动，`references/platforms.md` 的数字以平台当前公告为准，不确定时在文件里注明"以平台当前限制为准"。

## 如何确认完成

`分发/<标题>/` 下每个选中平台都有文件且字数在上限内；`README.md` 列出全部文件；核心观点在各版本一致；回复说明了发布方式。
