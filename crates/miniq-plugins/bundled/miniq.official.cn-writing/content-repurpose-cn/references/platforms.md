# 各平台字数与格式规格表

`content-repurpose-cn` 第 3 步读取。数字为常见限制与经验值，平台规则会调整，产出文件中标注"以平台当前限制为准"。

## 总览

| 平台 | 标题 | 正文上限 | 推荐长度 | 话题标签 | 外链 | 图片 | 语气 |
|---|---|---|---|---|---|---|---|
| 公众号摘要 | 标题 ≤ 64 字，建议 ≤ 28 | 摘要 ≤ 120 字 | 80–120 字 | 不加 | 不适用 | 封面 2.35:1 | 与正文一致 |
| 小红书 | ≤ 20 字 | ≤ 1000 字 | 300–600 字 | 3–8 个 | 禁止 | 3–9 张，3:4 | 口语、第一人称 |
| 微博 | 无 | 140 字（长微博可更长） | ≤ 140 字 | 1–2 个 `#话题#` | 可带短链 | ≤ 9 张 | 直接、有观点 |
| X | 无 | 280 字符（中文约 140 字） | 1 条或 3–5 条串推 | 0–2 个 | 可 | ≤ 4 张 | 简洁、英文可混 |
| 知乎回答 | 用问题当标题 | 无硬限 | 800–2000 字 | 不加 | 可，建议文末 | 配图配表均可 | 理性、结论先行 |
| 朋友圈 | 无 | 无硬限，超约 6 行折叠 | ≤ 150 字 | 不加 | 不带（会变纯文本） | 1 / 3 / 4 / 6 / 9 张 | 私人、克制 |
| 视频口播 | 视频标题 ≤ 30 字 | 按时长 | 60 秒 ≈ 180–220 字；3 分钟 ≈ 600–700 字 | 平台内填 | 不适用 | 画面提示 | 口语、短句 |

## 各平台结构模板

### 公众号摘要
- 摘要：一句话说"这篇讲什么 + 读者得到什么"，不超过 120 字，不用问句堆叠。
- 3 个备选标题：数字型 / 反常识型 / 场景型，每个 ≤ 28 字。
- 不加话题标签，不写"点击阅读全文"。

### 小红书
```
标题（≤20 字，可含 1–2 个 emoji）

首段：2 行内说清这篇帮你解决什么

✅ 要点一（加粗短句）
展开 1–2 行

✅ 要点二
……

结尾一句互动引导

#大类话题 #细分话题 #人群话题
```
- 禁用：外链、二维码、"微信 / 公众号 / VX"、"最好 / 第一 / 100%"等绝对化用语。
- 配图建议表：序号 / 内容 / 形式 / 画面文字。

### 微博
- 结构：钩子句（观点或数字）→ 1–2 句展开 → `#话题#` → 可选"详见评论区链接"。
- 超过 140 字时拆成"正文 + 评论区补充"或改用长微博（头条文章）。
- 不用超过 2 个 emoji。

### X
- 单条：观点 + 数据 + 一个问题。
- 串推：第 1 条是完整钩子（能独立成立），之后每条一个点，末条给出总结与来源链接；条数 ≤ 5；每条标 `1/`、`2/`。
- 中文 280 字符约等于 140 个汉字，标点占位按字符计。

### 知乎回答
```
（拟定的问题，作为标题）

先说结论：一句话。

一、分点论证（2–4 点，每点有例子或数据）
二、……

反对意见 / 边界条件：一段

参考来源：[1] …（URL）
```
- 不写"谢邀"。不用 emoji。段落 ≤ 6 行。
- 数据与来源与源文一致；补充的内容标"（新增）"。

### 朋友圈
- ≤ 150 字（折叠线约在第 6 行）；最重要的话放第一行。
- 个人口吻，1 句观点 + 1 句引导（"文章放评论区"），不放链接到正文。
- 配图数量选 1、3、4、6、9 张（排版整齐）。

### 视频口播稿
```
【标题】≤30 字
【时长】60 秒 / 3 分钟
【开场 0–5 秒】钩子一句（提问或反常识结论）
【主体】每段 ≤ 60 字，每句 ≤ 20 字；（停顿）标注；［画面：……］标注
【结尾】一句行动引导 + 一句总结
```
- 语速按每分钟 200–240 字估算。
- 不读数字串太长的内容；大数字改"约 1,200 万"式说法并在画面提示中显示精确值。
- 用 `synthesize_speech` 试听时，检查句尾是否有歧义断句。

## 建议发布顺序与间隔

1. 公众号（完整版）→ 当天
2. 知乎回答 → 同天或次日（可链接回公众号）
3. 小红书 → 次日（平台偏好原创图文，不要同天同图）
4. 微博 / X → 发布日当天与次日各一条
5. 朋友圈 → 公众号发布后 1 小时内
6. 视频 → 1–3 天后，用评论区引导回长文

同一内容不要同一天在所有平台用同一张封面图。
