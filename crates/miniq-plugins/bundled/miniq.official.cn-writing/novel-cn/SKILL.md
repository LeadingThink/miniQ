# 中文小说创作

## 适用场景

用户说：
- "我想写一本都市悬疑小说，主角是个法医，先帮我搭世界观和人物"
- "按大纲写第 12 章，3000 字左右"
- "这章读起来和前面风格不一样，帮我统一一下"
- "给我设计三个配角，要和主角有冲突"

不适用：非虚构书稿（`long-doc-cn`）；短篇故事一次成文（直接写即可）；剧本分镜。

## 前置条件

- 所有文件落在 `<工作区>/小说/<书名>/`：
  ```
  小说/<书名>/
  ├── 设定.md            # 世界观、规则、地点、势力、时间线
  ├── 风格卡.md          # 叙事人称、语气、句式偏好、禁用词、示例段落
  ├── 人物/
  │   ├── <角色名>.md     # 人物卡
  │   └── 关系图.md
  ├── 大纲.md            # 卷/章规划 + 伏笔登记表 + 章节状态
  ├── 前情/
  │   └── 第NNN章.md      # 每章 150–300 字摘要（写完即生成）
  └── 章节/
      └── 第NNN章-<章名>.md
  ```
- 用户说"接着写"时，先 `file_read` `大纲.md` 的状态表，找到下一个"未写"章节，不重新问设定。

## 步骤

### 一、建书（首次）

1. 用 `ask_user` 一次确认：书名（可暂定）、题材与分类、目标读者与平台（起点 / 晋江 / 番茄 / 自娱）、一句话卖点、预计总字数与每章字数（默认 2000–4000）、叙事人称、参考的作品或作者气质、绝对不能出现的内容。
2. 写 `设定.md`（`file_write`）：世界规则（力量 / 科技 / 社会）、核心地点（3–6 个，各一段）、势力与冲突、时间线起点。规则要能产生限制，限制才有故事。
3. 写人物卡 `人物/<角色名>.md`：姓名与称呼、外貌速写、核心欲望、核心恐惧、说话方式（给 2 句示例台词）、与主角的关系、成长弧线起点与终点、禁忌（这个人绝不会做的事）。主角 + 2–4 个主要配角。`人物/关系图.md` 用表格列两两关系与张力。
4. 写 `风格卡.md`：人称与视角、整体语气（冷峻 / 温暖 / 诙谐）、句子长度偏好、描写密度（动作 : 对白 : 心理的大致比例）、禁用词（见下方红线）、以及 1–2 段 200 字示例作为"音叉"。
5. 写 `大纲.md`：
   - 分卷：每卷一句话目标 + 卷末高潮。
   - 章节表：`| 章号 | 章名 | 本章必须发生 | 结尾钩子 | 目标字数 | 状态 |`，先规划前 10–20 章即可。
   - 伏笔登记表：`| 埋在第几章 | 伏笔内容 | 预计回收章 | 状态 |`。
6. 用 `ask_user` 确认设定、人物与大纲，再开始正文。

### 二、写章（每章重复）

7. **回读（防止上下文丢失，必做）**：`file_read` 依次读 `风格卡.md`、`大纲.md` 中本章及前后各一章的行、本章涉及人物的人物卡、`前情/` 最近 3 章摘要、上一章最后 500 字。
8. 章前小纲：在回复中先给 5–8 行"本章场景顺序 + 情绪曲线（铺垫 / 升 / 高潮 / 收）+ 结尾钩子"，用户要求"直接写"时跳过确认。
9. 写正文到 `章节/第NNN章-<章名>.md`（`file_write`），要求：
   - 字数 2000–4000（以 `shell_run` `wc -m` 实测为准）。
   - 场景开头给出时间地点锚点；对白推动剧情，动作写具体；每 600–800 字有一次小转折。
   - 结尾停在悬念、决定或反转上，不要用感悟句收尾。
   - 严格遵守 `风格卡.md` 的人称、语气与禁用词。
10. 写 `前情/第NNN章.md`：150–300 字摘要，含人物状态变化、新埋 / 已收伏笔、未解决的问题。
11. 更新 `大纲.md`：状态列改"已写"、填实际字数；伏笔表登记本章新伏笔或标记回收。

### 三、检查与修订

12. 一致性：`file_grep` 搜索本章人物名、地点名，核对与设定一致；人物说了"绝不会做的事"时提醒用户。
13. 文风漂移：把本章开头 300 字与 `风格卡.md` 示例并排对比句长、人称、描写密度；偏差大时重写该段。
14. 红线自查（`file_grep`）：`众所周知|不言而喻|他明白了|她终于懂得|多么|真是太|所有人都没想到|命运的齿轮`；连续三句同一代词开头；连续排比。命中处改写。
15. 用户要求评审时，给出 5 维简评（开篇吸引力 / 节奏 / 人物 / 逻辑与伏笔 / 语言），各 1–2 句，附 3 条具体修改建议。

## 注意事项 / 安全

- 不写涉及未成年人的性内容、不写煽动暴力与仇恨的内容；平台有审核规则时提醒用户。
- 不抄袭：用户给出参考作品时只借鉴气质，不复用其情节、人名、独创设定。
- 不覆盖已写章节；重写前 `shell_run` 复制一份 `.bak`。
- 批量推进（"写 5 章"）时逐章执行第 7–11 步，每章结束汇报一行，用户可随时叫停；不用 `agent_run` 并行写正文（文风会漂）。
- 投稿、上传到任何平台不在本技能范围。

## 如何确认完成

本章文件存在且实测字数在区间内；`前情/` 有对应摘要；`大纲.md` 状态与伏笔表已更新；红线自查无命中；回复给出路径、字数、结尾钩子一句话。
