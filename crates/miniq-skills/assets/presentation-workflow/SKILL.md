## Workflow
1. Read the deck structure and inspect representative slides before editing.
2. Preserve the theme and master layouts; keep text within safe areas.
3. Render all changed slides at presentation resolution and visually check clipping, overlap, contrast, and media.
4. Save a separate output deck and list the slides that were checked.
