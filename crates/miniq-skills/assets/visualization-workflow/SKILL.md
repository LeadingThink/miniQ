## Workflow
1. Clarify the comparison, units, and audience before choosing a chart.
2. Validate input rows, missing values, and axis units.
3. Prefer a readable interactive view for exploration and export a static artifact when requested.
4. Check labels, legends, color contrast, and source attribution before delivery.
