## 适用场景

用户想了解某个目录里有什么("帮我看看这个文件夹"、"整理一下这个目录"、"这里都有哪些资料"),或需要一份目录清单交付物。

## 步骤(写明每步用哪个工具)

1. 用 `file_list` 查看目标目录的顶层结构,识别主要子目录。
2. 用 `file_glob` 按类别统计文件:例如 `**/*.{docx,xlsx,pptx,pdf}`、`**/*.md`、`**/*.{png,jpg}`,分别记录数量与文件名。
3. 对不认识的文件类型,再用一次 `file_glob` 的 `**/*` 查看全量文件名(注意结果里的 `truncated` 字段,截断时按子目录分次查询)。
4. 汇总为 markdown 报告:目录概览、按类型分组的文件清单、最近修改的文件(glob 结果本身按修改时间排序,取前 10 个)。
5. 用 `file_write` 把报告写为目标目录下的 `inventory.md`(需要用户审批)。

## 注意事项(真实踩过的坑)

- `file_glob` 的结果按修改时间从新到旧排序,直接取前几个就是"最近改动"。
- 大目录下 `**/*` 可能触发 `truncated: true`,此时报告里要注明"仅统计前 N 个文件",不要谎报全量。
- 不要读取每个文件的内容,清单只需要文件名和结构;用户点名要摘要的文件才用 `file_read`。

## 如何确认完成

`inventory.md` 已写入且内容包含:目录概览、分类清单、最近修改列表。回复中给出报告路径。
