# 动态壁纸筛选原则

这套规则来自参考图的视觉结构。它限制单张壁纸的干扰程度，不限制壁纸库的主题范围。

## 通过条件

1. **色彩集中**

   画面以一个主色家族为主。辅助色只用于主体或局部光线。暖色、浅色、冷色和深色都可以使用。

2. **阅读区连续**

   画面至少保留一块连续的低细节区域。文字、消息和输入框可以在这块区域上保持清晰。

3. **主体适中**

   只保留一个主要视觉焦点。主体放在下方或三分之一位置。人物、动物、动漫角色和 3D 物体都适用。主体不能铺满画面。

4. **对比受控**

   使用柔和边缘和低对比光线。避免满屏高亮、强霓虹、硬边密集结构和多处跳色。

5. **动态缓慢**

   动态只发生在水纹、雾、雨、叶影、衣摆、微光或呼吸等局部。禁止快速镜头、闪烁、突然变亮、切镜和主体大幅移动。

6. **内容干净**

   不保留可读文字、品牌标识、水印、界面截图和复杂符号。场景内容可以多样化，但细节密度必须受控。

7. **裁切安全**

   关键主体不能贴近边缘。每张壁纸设置焦点位置，保证桌面横图和手机竖向裁切都不会切掉主体。

## 主题范围

当前库可以包含自然、人物、动物、原创动漫、极简 3D、植物、抽象科技、字符和程序光影。主题之间可以明显不同。每一张图仍然单独执行上面的通过条件。
