# 移动端远程工作体验改进与验收

基线：0.1.46（54ff1304），实现分支：`codex/mobile-remote-ux`。

本轮针对 Android、iPhone/iPad 和手机浏览器共用的前端。没有修改版本号、发布安装包、上传 TestFlight 或重启用户正在使用的桌面客户端。

## 发现与完成的改进

| 范围 | 已完成的行为 |

## 验收方式

使用 `apps/desktop/mobile-ux-preview.html`，组合真实 Sidebar、AppStatusBar、Timeline、Composer、SessionModelControls 和 FilePreviewPanel。数据为本地合成的长中文/英文标题、多项目、运行/待确认/失败任务和报告文件，不读取用户 Key，不连接真实电脑，不调用付费模型。

运行：从 `apps/desktop` 启动 `npm run dev -- --host 127.0.0.1 --port 1446`，打开 `/mobile-ux-preview.html`。该入口只有开发模式渲染，不在生产构建入口中。

浏览器实际检查：320×568、360×800、390×844、640×360、768×1024、1280×800。检查完整标题、侧栏滚动/搜索/展开、连接详情和模拟恢复、模型弹层、会话更多菜单、手动分页、Markdown 预览及带路径继续提问。以上尺寸未出现整页横向溢出。320px 工具栏多换一行、文件提问按钮被压缩的问题是在浏览器验收中发现并修复。

自动化测试覆盖导航、输入/中文组合态、附件延迟与跨会话隔离、模型作用域与弹层、连接互斥/前后台恢复、隐私流程、历史分页、预览、SSH 主机目录，以及原有加密/分块传输。TypeScript 和 Vite 生产构建通过；`git diff --check` 通过。

构建仍提示已有的文档/编辑器大分块和动静态混合导入；本轮未修改这些解析器，相关文件继续按需加载。

## 明确的验收边界

- 浏览器尺寸验收不等于 Android/iOS 真机验收。系统软键盘、安全区、系统返回与后台恢复仍需对候选 APK/IPA 在实体设备验收。
- 断线流程做了组件与连接钩子测试；没有以模拟页面替代真实中继网络吞吐、长时弱网或断电测试。
- “附加远程文件”使用电脑上的现有路径，不是将手机相册/文件上传到电脑。新增上传协议不在本轮实现内，界面已明确说明。
- 电脑切换复用已有 SSH 主机目录，没有声称支持当前协议尚未提供的同 Key 多桌面设备选择器。
- 手机工作区中的“网页记录”仍是桌面执行留下的网页记录，并未伪装成手机上的实时原生浏览器控制。

## 发布前真机复核建议

1. Android、iPhone、iPad 分别进入移动问答和远程桌面，校对长标题和横竖屏布局。
2. 打开/关闭软键盘，中文候选确认与换行不应误发送；输入后退后台、再打开应保留草稿。
3. Wi-Fi/蜂窝切换、后台停留后返回，观察状态和恢复；电脑任务继续执行，不重新发送原任务。
4. 打开长报告/图片、切换文件标签、返回会话继续提问；核对电脑和会话归属。
5. 切换本机/SSH 主机，确认旧详情弹窗关闭，失败切换保留当前会话和错误说明。
