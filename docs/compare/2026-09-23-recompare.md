## 上一份建议里已经落地的

这些不要再当成下一阶段的第一件事：

1. **定时任务分成两种跑法。** 迁移 `0016_scheduled_task_continuity.sql` 增加 `mode`：`newSession` 或 `heartbeat`。心跳必须指定 `target_session_id`。周期除了每天、每周、固定间隔，还可以选工作日。
2. **每条定时任务有一段记忆。** 字段是 `memory`。执行时如果非空，会追加到提示词后面，前缀是「任务记忆：」。它是用户填写的一段文字，不是 ChatGPT 那种会随每次运行改写的 `memory.md`。
3. **子任务状态进了主时间线。** `AgentStatusIndicator` 挂在 `Timeline` 上，显示数量、阶段和步骤。这还不是子任务自己的一条时间线。
4. **长文本朗读按段播放。** 单段上限仍是约 1500 字，失败段可以重试，段间空白保留。转写模型跟随探测结果，不再写死。
5. **设置里有全局默认 Chat 模型。** 文案写明它作用于所有项目和新会话，项目或会话可以单独覆盖。保存密钥后从服务返回的 Chat 模型列表里选。

`0.1.45`–`0.1.48` 已有、本版没有改掉的能力仍然算已有：队列编辑和调序（无拖拽）、桌面进程活着时 `caffeinate`、文件预览跳外部编辑器、记忆搜索/翻页/删除、侧边栏定时任务、非前台通知、SSH、会话搜索。本版 diff 没有动这些文件。

## 插件：数量和能力都差一截

本机 ChatGPT 配置里启用了 10 个插件。随包市场里还能看到 Chrome、LaTeX、信息、录制回放，这四个没有打开。

| 已启用插件 | 版本 | 它实际多出来的能力 |
| :--- | :--- | :--- |
| `browser` | `26.901.51231` | 操作应用内浏览器：打开、点击、输入、看页面、截图；可以沿用已登录的会话 |
| `computer-use` | `1.0.1000926` | 操作本机 Mac 应用界面 |
| `unified-computer-use` | `26.901.51231` | 和电脑操作配套的统一入口 |
| `codex-app-tools` | `0.1.3` | 客户端自己的工具 |
| `visualize` | `1.0.29` | 在对话里直接做可视化、对比和可交互演示 |
| `documents` | `26.921.11914` | 写、改、批注 `.docx`，并渲染成页图再检查 |
| `pdf` | `26.921.11914` | 读、写、渲染、核对版式，包括可填写表单 |
| `spreadsheets` | `26.921.11914` | 公式、格式、图表、重算；另有一个活的 Excel 连接技能。清单里还挂了 `.app.json` |
| `presentations` | `26.921.11914` | 读、写、改幻灯片 |
| `template-creator` | `26.921.11914` | 从一份参考文稿做出以后能复用的模板技能 |

这 10 个不是同一种东西。文档五件套是「技能 + 脚本 + 单独版本」。浏览器和电脑操作还会带 MCP。LaTeX 市场包里有编译、诊断、运行时安装三份技能。信息插件是本机「信息」的 MCP。录制回放带会话开始钩子。也就是说，ChatGPT 的插件可以装技能、工具、钩子和应用，而且文档包不必等主程序发版。

miniQ 0.1.49 的插件面是另一回事：

- 运行时有，桌面有「插件」页，可以添加本地目录、启用或停用。空状态写的是「还没有本地插件」。
- 协议 `plugin.wit` 的 v1 只有一种能力：`tool`。宿主调用 `execute(name, arguments)`，插件返回一段文字。
- 权限只有工作区、网络、记忆三项。WASM 插件不能碰网络和记忆，只能打日志。
- 仓库里唯一的例子是 `examples/node-plugins/text-utils`，做文本变换，清单里 `enabled = false`，不随应用安装。
- 随包技能只有 4 个，而且写在 `crates/miniq-skills/assets/` 里：开发插件、邮件草稿、整理目录、汇总改动。它们不是可装卸插件，改一次就要发一版应用。
- 插件不能自带 `SKILL.md`，不能注册钩子，不能带一个小应用，也不能像 `26.909` 到 `26.921` 那样单独升级。

所以「插件太少、功能太弱」是对的。少，是因为装完是空的，随包没有文档、表格、幻灯片、PDF、可视化和 LaTeX。弱，是因为现在的插件只能当一个返回字符串的函数，装不上 ChatGPT 那种整包能力。

## 会话操作：命令菜单对过一遍

对照的是 ChatGPT 客户端中文命令，不是设置页。miniQ 用 `v0.1.49` 的界面文案核对。下面只记能对上名字的项。

已经有，不必再做一遍：

- 新聊天、重命名、置顶、归档、删除。会话菜单就是这四项加删除。
- 查找。侧栏可以搜会话标题和历史消息，当前会话里也有搜索框。
- 未读。侧栏能筛「未读」，条目上会标「新回复」。没有单独的「标记为未读」命令。
- 语音输入。输入框有录音按钮，只是不叫「听写」。
- 侧栏可以收起。
- 分享。可以勾选消息、审核后生成链接、复制和撤销。这不是菜单里的「复制深层链接」，链接是发布出去的，不是本机直接打开那条会话。
- 修改消息，以及一个「重新生成」按钮。

确认没有的：

| ChatGPT 里的操作 | 它做什么 | miniQ 0.1.49 |
| :--- | :--- | :--- |
| 分支到新聊天 / 分叉聊天 | 从某一条回复另开一条聊天。可以留在当前目录，也可以进一个新工作树。旧回合分叉会先确认 | 没有。协议里没有分叉会话。工作树只给子任务隔离，用户不能从一条回复分出新聊天 |
| 重新生成的版本 | 保留上一版、下一版，还可以「思考更久」、带搜索或不带搜索再生成 | 只有一个按钮：找到上一条用户消息，用原文重跑。原来的回复不保留 |
| 新建临时聊天 | 不进历史，也不写新的记忆 | 没有 |
| 新建独立聊天 | 不挂在项目上 | 会话都在项目里 |
| 在新窗口中打开 | 同一条聊天开一个新窗口 | 没有 |
| 复制为 Markdown、复制对话路径、复制工作目录 | 会话菜单里的复制 | 没有这三项。分享链接是另一条路 |
| 打开终端 | 应用里的终端面板 | 没有。远程连接是 SSH，不是这条聊天旁边的终端 |
| 置顶摘要 | 把一段摘要钉在会话上，并可显示或隐藏 | 没有。现有审阅是文件 diff，不是会话摘要 |
| 转到聊天 1–9、上一个 / 下一个、下一个需关注的 | 键盘在会话之间跳 | 没有这组快捷键 |
| 把聊天移到另一台电脑或另一棵工作树 | 会话本身搬家 | 没有。换电脑靠 SSH 项目，不是把这条聊天移走 |

子智能体仍然只是时间线上的状态，不能像对方那样打开一个子任务面板再返回。这点和上一行「子任务可见性」是同一件事，不单列成新功能。

实时语音聊天、彩纸、桌面宠物仍然不算缺口。miniQ 已有按段朗读和语音输入。

## 新的更新建议

按这个顺序。0.1.49 刚做完的心跳、工作日、时间线条和分段朗读不再重复。

1. **先把插件从「一个函数」做成「一个能力包」，并随包带上第一批。** 插件清单要能声明技能目录、工具和版本，桌面列出已装版本，升级不必重发整个 app。第一批只做六件，对齐本机已经在用、而且确实有活的那些：文档、PDF、表格、幻灯片、对话内可视化、LaTeX 编译与诊断。文档包要包含批注和渲染后检查，表格要能算公式和画图，PDF 要能渲染再核对。不要把字体配色手册抄进来。Chrome 登录态、本机「信息」、录制回放先不做；前一个是浏览器子系统，后两个碰的是个人会话和本机消息。
2. **从一条回复分出新聊天。** 对方回复上的操作叫「分支到新聊天」，命令菜单叫「分叉聊天」。新会话从那一条接着走，原来的会话留着。先做同一项目、同一目录。进新工作树、从很早的回合分叉要确认，这两步后做。不要用现在的「重新生成」充数：那个按钮会改写上一条用户消息再跑，原回复不保留。
3. **让定时记忆写回来，并记下这次结果。** 现在记忆只被拼进提示词，跑完不会更新；卡片也只有「上次运行」。下一步是：这次结论写回该任务的记忆，并显示成功、失败或被跳过，点开能回到那次会话。不要再加 cron 表达式，也不要再加第三套模板。
4. **给会话一个目标和用量，而不是再加一条上下文条。** 对照物是 ChatGPT 的线程目标：一句话目标、状态、token 预算、已用 token、已用时间。`define-goal` 也说明他们把「先写可衡量目标」当成技能，而不是设置页开关。
5. **回合结束时允许一条本地命令。** ChatGPT 本机配置已有这种通知。用途是跑完去响一声、记一条日志或打开结果。插件钩子可以以后再做，这条先做成本低的本地命令。
6. **项目信任和目录只读分开。** 只读表示不能改文件；信任表示能不能执行命令、访问网络和记住密钥。现在只有前者。插件一旦能访问工作区和网络，这项就要一起做。
7. **技能可以导入，但不要手写一整座生态。** 值得看的是 `migrate-to-codex` 和 `cli-creator`。`hatch-pet`、Figma 全家桶、安全威胁模型不进 miniQ 本体。

明确不做：彩纸、桌面宠物、实时语音聊天、把设置拆成十几页、把单段朗读上限调到 1500 以上、为了凑插件数量去接本机「信息」或录屏回放。临时聊天、独立聊天、新窗口、应用内终端、置顶摘要、聊天 1–9 快捷键先记在上面的对照里，不进这一版。
