## 旧结论里已经过时的部分

这些在 `0.1.45`–`0.1.48` 已经有可用实现，不应再当成「从零开始」：

- 排队：改内容、插队执行、上下移动、多设备顺序冲突。没有拖拽排序。
- 防休眠：设置开关；有回合在跑且桌面进程还在时调用 `caffeinate`。应用退出后断言消失。
- 外部编辑器：文件预览可选 VS Code、Cursor、Zed 或系统默认程序，能跳到行，并记住上次选择。代码块和 diff 还不能这样开。
- 记忆：设置里搜索、分页、按预期内容删除。不能手写或修改，也没有按项目分开的视图。
- 定时任务：侧栏入口；每天、每周、间隔；三个模板；开关、立即运行、删除、打开结果会话。调度器明确拒绝 cron 表达式。每次触发是新建会话，不是续写旧线程。
- 通知：完成和等待授权；只在窗口不在前台时发；按设备记住。
- 子任务：`AgentPanel` 已有运行中、完成、失败计数，以及阶段和轮次。`AgentActivity` 可以分页看某个子任务的工具记录。缺的是主时间线上的常驻叠层，不是统计本身。
- 语音：按服务商是否提供转写和朗读模型来显示。朗读走 `grok-tts`，单次约 1500 字。
- 另外已有：SSH 工作区打通桌面和手机、历史图片损坏不再卡死整段记录、对话搜索、模型预算布局、Grok 请求失败时回退普通对话接口。

## 这次才看清的格局

miniQ 已经不该再被写成「工作台接近、其余都缺」。下面这些是它自己的，ChatGPT 桌面端并没有对等的一整套：

- 把一次会话蒸馏成技能，重名可改已有技能，并在保存前提示可能的敏感内容。
- 会话 diff 审查：新增、删除、二进制、按块打开文件。
- 提问卡、批准收件箱、会话分享、把外部会话导入并改挂到别的项目目录。
- 手机中继、SSH 远程文件、后台操作原生应用，而不是只能抢前台键鼠。

ChatGPT 仍然明显更完整的，是插件市场和「一条线程可以长期活着」：

- 插件带版本，和主程序分开升级。本机启用了浏览器、Chrome、电脑操作、可视化、文档、PDF、表格、幻灯片、模板创建器和应用内工具。
- 应用内工具能读线程、读线程目标、拉应用截图、看工作区依赖。
- 配置里有项目信任级别、跟随模式（排队或直接插话）、对话详略（步骤或命令），以及回合结束时调用的本地程序。
- 目标表是独立的：一条线程一个目标，状态可以是进行中、暂停、堵住、用量受限、预算受限、完成，并记 token 预算、已用 token 和已用时间。本机有 2 条。
- 自动化是一个目录，不是一行表单。`ai` 用 RRULE 每天 4:00 跑，绑定项目和模型；旁边有一份约 47KB 的 `memory.md`。`suno` 是每分钟心跳，写回同一条线程。两条目前都是暂停。

## 新的做法

上一份路线图的顺序是：排队、防休眠、外部编辑器、子任务头像、记忆页面、定时任务看板。前半已经做完。剩下值得做的，换成下面这六件。

1. **定时任务分成两种，并自带记忆。** 现在每次到点都新建会话，适合「写一份新日报」，不适合「看着同一条浏览器恢复线程」。增加续写同一会话的心跳；每个任务一个可编辑的记忆文件，而不是三个固定短提示。每天、每周、间隔先保留，cron 可以后补，RRULE 那种「工作日 4:00」比再堆模板有用。
2. **给线程一个目标和预算。** 比单独画一条上下文进度条更有用：目标、状态、token 和时间上限，到限就暂停并说明原因。进度条可以做在这个状态旁边，不必先做。
3. **能力包跟应用版本解开。** 文档、表格、幻灯片、可视化和模板不必等桌面发版。miniQ 已能把会话蒸馏成技能，下一步是同样的流程用来沉淀文档模板，而不是先抄一套版式指南。
4. **回合结束钩子。** ChatGPT 的完成通知可以是一个本地程序，不只能弹系统通知。先做「结束时运行一条命令」，菜单栏常驻、外部播放器、自己的脚本都能接。比重做一套通知中心小。
5. **项目信任，而不只是目录只读。** 现在项目目录能标只读。还缺：这个目录允许自动执行到什么程度，以及换机器、换会话后还认不认。
6. **把已有的子任务统计放到主对话。** `AgentSummary` 的计数和阶段不用重写。缺的是主时间线上一眼能看见，并点进现有的活动列表。

Chrome 登录态复用仍然是最大的网站工作流缺口，但是独立项目。语音长文应分段朗读，不要把 1500 字上限直接抬高。完成彩蛋、宠物、把设置拆成十几页，这次仍然不建议做。

## 不该再做的

- 不要把排队、防休眠、记忆列表、定时任务入口再排进「第一阶段从零实现」。
- 不要为了像 ChatGPT 而把子任务统计重做成头像叠层；先把它放到主对话。
- 不要用三个更长的模板冒充自动化记忆。记忆应该跟着具体任务长出来。
