# miniQ 0.1.41

## 桌面与终端

- 新增“设置 → 服务与远程 → SSH 连接”，可发现本机 SSH 别名或手动添加主机，连接远端 miniQ 项目和会话。
- 新增 `miniq bridge`，通过 SSH 提供认证后的任务、审批、文件与状态访问，不依赖 relay，不公开远端 daemon 端口。
- 执行主机之间隔离会话、草稿、项目及设置。连接失败保留原主机；断线重连恢复任务状态，不重放已发送操作。
- 远端文件通过远端服务读取，附件和项目使用远端路径；本机 API Key 不会自动复制到服务器。
- Linux 终端使用适合无图形服务器的构建；Linux 桌面安装包继续提供图形桌面的电脑控制能力。

## 工作面板与会话体验

- 工作面板增加任务、产物与文件入口，支持调整布局、展开及键盘操作。
- 文件标签支持查找、重新排序、批量关闭和恢复关闭的标签，保持会话隔离。
- 预览选区可以加入输入框继续提问；切换面板时保留视图位置，浏览器实例保持稳定。
- 审阅支持过滤、前后文件导航、已审阅标记和大差异分批显示。
- 左侧会话增加标题与项目筛选、状态筛选及折叠状态保存，减少无须显示的列表渲染。
- 优化消息时间、日期和执行用时显示；保存任务计时数据，断线与重启后保持一致。

## 使用说明

SSH 桌面端与远端 CLI 均需 0.1.41 或更新兼容版本。当前支持 Linux/macOS 远端，使用系统 OpenSSH 的免密认证及主机指纹校验。远端需要配置自己的模型服务。完整说明见 [SSH 连接](../ssh-connections.md) 与 [终端使用](../terminal.md)。

本版本不包含自动远端安装、完整交互式终端面板或 Windows 远端 shell 支持。Linux 服务器终端不提供真实图形桌面鼠标/截图工具；图形桌面功能继续使用桌面安装包。
