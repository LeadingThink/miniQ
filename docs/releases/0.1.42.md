# miniQ 0.1.42

本次桌面与终端版本为 **0.1.42**；对应 Android 版本为 **0.1.25（25）**。iOS 共享源码同步更新，本次不上传 TestFlight 或提交 App Store 审核。

## SSH 与移动远程

- 本机及多个 SSH 主机的项目和会话同时显示在同一侧栏，不再通过替换整个工作界面切换主机。
- 桌面 daemon 管理并持久化 SSH 连接。手机连接桌面后，可以继续访问桌面已保存的 SSH 主机、会话、任务进度与文件。
- 主机身份进入请求、事件、草稿、模型设置、文件预览与移动订阅，隔离不同电脑上的同名项目和相同会话 ID。
- 已连接主机复用现有连接和目录；慢主机独立刷新。移动历史继续分页，工具大正文按需读取。
- SSH 断开或请求超时不会断开本机根连接，也不取消远端任务。重连读取任务状态，不重放结果不明确的操作。
- 切换 SSH 保留本机内置浏览器；隐藏输入框、快捷键及迟到读取不会抢走附件或手机正在查看的会话。
- 改善主机错误、未读状态、客户端更新与后台连接之间的隔离。

## 图片历史

- 用带作用域的图片记录管理视觉历史，减少后续模型步骤中重复发送完整图片。
- 保留任务需要的近期视觉信息；历史图片可通过专用工具重新取回，避免靠直接删图节约上下文。
- 优化图像预览尺寸与不同模型提供方的图片输入，覆盖视觉历史恢复和实际请求格式回归。

## 更新与使用

桌面用户通过“检查更新”安装 0.1.42。手机需使用已更新的网页或 Android 0.1.25，并连接更新后的桌面 daemon；未更新的桌面仍可使用原有本机会话，但不能提供新的共享 SSH 目录。

远端需具备 `miniq bridge`（0.1.41 起提供），以及已配置好的远端模型服务。SSH 密钥仍由桌面电脑的 OpenSSH 管理，不传给手机，也不自动复制本机模型 Key。详细说明见 [SSH 工作区](../ssh-connections.md)、[实现与验收](../unified-ssh-workspaces.md)及[图片历史](../image-history-management.md)。

本次通过既有 GitHub Actions 发布签名更新包、终端归档及 Android APK；主下载源为七牛，GitHub 为镜像。桌面升级不要求强制重启正在工作的远端 daemon。
