# miniQ 0.1.146

- 修复 macOS/Linux 从桌面启动时无法发现用户 shell PATH 中命令的问题。PATH 在桌面进程首次连接 daemon 时解析一次，只将 PATH 传给新启动的 daemon。
- PATH 探测包含两秒超时、进程组清理和持久化诊断，配置异常时保留原进程 PATH，避免阻止启动。
- Windows 继续使用启动进程继承的用户/系统 PATH，不加载 PowerShell profile。
- 包含 main 上的图片粘贴与拖放修复。
- 包含 Windows 路径规范化修复，避免扩展路径前缀影响文件访问与预览。

平台：Windows x64、macOS Apple Silicon/Intel、Linux x64。修改环境配置后，请完全退出 miniQ 并重启；已运行的 daemon 保留原环境。
