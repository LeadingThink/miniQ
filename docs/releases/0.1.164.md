# miniQ 0.1.164

本次 Windows 与 macOS 更新合入 0.1.163 的 ConPTY 启动光标握手修复，以及本地完成的以下改动：

- 代码和命令工具开始执行时，不再自动打开终端面板，保留用户当前选择。
- 主任务和子任务按任务收益、协调成本与复杂度判断是否委派，删除固定 worker 数量的提示。
- 工具执行失败保存为失败结果，保留此前成功结果并继续任务；取消仍终止当前执行。
- 默认 OneAPI 的图片与视频参考文件共用私有七牛上传通道，模型请求使用短期图片链接，支持凭据隔离的内存缓存与临时上传失败重试；原图和历史记录保留。

发布平台为 Windows x64、macOS Apple 芯片与 Intel。通过现有 GitHub Actions 发布安装包和更新元数据。
