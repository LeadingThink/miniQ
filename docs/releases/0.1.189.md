# miniQ 0.1.189 / Android 0.1.102

## 个人助手记忆

- 跨聊天使用已保存的偏好和项目事实，项目记忆保持作用域隔离。
- 记忆支持去重、更正、版本管理和来源追溯；删除后同步失效索引、上下文和旧后台任务。
- 接续项目时读取实时目标、检查清单、成果引用和最近执行结果。
- 保留现有记忆管理页，增加使用记忆和自动保存开关。自动保存默认关闭，开启后使用来源会话的模型整理后续成功对话，会产生模型用量。

## 日常使用

- 支持选择文件引用。
- 删除当前会话后返回新对话。
- 优化执行时间线间距，子代理状态显示具体任务描述。

Windows、macOS（Apple Silicon / Intel）和 Linux 使用桌面版本 0.1.189。安卓独立版本为 0.1.102（versionCode 102），连接更新后的 miniQ 电脑端可使用新的记忆内核。
