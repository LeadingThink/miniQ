## 修复证据

旧输出归档实现在 64 个 FD 上限下保留 61 个输出后耗尽句柄。新实现可在同样上限下保留 192 个 pipe/PTY 任务，执行 384 次完整任务回放，任务完成后的 FD 基线、峰值和最终值均为 9。

macOS PTY 在 controlling session leader 退出时可能直接 EOF。延迟输出测试现将 PTY leader 保持到后代输出结束，pipe 继续覆盖 leader 提前退出的场景，没有删除输出完整性断言。
