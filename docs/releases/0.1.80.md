# miniQ 0.1.80

本版本加入手机离线推送和远程控制增强，并修复视频生成参考图：

## 手机离线推送（远程控制）

- iOS（APNs + Notification Service Extension）和 Android（极光推送）支持离线推送。触发场景包括：任务完成、任务失败、需要审批/回答、桌面离线。通知内容由桌面端加密，手机本地解密，relay 无法读取明文。
- 审批通知可直接点“批准 / 拒绝”；点击通知会跳转到对应会话。
- 新增免打扰时段，时段内通知静默送达；手机 App 在前台时只显示 App 内的任务横幅，不重复弹系统推送；iOS 和 Android 都支持角标。
- 远程访问开启后，daemon 会阻止电脑空闲休眠，手机随时可以连上。屏幕仍可关闭，合盖或手动睡眠照常生效。
- 桌面端的审批/提问提醒与任务结果通知已合并去重，不会对同一事件重复提醒。
- 配置与部署说明见 `docs/remote-push.md`。iOS TestFlight 工作流新增 Secret `IOS_NSE_PROFILE_BASE64`。

## 媒体生成

- 视频生成的参考图改为以 `image.url` 对象（data URL）发送，修复了参考图不生效的问题。
- 新增 `get_video_generation` 工具，可查询视频任务状态并取回结果。

验证：前端 TypeScript 类型检查和全部 Vitest 测试通过，Vite 生产构建通过，release/iOS/macOS 脚本测试通过；relay 测试通过（含推送）；`cargo fmt --check`、`cargo check --workspace`、`cargo test -p miniq-daemon` 均通过。
