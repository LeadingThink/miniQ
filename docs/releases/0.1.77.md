# miniQ 0.1.77

本版本为技能页面和聊天技能快捷菜单增加中文展示名称：

- 官方技能元数据补齐中文 `displayName`，技能卡片、详情页和快捷菜单显示中文标题。
- 技能搜索同时支持中文展示名称、英文稳定标识和描述。
- 英文 `name` 继续作为技能目录、RPC 调用和内部标识，保持已有技能调用兼容。
- 自定义技能或旧技能没有 `displayName` 时自动回退到英文名称。

验证：前端技能回归测试、TypeScript 类型检查、Vite 生产构建、Rust 技能解析与工具测试通过；384 个官方技能元数据文件完成覆盖检查。

发布状态：待推送标签 `v0.1.77` 并运行正式发布流水线。
