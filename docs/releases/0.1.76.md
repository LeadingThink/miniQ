# miniQ 0.1.76

本版本把 WorkBuddy 实测得到的可恢复体验原则落到产品基础层：

- 技能页支持更清晰的搜索、来源、依赖和启用状态发现。
- 技能页补齐首次加载、失败保留旧数据、重试和晚到响应隔离；待处理中心把未读数量与需要用户动作的数量分开。
- 401/403、连接断开等常见失败转换为可理解的中文提示，避免把原始协议错误直接展示给用户。
- 新增错误文案回归测试，覆盖凭据过期、权限不足和连接断开。
- 增加苹果产品原则、WorkBuddy 对照、优先级、验收和发布门槛报告。
- 保留并纳入 iOS App Store 自动化和 VS Code 扩展配套。

验证：桌面全量 209 个测试文件、1415 个测试通过；移动端 12 个文件、81 个测试通过；平台脚本 16 个测试通过；VS Code 扩展 8 个测试通过；Rust `cargo fmt --all -- --check`、daemon/CLI/local 测试、Tauri `cargo check` 和版本一致性检查通过。桌面生产构建和 sidecar 准备通过，保留既有大 chunk 警告。
