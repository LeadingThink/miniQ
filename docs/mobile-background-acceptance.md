## 自动化检查

| 范围 | 必须覆盖的行为 |
|---|---|
| 偏好 | 移动端与桌面端隔离；无效存储值降级；重启后保留选择 |
| 网络 | 默认仅 Wi-Fi 下载；移动网络须明确开启；断网或未知网络不新增视频下载 |
| 电源 | 默认仅充电播放视频；未知充电状态按保守策略处理；节电模式降级 |
| 生命周期 | 后台取消下载、暂停视频与 Canvas、暂停轮播；恢复前台后重新检查策略 |
| 缓存 | 命中时不下载；数量和容量上限；清理后不被旧请求重新写入；存储失败不崩溃 |
| 视频 | 超时、空文件、HTTP 错误、播放拒绝均保留封面；切换时清理资源 |
| 无障碍 | 系统减少动态优先；关闭背景可达；键盘焦点与对话框关闭行为正确 |
| 回归 | 桌面视频双播放器、背景收藏、合集与轮播保持现有行为 |

## 性能记录

在同一设备、亮度、网络和温度下，对照无背景、光影、字符和视频四组。每组至少记录 10 分钟的 CPU、内存、掉帧与能耗。低功耗模式单独测量。不要把渲染帧率上限当作实测帧率。

保存 Android Profiler / Perfetto 与 Xcode Instruments 的原始记录。若视频出现明显卡顿、持续内存增长或系统热警告，应保持默认保守策略并修复后复测。
