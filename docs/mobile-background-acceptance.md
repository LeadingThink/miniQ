## 已实现范围

- 首页与已连接远程工作区均有外观入口，移动偏好与桌面隔离。
- 完整背景库、搜索、收藏筛选、我的合集、时间段合集、顺序/随机与间隔轮播。
- 视频使用单播放器。默认仅 Wi-Fi 下载、仅充电播放；蜂窝下载须显式允许。
- IndexedDB 持久缓存、数量与容量上限、LRU 淘汰、用量恢复、清理、失败重试与下载状态。
- 已缓存视频可离线播放；未缓存视频仍受网络授权约束。下载去重、超时、取消和清理竞态有自动化覆盖。
- 后台停止播放、Canvas 与轮播，并取消下载；回前台重查网络和电源。未知电源状态保守降级。
- 系统减少动态覆盖用户标准模式。低功耗下 Canvas 不超过 15fps，降低像素比与粒子密度，减少模糊；视频使用静态封面。默认桌面引擎行为保持。
- 外观面板支持安全区、滚动、焦点恢复、Tab 循环与 Escape；Android 返回键优先关闭面板，迟到监听回调在卸载后无效。

## 自动化检查

| 范围 | 必须覆盖的行为 |
|---|---|
| 偏好 | 移动端与桌面端隔离；无效存储值降级；重启后保留选择 |
| 网络 | 默认仅 Wi-Fi 下载；移动网络须明确开启；断网或未知网络不新增视频下载 |
| 电源 | 默认仅充电播放视频；未知充电状态按保守策略处理；节电模式降级 |
| 生命周期 | 后台取消下载、暂停视频与 Canvas、暂停轮播；恢复前台后重新检查策略 |
| 缓存 | 命中时不下载；数量和容量上限；清理后不被旧请求重新写入；存储失败不崩溃 |
| 视频 | 超时、空文件、HTTP 错误、播放拒绝均保留封面；切换时清理资源 |
| 无障碍 | 系统减少动态优先；关闭背景可达；键盘焦点与对话框关闭行为正确 |
| 回归 | 桌面视频双播放器、背景收藏、合集与轮播保持现有行为 |
