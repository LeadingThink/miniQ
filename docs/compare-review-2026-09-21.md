# miniQ 对比报告复核与用户体验改进清单

复核日期：2026-09-21。实现基线：`origin/main` 的 `2040c5d`（0.1.45）；开发分支：`codex/compare-optimization`。

## 对昨晚报告的判断

方向有价值，尤其是长任务连续性、子任务可理解性、用户对记忆的控制，以及把产物带回日常工具。但不能把报告里的所有“缺失”直接当成开发任务。

原报告位于原工作区 `docs/compare/`，包含客户端清单、插件生态、miniQ 能力清单、历史与路线图五份文件。路线图标注的 miniQ 基线是 **0.1.41**，本轮按 **0.1.45** 源码重新核对；保留原报告，不覆盖其分析。

需要纠正的判断：

- 排队消息、编辑/删除、Steer 已存在。缺的是重排和多设备重排的可靠性。
- 自动化已经有侧栏一级入口、模板和基础历史；后续应补调度细节，而不是再造一套入口。
- `Alt+Space` 全局唤起已有实现；独立迷你浮窗仍可作为后续需求。
- 三栏拖动、右侧多标签、会话搜索、远程文件分块已有实现；“具备功能”不等于所有设备和大文件场景都已验收。
- “Computer Use 完全拉齐”“85% 平齐”等没有可复现指标，不能作为验收结论。原生安全审批、不同应用的 AX 支持、浏览器登录态仍需分别验证。
- 系统防休眠可阻止**闲置休眠**，不能承诺合盖、手动休眠、断电或网络中断时继续执行。
- 报告分析的是本机名为 ChatGPT 的应用中的 Codex 工作台，不能把它等同于所有 ChatGPT 客户端或账号能力。专有服务端调度无法仅凭本地资源证明。

官方交叉参考：[Codex App 设置](https://developers.openai.com/codex/app/settings/)确认运行时防休眠及通知偏好能力；本轮 miniQ 的完成状态以下列代码与测试为准。

## 本轮验证与边界

- 基线本地原工作区有用户未提交资料和宣传片文件，本轮在独立 worktree 修改，未覆盖这些内容。
- 前端验证包含队列、编辑器菜单、子任务状态、设置、通知、主机切换和防休眠生命周期；11 个相关文件的 82 项测试通过，多主机通知另有集成回归。Rust 验证包含存储及真实双客户端 WebSocket 集成测试。
- 记忆验证：前端 8 项（包含在上述 82 项中）、协议 1 项、Store 5 项、daemon RPC 1 项、既有 memory tool 2 项通过。未打开项目时只读全局；项目搜索只合并本项目与全局；搜索 `%`、`_` 和反斜杠按字面匹配。删除原子匹配范围、ID、时间及原文，时间戳相同但内容变化也会拒绝删除。
- 队列验证：Store 10 项、daemon 队列集成 9 项通过；同模型切换推理强度的 provider identity 定向测试通过。`expectedPosition` 保护目标消息的当前位置，不等同于整队列版本号。
- 浏览器独立样例位于 `agent-preview.html`、`queue-preview.html`、`memory-preview.html`，不访问用户真实会话、不调用付费模型。已操作队列移动及编辑、子任务展开及短暂断连恢复、记忆翻页/搜索/全文/取消及确认删除。390px 窄屏无横向溢出；`appearance-preview.html` 中实际设置弹窗的四个标签与记忆页也已验证。
- macOS 原生测试实际启动并释放 `caffeinate`，验证同一租约幂等、进程回收；Tauri `cargo check` 通过。防休眠当前只在支持的本机 macOS 设置中显示，Windows/Linux 不假装已支持。
- TypeScript 检查、前端生产构建、`cargo check --workspace`、Tauri 独立 `cargo check`、两个 Rust 工作区格式检查、`git diff --check` 均通过。已有大资源 chunk 及动态/静态导入警告仍需后续性能测量，不以本轮功能测试替代性能基准。
- 本轮未发布版本、未重启运行中的 miniQ、未上传 TestFlight，也未安装 Chrome 扩展。长时间离席、合盖、真实弱网和三款编辑器的安装态验收不在本轮已通过声明内。

## 下一批建议验收样例

1. 长任务同时生成文件和读取多个站点，期间切换会话、进入 SSH 项目，核对本机状态及防休眠租约。
2. 两台设备同时编辑和排序同一队列，混入 Steer、取消、自动开始，核对每条消息只执行一次。
3. 模型在文本输出、thinking 和工具参数三种位置分别耗尽预算，验证恢复不丢结果、不重复外部写操作。
4. 100 个子任务的聚合、筛选和分页，测真实网络请求数量、渲染耗时及弱网恢复。
5. 同一文件在本地/SSH/手机查看与讨论，对照来源路径和会话边界，防止把远程路径送给本地编辑器。
