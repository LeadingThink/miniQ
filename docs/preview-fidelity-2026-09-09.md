# 文件预览改进与验收（2026-09-09）

本轮针对桌面右侧预览的渲染、格式兼容、窄面板适配与生命周期。代码基于 `19512bc`，在 `codex/artifact-preview-fidelity` 独立分支完成；没有改变应用版本、发布安装包或重启本机 miniQ。

后续已获得本地安装授权，并完成原生运行验收和追加修复，见 [原生预览与阅读交互验收](native-preview-acceptance-2026-09-10.md)。下文保留本轮当时的验收记录。

## 对比依据

只读检查了本机 `/Applications/ChatGPT.app/Contents/Resources/app.asar` 中的前端资源：`docx-preview-panel`、`pdf-preview-panel`、`use-pdf-pager`、`artifact-preview-header`、`use-binary-preview-source` 和 Mermaid 相关模块。可确认其中使用按页面尺寸适配的 Office 视图，以及带文字层的 PDF 渲染、缩放与页码控制。没有复制客户端代码，也不将可读取的前端模块当作完整后端实现。

OpenAI 官方 [Work with files](https://learn.chatgpt.com/docs/artifacts-viewer) 确认桌面侧栏支持文档、演示文稿、表格、PDF，HTML 渲染/源码切换和文件批注。本轮据此优先改善阅读与渲染基础；没有宣称 miniQ 已具备同等批注编辑能力。

## 已实现

| 范围 | 之前的缺口 | 现在的行为 |
| --- | --- | --- |
| 预览面板 | 固定最小宽度与单行按钮挤占内容 | 面板受容器宽度约束；文件名、关闭按钮与文件操作分行；按格式显示图标 |
| Word / PPTX | 原始页面直接放入滚动框，窄面板裁切 | 测量内容自然宽度和容器宽度，按比例适配；手动缩放、原始尺寸、页码跳转 |
| PPTX | 列表容器固定高度，额外出现内部滚动区域 | 使用文稿自身幻灯片比例，统一外层滚动；保留图表所需的可测量解析环境 |
| Office 阅读位置 | 页面尺寸尚未稳定时恢复滚动 | 渲染和缩放布局就绪后恢复；按可见面积更新当前页，最后一页不被前一页覆盖 |
| PDF 清晰度 | CSS 缩小固定分辨率画布 | 实际渲染比例跟随可用宽度；保留画布像素/边长上限，逐页渲染 |
| PDF 文字 | 只能查看图像或另开原文 | 当前页建立可选择文字层；原文视图复用同一份提取结果 |
| PDF 兼容 | 未随应用提供全部解析资源；加密文件直接失败 | 随包提供 CMap、标准字体、WASM 解码资源；密码输入与错误重试；90° 旋转 |
| PDF 加载 | 加载提示改变布局，可能反复触发宽度重算 | 加载提示为浮层，滚动条预留空间；加载失败停止等待状态 |
| Markdown 图片 | 相对路径直接变成浏览器地址 | 按 Markdown 所在目录解析，经过原生工作区范围校验；接近视口时才读取；显示失败与重试 |
| Markdown 图表 | Mermaid 仅显示代码块 | 按需加载解析器，显示图表、放大/适配、源码与复制；错误时保留完整源码 |
| SVG | 仅显示 XML | 图像与源码切换，复用图片缩放；通过 Blob 图片显示，不把 SVG 作为应用 DOM 执行 |
| CSV / TSV | 仅显示文本 | 独立线程解析，复用分页、搜索、排序、筛选、完整单元格和导出；保留前导零与公式字符串 |
| CSV 兼容 | 混合 CRLF/LF 可能把后续记录并成一行 | 显式支持 CRLF、LF、CR；保留引号内换行、逗号、双引号和空单元格 |
| 生命周期 | 新增渲染器可能反复加载或覆盖新文件 | 取消旧工作线程、拒绝迟到结果、释放 Blob URL；Markdown 图片组件保持稳定，避免目录更新引发重读 |

PDF、Office、Mermaid 的大型依赖按需加载；PDF 兼容资源约 3.2 MB，只在相应文件需要时读取。CSV 的全部数据仍保留在解析结果中，DOM 每页最多显示 200 行。CSP 明确允许同源/Blob Worker 与 WASM 编译，未开放任意 JavaScript eval 或远程脚本。

## 验收

- 20 个相关测试文件、100 项回归测试通过；最后补充阅读位置恢复测试后，对涉及的 9 个文件重新运行，34 项通过。
- `npm run build`（含 TypeScript）通过；`cargo check --manifest-path apps/desktop/src-tauri/Cargo.toml` 通过；`git diff --check` 通过。
- 生产依赖审计未发现已知漏洞。安装新依赖没有升级已有依赖版本。
- 浏览器实测上游 PPTX 14 页，最后一页的 4 个 SVG 图表、中文文字、母版和表格均存在；缩放后无横向裁切。样例来自 `https://501351981.github.io/pptx-preview/examples/dist/test.pptx`。
- 浏览器实测 DOCX 表格样例：360px 面板下页面约 301px 宽，容器 `scrollWidth === clientWidth`。样例来自 `https://raw.githubusercontent.com/VolodymyrBaydalka/docxjs/master/tests/render-test/table/document.docx`。
- 390px 视口下 CSV 显示 `1003 / 1003 行`，DOM 为 200 行；搜索 `1002` 能找到最后一条记录，文档无横向溢出。
- Mozilla 的 `issue15893_reduced.pdf` 实测错误密码提示、重新输入及成功解锁；成功后密码表单消失，文字层正常出现。样例测试密码来自上游公开测试清单。
- 双页 PDF 在 320px 视口中旋转后正常显示；画布与文字层边界对齐，页面无横向溢出。
- Markdown 的 Mermaid、KaTeX、表格、图片与源码入口已在浏览器检查；本地图片范围校验调用、拒绝路径、卸载清理和不重复读取由组件测试覆盖。
- 使用实际 `night` 主题检查 Word：工具栏跟随深色界面，纸张保持白色、正文保持黑色。

开发验收入口为 `apps/desktop/experience-preview.html`，提供不同格式、面板宽度和主题选项，仅在开发环境运行，不进入生产主页。未使用真实会话执行写入任务。

## 仍有明确边界

- 这次验收运行的是源码构建与隔离浏览器页面，尚未安装到正在运行的桌面应用；原生 WebView 的运行验收应随下一次明确授权的安装更新执行。
- Excel 仍以数据表格为主，不等同于完整 Excel 的样式、合并单元格、公式计算和图表重现。
- Office 的特殊字体、动画、嵌入式对象、复杂 SmartArt 仍受解析库能力限制；没有宣称像素级对齐 Office 原生软件。
- PDF 链接/表单批注层、文档区域评论、文稿编辑与笔记本专用预览尚未实现。
- 本地文件预览仍使用既有 64 MB 明确上限；超大文件的流式读取、多页虚拟化和移动端远程文件预览不在本轮完成范围。
- 外部图片继续受应用原有网络策略约束；没有为预览放宽工作区文件访问或全局联网权限。
