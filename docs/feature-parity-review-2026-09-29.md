# miniQ 与 ChatGPT 桌面客户端：配套功能彻底对比与改进报告（2026-09-29）

> 上一份报告 `apple-design-review-2026-09-29.md` 比的是动效与视觉；本报告只比**功能**。
> 数据来源：本机 `/Applications/ChatGPT.app` 解包（app.asar → `webview/assets/app-initial-*.js` 命令注册表 126 条、zh-CN 文案 14607 条、原生菜单文案），miniQ `apps/desktop` 源码（HEAD 6fbcca5），每项“有/无”都经 grep 或读源码核实。

## 结论

miniQ 在会话核心能力上（置顶/归档/重命名/分叉/听写/朗读/导出/分享/队列/斜杠命令/模型切换/记忆/定时任务/MCP/插件/技能/预览/审阅/内置浏览器）已与 ChatGPT 基本对齐，部分更细（侧栏状态筛选带计数、测试通知）。

真正的差距集中在**“配套”层**——键盘驱动、会话切换、右键菜单、原生菜单、通知覆盖面、输入框效率：

| 维度 | ChatGPT | miniQ（改前） |
|---|---|---|
| 注册命令数 | 126 条（均可在命令面板/快捷键触发） | 命令面板 5 条 |
| 默认快捷键 | 约 60 个 | 7 个 |
| 快捷键帮助 | ⌘/ 对话框，分节 | 无 |
| 会话切换 | ⌘⇧[ ]、Ctrl+Tab、⌘1–9、⌘⌥A 下一个需关注 | 只能点侧栏 |
| 右键菜单 | 文件树、diff、浏览器 | 全仓 `onContextMenu` 为 0 |
| 原生菜单 | 文件/编辑/视图/前往/窗口/帮助，中文 | Tauri 默认英文菜单；托盘英文 |
| 通知 | 完成 / 需要审批 / 需要回答 | 仅完成、失败 |
| 输入框 | @提及文件、↑ 调上一条、选中引用 | 无 |

## 二、不做

账户/订阅/用量计费、云环境与云浏览器、ChatGPT 远程计算机中继、GPTs/资料库/理财/Sites 路由、宠物与头像浮层、实时语音、企业托管策略、内部调试与 Alpha 开关、云端代码审查投递、面板自由拖拽。原因：依赖 OpenAI 账户或云服务，或与 miniQ 本地助手定位无关。

## 三、本轮实施分组

1. **键盘与会话导航**：统一快捷键注册表 `shortcuts.ts`、⌘/ 帮助对话框、会话切换全家桶、会话操作快捷键、命令面板扩充、未读持久化、撤销 toast、返回/前进。
2. **文件树与预览**：右键菜单、添加到聊天、转到行、查找入口、更多菜单。
3. **输入框**：@ 提及文件、选中引用、↑ 调上一条、⌘U 添加文件。
4. **系统集成**：中文原生菜单（事件转发到前端命令总线）、关于、托盘中文、审批/提问通知。

前端各组之间通过两条约定通信：
- `window` 事件 `miniq:command`（`detail.id`）：原生菜单、命令面板统一派发，由导航组处理。
- `window` 事件 `miniq:composer-insert`（`detail.text`）：文件树/预览“添加到聊天”、聊天引用，由输入框组处理。
