# 输入框快捷命令

## 差异与改进

对照本机 `/Applications/ChatGPT.app/Contents/Resources/app.asar` 的命令注册与菜单实现，关键差异是：该客户端将应用动作、模型与项目子菜单、技能统一注册为可搜索的命令；miniQ 原来仅请求 `skill.list`、只搜索技能名称并最多显示 8 个结果。

本轮实现采用 miniQ 自己已有的应用动作和 RPC，没有复制客户端代码，也没有用聊天提示词伪装模型设置、分享或上下文压缩操作。

## 使用方式

- 输入 `/` 浏览分组命令，按中文名称、英文命令或描述搜索。
- `/model` 展开当前服务返回的文本模型，继续输入 `/model gemini` 可筛选；选择后只更新当前会话。新会话使用已有的独立草稿模型设置机制。
- `/reasoning` 只列出当前模型实际支持的推理强度及默认设置。
- `/project` 展开全部项目，可搜索名称和目录；选择后进入该项目的新会话。
- `/new`、`/search`、`/pin`、`/archive`、`/rename` 操作会话。
- `/share` 打开现有分享预览，选好内容后仍需点击发布按钮；选择命令本身不发布任何内容。
- `/review` 打开已有文件差异面板；`/usage` 打开模型调用、用量和执行事件记录。
- `/browser` 打开内置浏览器；本地 Tauri 客户端的 `/attach` 打开文件选择器。
- `/skills`、`/mcp`、`/plugins`、`/schedule`、`/import`、`/settings` 进入对应管理界面。
- `/distill` 从已完成会话中提炼技能；`/task` 复用首页的任务模板，填入草稿而不直接发送。
- 已启用技能按当前项目加载，描述也可搜索，所有结果均可滚动或用键盘访问，不再截断到固定数量。

命令随当前会话状态变化：新会话不展示分享、置顶、归档等已有会话动作；任务运行或模型配置保存期间禁用模型切换；远程端禁用本地会话导入并显示原因。

## 交互与隔离

- 上下箭头切换候选，Enter/Tab 选择，Esc 返回上层或关闭；中文输入法确认不会误选或发送。
- URL、包含目录分隔符的路径、多行消息不会触发菜单。
- 子菜单懒加载，网络失败可重试；切换项目或会话后忽略过期响应。
- 异步命令失败恢复原命令草稿；若期间通过文件预览插入了新问题，则保留新草稿。
- 菜单根据输入框、窗口和可视区域的位置选择上方或下方，窄屏可滚动且不撑宽页面。
- 自定义命令目录、技能加载、搜索状态、菜单渲染分别维护；原来的技能菜单实现已移除。

## 验证

69 项针对性测试通过，包含命令目录、真实模型更新 Hook、Composer 草稿、语音、模型控件及交互回归。

独立浏览器验收页 `apps/desktop/slash-preview.html` 使用模拟数据验证：41 项菜单完整保留、末尾技能可搜索、模型子菜单筛选并更新、390px 窄屏无横向溢出。该页面不连接用户的 daemon，不调用付费模型。

macOS 本地构建使用原 Developer ID Application 签名；版本维持 `0.1.32`，不创建发布标签、不修改线上下载或自动更新清单。最终本地安装和权限验收结果以本次任务回报为准。
