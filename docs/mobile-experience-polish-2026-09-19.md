# 移动端体验修复与验收（2026-09-19）

## 更新检查结论

本机安装的 `/Applications/miniQ.app` 与线上更新清单均为 **0.1.36**，因此检查更新不会提供更高版本。此前没有更新时只恢复“检查更新”按钮，容易让用户误以为没有响应。本次手动检查完成后明确展示“已是最新版本 v…”。后台检查仍保持安静；手动检查可以复用正在进行的后台请求。

本批改动在 `codex/mobile-experience-polish` 开发分支完成。未更改版本号，未创建发布标签，未上传新安装包或 TestFlight 构建，也未重启本机 miniQ。

## 已实现的优化

### 连接与隔离

1. 断开连接时立即清理待处理请求、超时定时器和传输，避免旧请求超时破坏新连接。
2. 压缩数据解码完成后再次核对连接身份，阻止旧电脑事件进入新连接。
3. 切换 Key 可以取消密钥推导及尚未收到服务端确认的连接。
4. 旧连接的异步清理不会清掉新连接的状态。
5. 合并原生 App 与网页同时发出的前台恢复通知，减少重复健康检查和目录请求。
6. 项目或会话列表同步失败时保留仍健康的连接，不因单个读取错误反复重连。

### 网页观察与文件

7. 远程“浏览器”入口改为查看当前会话保存的桌面网页记录，明确标注非实时画面。
8. 可选择历史网页记录并按需加载更早会话内容；只读取所选记录的详情和截图。
9. 网页记录可以带着页面标题和链接继续提问，内容放入草稿后由用户发送。
10. 截图支持全屏、缩放、适配、原图下载；全屏复用已加载图像。
11. 手机打开网页链接明确使用本机浏览器，不声称共享桌面登录状态。
12. 关闭观察或切换记录时取消正在进行的截图传输。
13. 文件目录按连接和会话隔离，不沿用上一会话的路径。
14. 目录分页失败保留已加载文件，并从失败页重试。
15. HTML 静态资源最多三路并行、规范化路径去重，并在传输前检查总大小预算。
16. HTML 预览支持响应式图片、嵌套样式导入、layer/supports/media 条件和 SVG 片段引用；保留脚本 defer/async 语义，并在真实浏览器中验证隔离策略。
17. 文件下载复用已有预览内容，避免再次传输同一文件。
18. 异步下载后保留可点击的保存入口；支持文件分享 API 的手机可直接分享或存储。
19. 关闭文件预览释放大文件内容，保留标签身份及查看位置。

### 移动问答

20. 模型列表只显示 `model_type=chat`，支持搜索、有效默认值与记住选择。
21. 模型列表未准备好时禁止发送；加载失败有明确的重新加载入口。
22. 正确处理流式响应的 UTF-8/换行边界、结束标记、服务方错误和异常断流。
23. 收到结束标记即停止读取；退出问答取消请求并释放 reader。
24. 出错或中断保留已收到内容，重新回答不会重复追加用户问题。
25. 发送“继续”时保留非空的部分回答作为上下文。
26. 流式输出批量渲染，历史消息复用渲染结果，避免每个 token 都写入设备存储。
27. 完成、离开和切后台时保存历史快照；切后台不会主动取消仍在进行的回答。
28. 上滑阅读时不抢滚动，提供返回最新内容入口。
29. 长历史每次增加 30 条展示，不截断或删除已有历史。
30. 中文输入法确认候选不会误发；图片读取未完成时禁止提前发送。

### 移动布局与操作

31. 网页高度跟随键盘上方可见空间；原生壳使用 WebView 尺寸调整。
32. 缩放不参与键盘高度计算，避免布局随缩放反复变形；保留主动缩放能力。
33. 编辑控件统一至少 16px 字号，减少 iOS 聚焦自动放大。
34. 常用按钮扩大触摸区域，补齐安全区、横屏与预览工具栏适配。
35. 网页和文件标签允许横向滚动，当前标签保持可见；网页标签支持键盘切换及关闭后焦点恢复。
36. 远程状态栏和 `/browser` 命令采用一致的网页记录入口；未选择会话时明确禁用。
37. 移动首屏不再提前加载桌面工作台和问答渲染器；进入对应功能时按需加载，并保留加载提示和返回入口。

## 首屏 JS 测量

对生产构建的 HTML 入口及所有递归静态 JS 依赖求和，未连接的移动入口从 **977,368 字节**降至 **196,987 字节**（减少 **79.85%**）；各文件 gzip 后合计从 **304,074 字节**降至 **67,476 字节**（减少 **77.81%**）。这不包含 CSS、字体、按需功能模块和模型响应，不代表完整工作台总量或实测网络时延。

## 验证边界

37 个相关测试文件共 **225 项测试**通过，另有 **5 项 iOS 构建脚本测试**通过；TypeScript 检查、前端生产构建及限定范围的差异格式检查通过。浏览器验收使用真实源码组件及隔离的模型/RPC 测试数据，不使用真实客户 Key，不发起付费模型请求，不修改真实会话。

在 320px、390px 和 844×390 浏览器视口检查入口、模型搜索、中文流式回复、网页记录、截图与文件分页。视口检查不等价于 iPhone/Android 真机测试；原生软键盘、系统分享、双指缩放和系统回收后的恢复仍需在新 App 构建的实体设备上复核。远程网页记录不是持续的视频流，也不提供手机对桌面网页的直接坐标操作。
