# 右侧工作区分栏修正与验收

## 对照依据

只读检查本机 `/Applications/ChatGPT.app/Contents/Resources/app.asar` 中与右栏有关的前端实现：`webview/assets/app-initial-cadb12d4a15e.js` 的分栏组件 `SKa`、方向计算 `CKa`、键盘操作 `wKa`、边界计算 `TKa`、分隔条 `EKa`，以及右侧调用者、`app-shell:right-panel-width:v3` 偏好逻辑和 `panel-ef6d006bdcad.js` 的拖动生命周期。阅读范围沿实际依赖展开，不代表读完客户端所有功能，也不涉及服务端实现。没有将其代码复制进 miniQ。

可借鉴的具体机制：边缘锚定的 16px 命中区域、可见的悬停/焦点状态、窗口级拖动监听、松手最终坐标、结束后保存、键盘方向与边界操作、按可用空间计算宽度。官方文件查看说明只用于功能范围参考：<https://learn.chatgpt.com/docs/artifacts-viewer?surface=app>。

## 根因与改动

1. 原 CSS 在窗口宽度 ≤1100px 时隐藏分隔条，并把预览固定为另一套宽度。现使用同一工作区容器，小桌面浮层仍可拖动；≤720px 手机采用全屏布局。
2. 原 1200px 窗口、展开侧栏时最大预览仅 496px，最小 380px。现基于实际侧栏宽度和主区域空间计算，最小 320px，保留至少约 320px 会话内容，不再使用任意 900px 上限。
3. 临时窗口约束与用户偏好分离。缩窗、展开侧栏、仅点击拖动条不会覆盖宽度；双击或 Enter 恢复 560px 偏好。
4. 工作区自己持有拖动状态，React 帧更新不再传播到 AppShell 和会话树；每帧最多一次预览宽度更新，松手只保存一次。
5. 使用窗口指针监听和捕获，处理最终坐标、失焦、丢失捕获、取消、卸载、移动端切换。Esc 撤销本次拖动。边界后反向移动立即响应；保留小数指针位移，防止逐事件取整累计漂移。
6. 方向键每次 12px，Shift 加速到 48px，Home/End 到达边界；补充可访问宽度描述和可见手柄。
7. 拖动时 HTML iframe 暂停接收指针，保留页面实例与内部交互状态；全屏预览保持独立尺寸，退出后恢复原分栏。
8. 实测发现 PDF.js 文字测量画布插入 body 后产生约 18px 多余高度、触发全局滚动条。将测量画布隐藏，避免影响分栏可用空间。
9. 内置浏览器的 ResizeObserver 直接同步原生几何位置，移除第二次动画帧等待；原生侧一次更新位置和尺寸。工具栏、状态栏禁止 flex 压缩，按钮保持窄栏可用的尺寸。
10. 删除远端手机样式中另一套预览定位规则，统一由工作区容器负责尺寸；手机预览置于侧栏之上，避免被侧栏遮挡。
